Tessera — таблица данных для React поверх [TanStack Table](https://tanstack.com/table).
TanStack Table даёт модель таблицы, а Tessera рисует на ней готовую таблицу: виртуализация
строк и колонок, встроенный интерфейс сортировки, фильтров, закрепления, правки и другого, тема
на CSS-переменных.

## Как это устроено

Работа идёт через два вызова:

- `useCreateTable({ columns, data, plugins })` создаёт экземпляр таблицы.
- `<DataGrid table={table} />` его рисует.

Каждая возможность — **плагин**. Фабрика плагина импортируется из
`@tessera-grid/tessera/plugins` и кладётся в список `plugins`. Плагин не в списке не работает и
не попадает в бандл.

## Когда выбирать Tessera

- Нужны модель и типы TanStack Table, но не хочется самим собирать интерфейс таблицы.
- Данных много: строки виртуализированы всегда, а серверная модель строк грузит их блоками по
  мере прокрутки.
- Нужны клавиатура и скринридеры: таблица рассчитана на WCAG 2.2 AA.
- Таблица должна совпасть с вашей дизайн-системой: цвета, размеры и движение — CSS-переменные,
  иконки и подписи заменяются.
