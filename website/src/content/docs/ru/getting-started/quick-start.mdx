## Что здесь происходит

- **`plugins`** включает возможности. `columnSorting()` добавляет кнопки сортировки в
  заголовки, `columnSizing()` — ручки изменения ширины.
- **Колонка разрешает возможность себе.** Плагин включает сортировку у таблицы, а
  `enableSorting: true` разрешает её колонке.
- **`dataType`** говорит таблице, как показывать, сортировать, фильтровать и править значения
  колонки.
- **У `columns` и `data` постоянная ссылка.** Новый массив пересобирает модель таблицы,
  поэтому задавайте колонки вне компонента или мемоизируйте их.
- **Id строк.** По умолчанию id строки — её поле `id`. Если строкового `id` у строк нет,
  передайте `getRowId: row => String(row.key)`.
