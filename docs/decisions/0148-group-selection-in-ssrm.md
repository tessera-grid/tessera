## Контекст

Серверная группировка (ADR 0144) показывает группы по всей выборке: страны, менеджеров,
статусы на миллионах строк. Выбирать в ней можно только строки данных — по одной или все
сразу («всё, кроме», ADR 0138, §9). Массовое действие над частью выборки — выгрузить,
удалить, изменить все строки страны US — без выбора группы возможно только через фильтр:
загрузить строки группы нельзя, а перещёлкать их флажки — тем более.

Выбор группы должен описываться без загруженных строк: группа из миллиона строк выбирается
одним нажатием, исключения внутри неё — отдельные строки и подгруппы, а значение уходит
на сервер, который сам разбирает, какие строки выбраны.

### Как у других

- **AG Grid** (SSRM, `groupSelects: 'descendants'`) хранит дерево переключений: у узла
  `selectAllChildren` и `toggledNodes` — дети, чьё состояние отличается от родителя
  (`getServerSideSelectionState`). Флажок группы — в трёх состояниях; дерево разбирает
  сервер. Смена группировки выбор сбрасывает.
- **MUI X** хранит выбор как `include`/`exclude` со списком `id`; выбор потомков группы
  (`rowSelectionPropagation`) работает по загруженным строкам — группы с незагруженными
  детьми целиком не выбрать.
- **Excel, Google Sheets** — выделение по координатам, выбора групп нет.

## Решение

### 1. Флажок у строки-группы

При серверной группировке и включённом `rowSelection` у строки-группы есть флажок.
Нажатие или `Space` (с `keyboardNavigation`) выбирает группу целиком, не загружая её строк;
повторно — снимает. Флажок группы — в трёх состояниях:

- **выбрано** — группа выбрана, исключений внутри нет;
- **частично** (`aria-checked="mixed"`) — внутри есть исключения, отдельно выбранные строки
  или выбранные подгруппы;
- **не выбрано**.

Строки и подгруппы выбранной группы выглядят выбранными, в том числе те, что придут позже.
Снятый флажок строки или подгруппы — исключение в узле группы. У строки-группы есть
`aria-selected`.

### 2. Срез — дерево переключений поверх «всё, кроме»

Нынешний срез расширяется, а не заменяется:

```ts
interface RowSelectionAll {
  /** Выбрана вся выборка. */
  all: boolean
  /** Строки, чьё состояние обратно `all`: при `all: true` — снятые, при `false` — выбранные. */
  except: string[]
  groups?: RowSelectionGroup[]
}
interface RowSelectionGroup {
  /** Путь значений группировки от корня: ['US', 'Smith']. */
  keys: unknown[]
  /** Группа выбрана целиком, кроме `except` и узлов `groups` внутри неё. */
  all: boolean
  except: string[]
  groups?: RowSelectionGroup[]
}
```

`except` — строки, чьё состояние обратно `all` своего узла, как `toggledNodes` у AG Grid. При
`all: true` это прежние исключения ADR 0138; при `all: false` — отдельно выбранные строки вне
выбранных групп.

- Узел группы появляется, только если её состояние отличается от родителя: выбранная группа
  под невыбранным корнем, снятая — под выбранным. Узел, совпавший с родителем без
  исключений и подузлов, удаляется.
- Без группировки срез прежний — `{ all: true, except }` или выбранные `id`; приложения,
  написанные под ADR 0138, не меняются. `all: false` с `groups` — выбраны только эти группы.
- Срез приходит в `onRowSelectionChange` и задаётся аргументами `rowSelectionModel`
  (ADR 0120). TanStack получает эффективное значение, как сейчас (ADR 0039): строка выбрана,
  если по пути её групп ближайший узел — с `all`, и её `id` нет в его `except`.
- «Выбрать всё» в шапке ставит `all: true` и сбрасывает узлы групп; снятие — пустой выбор.

### 3. Счётчик

Если сервер прислал число строк для каждой выбранной группы (`getGroupChildCount`,
ADR 0144) — счётчик точный: сумма строк выбранных групп минус исключения. Нет числа хотя бы у
одной — «N строк и k групп»; так же, как «все, кроме k» без итога (GS9). Подписи — ключами
`localization`.

### 4. Выборка

- Смена группировки сбрасывает выбор целиком: ключи групп прежней группировки теряют смысл, а
  частичный перенос сбивает с толку. Отказ серверного действия смены группировки (GS3)
  возвращает и прежний выбор.
- Сортировка, фильтр и поиск выбор групп не сбрасывают — как выбор строк (ADR 0138, §9). Что
  значит «выбрана группа US» при новом фильтре, решает сервер в момент действия.

### 5. Сервер

Серверная выгрузка и серверные действия получают срез с узлами групп в `selection`. Разбор
дерева — на сервере: Tessera строки выбранной группы не перечисляет. Канал действий сообщает
выбор и снятие группы с путём её ключей.

## Границы

- **Только SSRM.** В клиентской модели выбор при группировке по-прежнему инертен с причиной
  `'grouping'`; его разблокировка — отдельная прожарка.
- **Группировка вместе с деревом данных** (`hasChildren`) — осознанное ограничение (roadmap):
  строки данных при группировке детей не раскрывают (GS11), значит и выбирать в них нечего.
- **`canSelectRow`** вызывается для загруженных строк; для незагруженных строк выбранной
  группы — нет: запрет выбора отдельных строк внутри группы проверяет сервер.
- **`onSelectRow`** по строкам незагруженной группы не зовётся — изменение приходит одним
  `onRowSelectionChange`.

## Отвергнутые альтернативы

- **Единая форма как у AG Grid** (`{ all, toggled: [{ id, all, toggled }] }` во всех режимах)
  — одна модель, но ломает тип `{ all, except }` из ADR 0138 ради группировки.
- **Плоский список выбранных групп** (`groups: [{ keys, except }]` без вложенных узлов) —
  проще для сервера, но «группа выбрана, кроме подгруппы» не выразить.
- **Выбор группы загрузкой её строк** — не работает на миллионе строк, ради которых SSRM.
- **Переносить выбор строк при смене группировки, снимая только узлы групп** — половина
  выбора исчезает без видимой причины.
- **Флажок группы только при известном числе строк** — счётчик всегда точен, но сервер без
  `getGroupChildCount` теряет выбор групп целиком.

## Последствия

- **+** Массовое действие над группой из миллиона строк — одно нажатие; сервер получает
  компактное дерево.
- **+** Приложения без группировки не меняются.
- **−** Разбор дерева выбора — работа сервера приложения; мок историй показывает её, но
  писать её приложению.
- **−** Эффективный выбор строки — проход по пути её групп: цена растёт с глубиной
  группировки (GX12).
- **Публичный API:** тип `RowSelectionValue` расширен необязательным `groups` и новым
  `RowSelectionGroup`; `all` у «всё, кроме» — `boolean`, а не `true`. Ключи подписей
  счётчика с группами. Ломающее только для кода, который сравнивает `all === true` как
  признак формы среза: признак — `isAllSelection`.
