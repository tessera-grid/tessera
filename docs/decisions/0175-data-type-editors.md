## Контекст

Тип колонки (ADR 0172, 0174) задаёт вид, сортировку, фильтр, поиск и выгрузку, но правка
ячейки о нём не знает. Встроенный редактор — одно текстовое поле на любой тип: число в `ru`
открывается с точкой, хотя ячейка показывает запятую; дату, булево и вариант приходится набирать
текстом. `onCellEdit` получает строку, и разбирает её приложение — кроме серверной модели, где
разбор по типу уже есть (ADR 0139). Свой редактор задаётся одним аргументом плагина на все
колонки и сам ветвится по колонке.

### Как у других

- **AG Grid** — `cellDataType` выбирает редактор: `agNumberCellEditor`, `agDateCellEditor`,
  `agCheckboxCellEditor`, `agSelectCellEditor` и `agRichSelectCellEditor` (поиск, асинхронные
  значения, несколько значений); `valueParser` колонки; значение в `onCellValueChanged` — в типе
  колонки.
- **MUI X** — `type` колонки: `number`, `date`, `dateTime`, `boolean`, `singleSelect` (список без
  поиска); `renderEditCell` колонки; `processRowUpdate` получает строку со значением в типе.

В обеих свой редактор задаётся у колонки, значение правки — в типе колонки.

## Решение

### 1. Значение в типе колонки

`onCellEdit` получает `value` в типе колонки — число, `Date`, запись, массив — и `text`,
введённый текст. `validate` получает то же значение и текст, `onEditCancel.draft` — черновик в
типе колонки. Ввод разбирается по базовому типу при сохранении в обоих режимах; `parseValue` типа
или колонки главнее встроенного разбора. Серверная модель пишет в кэш то же значение, второго
разбора нет (ADR 0139).

### 2. Встроенные редакторы по базовому типу

| Базовый тип                  | Редактор                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `text`                       | Текстовое поле, как сейчас.                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `number`, `numberString`     | Поле с числом на языке таблицы — десятичный знак языка, без разрядов («1234,5» в `ru`); ввод — по языку, разряды допустимы. Не число — ошибка поля из словаря, как у `validate`, сохранения нет. Пустое поле — `null`. `numberString` не проходит через float.                                                                                                                                                                                  |
| `boolean`                    | Без поля: действие правки — кнопка, Enter, F2, Space — сразу переключает значение и сохраняет его.                                                                                                                                                                                                                                                                                                                                              |
| `date`, `dateString`         | Поповер с календарём фильтра даты: пояс таблицы, язык календаря. Значение — `Date` или строка формата типа.                                                                                                                                                                                                                                                                                                                                     |
| `dateTime`, `dateTimeString` | Тот же календарь и поле времени.                                                                                                                                                                                                                                                                                                                                                                                                                |
| `select`, `object`           | Поле с поиском (Combobox Base UI): набор сужает список, стрелки и Enter. Варианты — `options` колонки, справочник — `loadOptions` с ожиданием, отказом и повтором. `object` сохраняет запись варианта: у `ColumnOption` поле `record` (`value` — её ключ, как в фильтре), без него — запись с тем же ключом из загруженных строк, иначе текст ключа разбирает свой `parseValue`; подпись — по `getLabel`. Значение очищается отдельным пунктом. |
| `multiSelect`                | Поповер со списком флажков и поиском — общий модуль с панелью фильтра вариантов. Сохраняет массив.                                                                                                                                                                                                                                                                                                                                              |

В поповерах Enter сохраняет, Escape отменяет, фокус возвращается в ячейку. Календарь и список
вариантов грузятся ленивыми модулями при первой правке своего типа (ADR 0061), длинный список
виртуализирован.

### 3. Язык календаря

Календари фильтра и редактора даты берут язык — месяцы, дни недели, первый день недели — из
опции таблицы `dateLocale` (объект `Locale` `date-fns`), рядом с `locale` и `timeZone`. Аргумент
`dateLocale` у `columnFiltering` снят: плагин не читает опцию другого плагина (ADR 0163), а
язык дат один на таблицу. **Ломающее изменение.**

### 4. Свой редактор

Редактор выбирается по порядку: `editor` колонки, затем `editor` типа (наследуется по `extends`),
затем аргумент `editor` плагина, затем встроенный по базовому типу. `CellEditor` получает
черновик в типе колонки, `commit(value)`, `setDraft(value)`, введённый текст, подпись, ошибку и
контекст ячейки.

### 5. Дополнения (этап 4)

По итогам разбора внедрения (решения автора 2026-11-01):

- **Свой формат даты.** Тип даты со своим `parseDate` записывает значение обратно полем типа
  `formatDate(date)`: редактор даты отдаёт ему выбранный момент (у `dateString` — полночь дня по UTC, как он
  читается, у `date` — полночь в поясе таблицы), без поля пишет в формате базового типа.
- **Очистка даты.** Под календарём — пункт «Очистить значение»: сохраняет пустое значение.
- **Записи без справочника.** У `object` без `options` и `loadOptions` варианты — уникальные
  записи колонки в загруженных строках, по ключу, с подписью по `getLabel`, как у фильтра
  (ADR 0174, TY4).
- **Задержка поиска справочника** — необязательный аргумент `cellEditing({ searchDebounceMs })`,
  по умолчанию без задержки.
- **Подписи редакторов** — свои ключи словаря `edit*`, а не ключи фильтра вариантов.
- **Булево и пробел** (WAI-ARIA APG, Data Grid): на редактируемой булевой ячейке `Space`
  переключает значение, как флажок; выбор строки — `Shift+Space` на любой ячейке тела, а
  `Space` выбирает строку на остальных (уточнение KN12, ADR 0021). Значение редактируемой
  булевой ячейки — флажок для скринридера (`role="checkbox"`, `aria-checked`); нажатие на него
  переключает значение.

### 6. Правки по замечаниям (этап 5)

Решения автора 2026-11-01 после просмотра историй:

- **Числа** выровнены к началу, как текст; вправо — своим `align` (ADR 0172, DT9).
- **Отклонение из-за конфликта** (`onConflict: 'block'`) показывается как отказ сервера:
  вспышка отката, отметка отказа на кнопке правки с причиной, объявление; повторная правка —
  с черновиком и причиной.
- **Флажок булевой ячейки** — флажок кита у левого края ячейки, как текст, нажатие — во всю ячейку, кнопки
  правки нет; нажатие сохраняет сразу, ожидание — дугой на флажке, отказ — вспышкой отката на
  ячейке (ADR 0176, подход «контрол сам»).
- **Прокрутка таблицы** закрывает поповер редактора, правка отменяется (как меню, ADR 0085).
- **Загрузка, отказ и пустой список** вариантов — компонентами кита: строки-скелеты, блок
  ошибки с причиной и повтором (общий с ошибкой загрузки строк), заглушка `Stub`; так же — в
  панели фильтра вариантов.
- **Поиск** у всех редакторов вариантов — в поповере, в ячейке — текст значения; у поля поиска
  кнопка очистки.
- **«Очистить значение»** — отдельная кнопка внизу поповера у даты, варианта и нескольких
  вариантов, а не пункт списка.

## Границы

- Ввод своего варианта, которого нет в списке (creatable), — вне объёма.
- Массовая правка, протяжка значения и правка строки целиком — вне объёма (roadmap).
- Редакторы будущих типов вида ячейки (`url`, `rating` и др.) — с ADR «вид ячейки по типу».
- Типы `time` и `duration` — свои прожарки.
- Ввода даты текстом без календаря нет.

## Отвергнутые альтернативы

- **Строка в `onCellEdit`, как сейчас** — разбор по типу дублируется в каждом приложении, а
  серверная модель уже разбирает сама: два правила для одного ввода.
- **Выпадающий список без поиска для `select`** — справочник с сервера и длинный список так не
  правятся.
- **Поле с чипами для `multiSelect`** — в узкой ячейке чипы не помещаются.
- **`input type="number"`** — разряды и запятая языка таблицы работают не во всех браузерах.
- **Свой редактор только аргументом плагина** — один редактор на все колонки ветвится по
  колонке сам, а тип из реестра не может принести свой редактор.

## Последствия

- **+** Правка в типе колонки: число по языку таблицы, календарь, выбор варианта и записи.
- **+** Одно правило разбора для клиентского и серверного режимов.
- **−** Ломающее изменение `onCellEdit`, `validate` и `onEditCancel`: истории и тесты правки
  переводятся на значение в типе.
- **−** Календарь и список вариантов переезжают из фильтров в `shared/` — тесты DF и SF остаются
  страховкой.

## Внедрение

- **Этап 1** (ED1–ED5; S1, S2, S7) — внедрён 2026-11-01: сессия правки хранит черновик в типе
  колонки (`draft`) и текстом (`text`); `saveEdit` в `plugins/cellEditing/session.ts` разбирает
  набранный текст (`parseEditText` в `editValue.ts`: свой `parseValue` колонки или типа, иначе
  по базовому типу, без типа — по прежнему значению), не разобрался — ошибка поля
  (`editInvalidNumber` у чисел, иначе `editInvalidValue`), сравнивает с исходным
  (`sameEditValue`), зовёт `validate(value, ctx, text)` и коммит; кэш серверной модели получает
  то же значение. Редактор выбирает `editorOf` в `editors.tsx`; поле `editor` у типа и колонки
  объявляет плагин, дополняя `DataTypeFields`, а запись реестра наследует все свои поля, кроме
  `extends`. Поле числа — текст без разрядов (`useGrouping: false`) с `inputmode="decimal"`;
  булево переключает `beginEdit` (кнопка, Enter, F2, Space — действие `cellEditing.toggle` с
  приоритетом над выбором строки), открытая правка булева (отказ `validate`, правка от
  приложения) — значок-флажок в фокусе. Двойной щелчок из ED5 снят: он не открывает правку и у
  других типов. ED11 перенесено в этап 3 — подписи поиска и вариантов появятся там. Тесты:
  модульные `cellEditWrite.dom` (ED1–ED2) и `typedEditors.dom` (ED3), визуальный
  `typed-editors` (ED4–ED5); гайды S1 `EditingNumber`, S2 `EditingBoolean`, S7
  `EditingTypeEditor` (свой тип «приоритет» с сегментами кита). Бюджет снимков Chromatic — 1075 (решение автора 2026-11-01: гайды с близнецами шагов).
- **Этап 2** (ED6–ED7; S3) — внедрён 2026-11-01: календарь и поле времени — `shared/calendar`
  (`Calendar`, `TimeField`, стили — бывший `DateFilterPanel.module.css`), их берут панель
  фильтра даты и редактор `plugins/cellEditing/DateEditor.tsx`. Редактор — ленивый модуль
  (`preloadable` в `editors.tsx`): поповер Base UI под ячейкой, день и время — на часах пояса
  таблицы (`cellToWallValue`), значение — `Date` у `date` и `dateTime` (у `date` время суток
  прежнее), день у `dateString`, у `dateTimeString` — ISO-момент или стенное время, если оно
  было без смещения. Выбор дня у даты без времени сохраняет, Enter в поле времени и уход из
  поповера сохраняют, Escape отменяет, фокус возвращает `restoreFocusIfLost`. Язык календаря —
  опция таблицы `dateLocale` (§3). Текст значения в правке у дат — как в ячейке. Найдено и
  исправлено: закреплённые часы историй (`__mocks__/clock.ts`) не передавали `new.target`, и
  подклассы `Date` (`TZDate` календаря) читали поля в поясе браузера — календарь в Storybook и
  тестах сдвигал день, когда пояс таблицы далёк от пояса браузера. Тесты: визуальный
  `date-editor` (ED6), модульный `dateEditorChunk` (ED7); гайд S3 `EditingDate`, состояние
  каталога `overlay.dateEditor`. Бюджет снимков Chromatic — 1250 с запасом под следующие гайды (решение автора 2026-11-01).
- **Этап 3** (ED8–ED14; S4–S6) — внедрён 2026-11-01: загрузка справочника и список с флажками —

  другой элемент; снятый в никуда фокус (так его снимает и приложение) правку не закрывает. У `ColumnOption` поле
