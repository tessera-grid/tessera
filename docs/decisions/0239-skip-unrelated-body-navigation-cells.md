# 0239 — Быстрая проверка активной позиции ячейки тела

- **Статус:** Принято.
- **Дата:** 2026-11-25
- **Слой:** ядро — определение активной позиции ячейки тела (`core/keyboardNavigation`); грид — использование проверки в `BodyCell`.
- **Связано:** [ADR 0032](0032-wcag-aa-remainder.md), [ADR 0234](0234-filter-tree-and-optional-acceleration.md).

## Контекст

Ячейка тела проверяет, принадлежит ли ей активная позиция. До изменения
каждая проверка вычисляла полную позицию с ограничениями строк, колонок
и шапки. Большинство ячеек нового окна заведомо находится в другой строке.

Контроль FL35 на одном гриде, Chromium ×4, по шесть прогретых переходов
на вариант и позицию. В обоих вариантах монтировалось по 100 ячеек
по медиане.

| Метрика                                  | Активна шапка, база → прототип | Активно тело, база → прототип |
| ---------------------------------------- | -----------------------------: | ----------------------------: |
| Полное вычисление позиции для ячеек тела |                        124 → 0 |                       127 → 0 |
| Чтения числа строк в селекторе тела      |                       124 → 10 |                      127 → 40 |
| Время селектора тела, мс                 |                      4,7 → 1,0 |                     6,7 → 1,2 |
| Рендер вновь смонтированных ячеек, мс    |                    60,9 → 62,0 |                   81,8 → 70,1 |
| До кадра с результатом, мс               |                      315 → 323 |                     467 → 408 |

Варианты чередовались на одном экземпляре. При активной шапке
зафиксировано сокращение работы селектора, изменение времени рендера
в этом сценарии не подтверждено. Сырые данные и сводка находятся в
`performance-results/nav-body-profile-paired.json` и
`performance-results/nav-body-profile-paired-summary.json`.

## Решение

Для строки тела сначала проверить, может ли в неё попасть ограниченная
позиция. Если запрошенный индекс меньше положительного индекса цели,
ограничение никогда не поднимет его до цели. Для остальных целей
прочитать актуальную длину тела и проверить строку до вычисления колонки.
Фокус строки дерева, футер и отсутствие шапки используют те же границы,
что полное вычисление.

Селектор читает текущие данные без разделяемого изменяемого кэша.
Шапка и обработчики клавиатуры сохраняют полное вычисление позиции.

## Требования

| ID   | Требование                                                                                                    | Проверка |
| ---- | ------------------------------------------------------------------------------------------------------------- | -------- |
| NBJ1 | Заведомо чужая ячейка тела отклоняется без чтения геометрии модели.                                           | unit     |
| NBJ2 | Быстрая проверка совпадает с полной при изменении числа строк, колонок, шапки, футера и фокуса строки дерева. | unit     |

Существующие браузерные сценарии проверяют единственный tabindex=0,
стрелки, переход через виртуальное окно, вход с Tab, смену управляемой
позиции и переключение навигации.

## Последствия

Выигрыш относится к синхронной работе на главном потоке и не требует
переноса состояния либо вычислений в Worker.
