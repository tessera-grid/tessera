## Контекст

Основа клавиатуры есть: навигация по ячейкам и режим действия (ADR 0021), WCAG 2.1.1 и замены клавиш
для компактных клавиатур (ADR 0031), меню ручек вместо перетаскивания (ADR 0034). Гарантии «каждая
фича работает с клавиатуры» нет:

- **KB10 устарел.** Аудит собирает грид из 13 плагинов из 40 и проверяет только устройство разметки:
  контрол лежит в ячейке навигации и не выключен из `Tab`. Тулбар, нижняя панель и поповеры вне
  проверки; что контрол срабатывает, не проверяется.
- **Нет реестра.** Новый плагин без клавиатурного пути ничего не роняет; таблица «жест → клавиша»
  ADR 0031 не знает жестов, появившихся позже.
- **Граница KB9.** Без `keyboardNavigation` таблице ничего не обещано, хотя WCAG 2.1.1 требует
  клавиатуру для всей функциональности.
- **Платформы.** `event.ctrlKey || event.metaKey` — во всех сочетаниях: на macOS `Ctrl+стрелки`
  занята системой, `Ctrl+A` в поле — начало строки; на Windows и Linux `Meta` — клавиша Win, её
  сочетания принадлежат системе.
- **Сочетания не видны.** Ни подсказка, ни пункт меню их не показывают, `aria-keyshortcuts` нет.
  Половина клавиш грида не привязана ни к одной кнопке — стрелки, `Ctrl+Enter`, `Alt+Shift+стрелки`,
  `Space`, — о них можно узнать только из документации.

Аудит по плагинам: с настоящими клавишами в наборе фичи проверены правка и редакторы по типу,
вставка и заполнение, отмена и повтор, фильтры, ширина, перенос колонок и строк, выделение,
контекстное меню, ошибки ячейки, журнал отказов, «Настройки вида», скрытие колонок, лента, серверная
модель, липкие строки, «наверх», номера страниц, тулбар. Только общим `Ctrl+Enter` (KB12), без теста
фичи, — закрепление, группировка, «Выбрать всё», сводка, меню строки, «Раскрыть всё», размер
страницы, выгрузка. Подсказки только по наведению или пальцу — цветные точки, ошибка ячейки, итоги
и счётчики.

### Как сделано в других библиотеках

- **AG Grid** — сочетания описаны в документации; переназначение колбэками `suppressKeyboardEvent` и
  `navigateToNextCell`; `Ctrl` и `Cmd` равны.
- **MUI X** — шаблон WAI-ARIA grid; список сочетаний в документации.
- **Handsontable** — менеджер сочетаний по контекстам: добавить, убрать, переназначить.
- **Glide Data Grid** — проп `keybindings` включает и выключает группы сочетаний.
- **Google Sheets** — справка по сочетаниям `Ctrl+/` с поиском; сочетания своей платформы.

## Решение

### 1. Гарантия — реестр клавиатуры

Каждый экспорт `/plugins` — строка реестра `KEYBOARD_REGISTRY` (`src/lib/__tests__/keyboardRegistry.ts`):
ID требований, которые проверяют фичу настоящими клавишами, или причина, почему клавиатура ей не
нужна (фича без интерфейса). Страж роняет `npm test`, когда у плагина нет строки, когда ID нет среди
требований принятых ADR и когда у требования нет теста.

### 2. Два уровня

С навигацией по ячейкам (`enableKeyboardNavigation`) — полный путь каждой фичи: стрелки, режим
действия, сочетания. Без неё — роль `table`, каждый контрол достижим по `Tab` в порядке чтения и
работает на `Enter` и `Space`; скрытые кнопки видны по фокусу; перестановка — меню ручки, выделение —
флажки. Оба уровня — WCAG 2.1.1.

### 3. Стандарты

WCAG 2.2 AA: 2.1.1, 2.1.2, 2.1.4, 2.4.3, 2.4.7, 2.4.11, 1.4.13, 4.1.2. Шаблоны WAI-ARIA APG: grid и
treegrid, menu, toolbar, dialog, listbox, radiogroup. axe — в каждом состоянии, открытом с клавиатуры,
с `color-contrast`, в обеих темах и ролях таблицы.

### 4. Платформа и модификатор

`core/keyboardPlatform.ts` определяет платформу: `navigator.userAgentData.platform`, без него —
`navigator.platform`; Apple — macOS, iPadOS, iOS. Опция ядра `keyboardPlatform: 'auto' | 'apple' |
'other'` (по умолчанию `'auto'`) задаёт её явно — для Electron, тестов и историй. Основной модификатор
— `Cmd` на Apple, `Ctrl` на остальных; второй модификатор сочетание не запускает. Все проверки
модификатора идут через `primaryModifier(event)` — страж запрещает в коде проверку «`ctrlKey` или
`metaKey`».

Клавиши, которых нет на клавиатуре Mac, имеют замену в таблице платформ:

| Клавиша       | Apple             | Остальные                       |
| ------------- | ----------------- | ------------------------------- |
| `Home`, `End` | `Cmd+←`, `Cmd+→`  | `Home`, `End`                   |
| `PageUp/Down` | `Option+↑/↓`      | `PageUp/Down`, `Alt+↑/↓`        |
| `F2`          | `Enter`           | `F2`, `Enter`                   |
| `Delete`      | `Backspace`       | `Delete`, `Backspace`           |
| `Shift+F10`   | `Cmd+Shift+Enter` | `Shift+F10`, `Ctrl+Shift+Enter` |
| Повтор        | `Cmd+Shift+Z`     | `Ctrl+Y`, `Ctrl+Shift+Z`        |

Наборы тестов считают платформу «не Apple» на любой машине (`pinTestPlatform` в настройке Vitest):
сочетания с `Ctrl` в них одинаковы на Windows, Linux и Mac; свою платформу тест задаёт опцией.
Синтетические клавиши гайдов берут модификатор платформы (`mod()`).

Ломающее изменение до 1.0: `Ctrl` на Mac больше не работает как `Cmd`, клавиша Win на Windows — как
`Ctrl`.

### 5. Сочетание у действия

У действия с сочетанием — отмена, повтор, копирование, вставка, вырезание, заполнение, «Выбрать
всё», контекстное меню — сочетание показано в подсказке кнопки («Отменить · ⌘Z») и справа в пункте
меню, в виде своей платформы (`⌘Z` или `Ctrl+Z`), и записано в `aria-keyshortcuts`. Подписи клавиш —
из словаря.

### 6. Сводка сочетаний

`Cmd+/` или `Ctrl+/`, пока фокус в таблице, и пункт «Сочетания клавиш» в «Настройках вида» открывают
поповер кита со списком сочетаний текущей таблицы. Список строится из канала клавиатурных действий и
клавиш ядра: в нём только включённое, в виде своей платформы; новый плагин попадает в сводку сам.
Разделы — навигация, выделение, правка, перестановка, меню; поиск по названию действия. `Escape`
закрывает сводку и возвращает фокус туда, откуда её открыли. Подписи — из словаря.

### 7. Фокус

Фокус виден (2.4.7) — кольцо из токена не ниже 3:1; у пунктов списков поповеров — подсветка пункта, как
в шаблоне меню WAI-ARIA. Фокус не перекрыт (2.4.11): активную ячейку не
прячут липкая шапка, футер, закреплённые колонки, липкие строки. Ловушки нет (2.1.2): из поповера,
панели и редактора `Escape` возвращает фокус на кнопку-источник, `Tab` выводит дальше. Фокус не
теряется: после закрытия, удаления, вставки, переноса, отказа, смены страницы и сворачивания группы с
фокусом внутри он не уходит на `body`.

### 8. Подсказки по фокусу

Всё, что показывает наведение — подписи значков, цветные точки, ошибка ячейки, обрезанный текст,
итоги и счётчики, — показывает и фокус с клавиатуры (1.4.13); `Escape` скрывает подсказку, не уводя
фокус.

### 9. Где истории

Путь с клавиатуры, отличный от мышиного, — сценарий в разделе фичи; сквозное поведение — в
«Cells/Keyboard». Клавиша, равная клику, своей истории не получает: её проверяет тест.

## Границы

- Настройка сочетаний — roadmap (как у Handsontable и Glide Data Grid).
- Скринридер — объявления и дерево доступности остаются за ADR 0033.

## Отвергнутые альтернативы

- **`Ctrl` и `Cmd` равны везде.** Расходится с соглашениями платформ: сочетания системы и полей ввода
  перехватываются таблицей.
- **Сводка списком вручную.** Расходится с набором плагинов таблицы; канал клавиатурных действий уже
  знает включённое.
- **Гарантия только с навигацией по ячейкам.** WCAG 2.1.1 требует клавиатуру для всей
  функциональности, не только при опции.

## Последствия

- Новый плагин без строки реестра клавиатуры роняет `npm test`.
- Проверки модификатора — только через `primaryModifier`.
- Пользователи Mac, нажимавшие `Ctrl` вместо `Cmd`, переходят на `Cmd`.
