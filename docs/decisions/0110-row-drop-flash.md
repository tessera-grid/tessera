# 0110 — Приземление перестановки строки вспышкой

- **Статус:** Принято (решения — по итогам обсуждения 2026-10-14)
- **Дата:** 2026-10-14
- **Изменяет:**
  - [ADR 0107](0107-row-motion.md) — RM10: облако при броске не долетает до слота, а
    пропадает; строка на новом месте вспыхивает.
  - [ADR 0006](0006-dnd-with-dnd-kit.md) — «Фиксация + очистка»: анимации броска у
    облака нет ни с движением строк, ни без него.
- **Изменено:** [ADR 0134](0134-outcome-flash.md) (2026-10-24) — приземление — вспышка `arrived`, срез `rowDrops` удалён; LD2, LD4, LD5 — по механизму вспышки. §2 описывает прежний вид.
- **Связано:**
  - [ADR 0056](0056-lazy-children-arrival-highlight.md) — вспышка прихода строки: слой,
    цвет и время.
  - [ADR 0108](0108-row-drop-preview.md) — слот-скелет на месте броска.

## Контекст

Бросок строки мышью (ADR 0107, RM10) — облако долетает до слота, слот проявляется
строкой. Облако и слот — две разные картинки одной строки: облако — урезанная первая
ячейка, слот — скелет (ADR 0108). Полёт одного в другое читается как лишнее движение, а
проявление скелета строкой — как мерцание. Без движения строк облако гаснет со сдвигом.

Где строка оказалась, грид уже умеет показывать: пришедшие дети ленивой строки
вспыхивают слоем прихода и гаснут (ADR 0056).

## Решение

### 1. Облако пропадает

При отпускании облако исчезает в том же кадре — без полёта и угасания, с движением
строк и без него. Слот в том же кадре становится строкой: соседи уже стоят на местах
после броска, ни одна строка не переезжает (RM10).

### 2. Строка вспыхивает

Переставленная строка получает отметку броска — срез `rowDrops` плагина `rowDragging`
(момент по `performance.now()`, как отметки прихода ADR 0056). Строка с отметкой
рисует слой прихода: цвет `--tsr-comp-row-arrival-color`, держится
`--tsr-comp-row-arrival-duration`, гаснет переходом `--tsr-comp-row-arrival-fade-duration`.
Своих токенов нет: перестановка и приход — одно и то же «строка появилась здесь».

- Перестановка с клавиатуры (`Alt+Shift+стрелки`, ADR 0031) и из меню ручки (ADR 0034)
  вспыхивает так же; строки между старым и новым местом по-прежнему переезжают (RM11).
- Без движения строк (`enableRowAnimation: false`) вспышка есть: это цвет, а не
  движение. При уменьшенном движении — как у прихода: слой держится и пропадает без
  перехода.
- Высокая контрастность — как у прихода: слоя нет (ADR 0087).
- Отметка не попадает в подсветки приложения (`highlights`, ADR 0080) и не перебивает
  их.

## Отвергнутые альтернативы

- **Подсветка `table.highlight`** с тоном и `duration`, как `reveal` у `scrollToRow`. Срез
  `highlights` принадлежит приложению: вспышка перестановки перебивала бы его подсветку
  строки и была бы видна ему как его состояние.
- **Облако гаснет на месте.** Так было без движения строк: глаз всё равно ищет, куда
  делась строка.
- **Свои токены вспышки перестановки.** Дублировали бы прихода без разницы в смысле;
  тема, которой нужна разница, переопределяет токены прихода на строке с
  `data-arrived`.

## Последствия

- Вид броска меняется по умолчанию: полёта облака нет (в CHANGELOG).
- `rowDragging` хранит отметки перестановки; срез внутренний, из `/plugins` не
  экспортируется.
- Строка рисует слой прихода по отметкам `rowArrivals` (ADR 0056) или `rowDrops`.

## Требования

| ID  | Требование                                                                                                                                                                                       | Вид        |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |
| LD1 | Бросок мышью: облако пропадает в кадре отпускания — без полёта и угасания, с движением строк и без него; строка в том же кадре на новом месте                                                    | визуальный |
| LD2 | Брошенная строка вспыхивает `arrived` ([ADR 0134](0134-outcome-flash.md)) тоном `--tsr-comp-flash-arrived-bg`: держится `--tsr-comp-flash-duration`, затем гаснет; соседние строки не вспыхивают | визуальный |
| LD3 | Перестановка с клавиатуры и из меню ручки вспыхивает так же                                                                                                                                      | визуальный |
| LD4 | Без движения строк (`enableRowAnimation: false`) и при уменьшенном движении вспышка есть                                                                                                         | визуальный |
| LD5 | Перестановка пишет вспышку `arrived` строки в срез вспышек ядра; повторная перестановка той же строки перезапускает время; срез `highlights` не меняется                                         | модульный  |

## План внедрения

1. `rowDragging`: срез `rowDrops` и отметки на `createExpiringMarks`; отметка при броске,
   перестановке с клавиатуры и из меню ручки.
2. Строка: слой прихода по `rowArrivals` или `rowDrops`.
3. `DragOverlay` без анимации броска; `rowDropAnimation` и `dropAnimationConfig` уходят.
4. Тесты: `row-motion` (LD1–LD4, RM10 приводится к новому броску), модульный
   `rowDragging` (LD5).
5. Документация: ADR 0006 и 0107, `docs/architecture/dnd.md`, roadmap, AGENTS.md, README
   решений.
