# 0074 — Сегменты и панель экспорта в виде меню

## Контекст

Панель экспорта — сплошной столбец: пресеты, «Строки», «Колонки», «Формат» списками
радиокнопок через разделители. С Excel (ADR 0073) формат — первый выбор пользователя,
а стоит последним, и два его варианта занимают столько же места, сколько длинные
подписи строк. Радиокнопки выглядят иначе, чем остальные меню грида, а единственный
вариант оси (например, «Все строки») читается как невыбранный.

Решено (прожарка 2026-10-09):

- формат — первым, переключателем-сегментами; сегменты — новый публичный примитив
  `ui/Segments`;
- группы панели — как в меню действий строки: подпись группы и разделитель; варианты
  «Строк» и «Колонок» — пункты меню с иконкой и галочкой справа, логика — радиогруппа;
- единственный доступный вариант оси выбран по умолчанию и отмечен галочкой.

## Решение

### 1. `ui/Segments`

```tsx
<Segments
  value={format}
  options={[
    { value: 'csv', label: 'CSV' },
    { value: 'xlsx', label: 'Excel' },
  ]}
  onValueChange={setFormat}
  aria-labelledby={labelId}
/>
```

Выбор одного из немногих коротких вариантов. Построен на `RadioGroup` Base UI:
семантика `radiogroup`, сегмент — `radio` с `aria-checked` и `data-value`, стрелки
переводят выбор, Tab попадает на выбранный, недоступный пропускается. Вид — дорожка
на фоне токена, под выбранным сегментом — приподнятая рамка (фон и тень), ширины равные,
длинная подпись обрезается с `…`. Рамка одна на дорожку: при смене выбора она
переезжает по горизонтали (`transform`, токен `--tsr-comp-segments-indicator-transition`
из базовых токенов движения); «меньше движения» гасит переезд общим правилом темы (MO3).

Токены (`--tsr-comp-segments-*`) выводятся из семантического уровня — тёмная тема
меняет их через `--tsr-sys-*`: высота, внутренний отступ, скругление, фон дорожки,
цвет и фон выбранного, тень выбранного, переходы цвета и рамки.

### 2. Панель экспорта

Порядок: пресеты, «Формат» сегментами (если форматов два и больше), «Строки»,
«Колонки»; «Выгрузить» — последней, справа. Группы устроены как в меню действий строки
(ADR 0024): мелкая подпись группы заглавными и разделитель между группами, без фона и
карточек. Подписи групп, иконки пунктов и дорожка сегментов стоят по одному левому
краю.

Варианты «Строк» и «Колонок» — пункты меню: иконка слева, подпись, галочка справа у
выбранного. Галочка проявляется прозрачностью и масштабом (токен
`--tsr-comp-popup-check-transition`), при «меньше движения» — сразу. Логика прежняя — `radiogroup`: пункт — `radio` с `aria-checked`, выбран
один, стрелки переводят выбор, недоступный пропускается. Иконки — новые ключи
контракта `icons` (`exportRowsAll`, `exportRowsView`, `exportRowsPage`,
`exportRowsSelected`, `exportColumnsVisible`, `exportColumnsAll`), их переопределяет
приложение.

Если у оси доступен один вариант (например, «Строки» — только «Все строки»), он выбран
по умолчанию и отмечен галочкой.

## Вне объёма

- «Строки» и «Колонки» сегментами: у строк до четырёх длинных подписей.
- Тот же вид в других поповерах (фильтры, «Колонки»).

## Последствия

- **+** Формат виден первым и выбирается одним касанием; панель выглядит как остальные
  меню грида.
- **+** Сегменты переиспользуемы приложением и другими панелями.
- **−** Новый публичный примитив, токены и ключи иконок — поверхность API и темы растёт.
