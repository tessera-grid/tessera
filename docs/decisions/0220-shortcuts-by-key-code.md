# 0220 — Сочетания клавиш по коду клавиши

- **Статус:** Принято (решение автора 2026-11-12: «все сочетания клавиш — на коды, нельзя зависеть
  от языка»)
- **Дата:** 2026-11-12
- **Слой:** ядро — канал клавиатурных действий (`core/keyboardActions.ts`, `keyComboOf`) и
  клавиши навигации (`core/keyboardNavigation`, событие канала клавиш несёт `code`); плагин
  `cellSelection` — свои сочетания (`plugins/cellSelection/keys.ts`). Правило общее для ядра и
  плагинов, поэтому имя клавиши по коду считает ядро, а не каждый плагин.
- **Изменяет:**
  - [ADR 0021](0021-keyboard-navigation.md) — Ctrl/Cmd+A выделяет все ячейки по коду клавиши.
  - [ADR 0031](0031-wcag-keyboard.md) — сочетания действий плагинов (`keys` у `KeyboardAction`) с
    буквой или цифрой совпадают по коду клавиши.
- **Связано:**
  - [ADR 0219](0219-paste-fill-and-bulk-edit.md) — Ctrl/Cmd+D и Ctrl/Cmd+R по коду клавиши (WR19).
  - [ADR 0029](0029-cell-range-selection.md) — выделение ячеек, Ctrl+A.

## Контекст

Сочетание с буквой сравнивалось с `KeyboardEvent.key` — буквой текущей раскладки. На русской
раскладке Ctrl+A приходит с `key` = «ф», и выделение всех ячеек не срабатывает; на macOS Option
меняет букву (Option+K даёт «˚»), и сочетание действия автора плагина `Alt+K` не совпадает.
Сочетание — это клавиша, а не символ: Excel, Google Sheets, AG Grid и браузеры ловят Ctrl+A на
любой раскладке.

## Решение

1. **Буква и цифра сочетания — по `KeyboardEvent.code`.** Ядро даёт имя клавиши сочетания
   `keyNameOf(event)`: `KeyA`…`KeyZ` — латинская строчная буква, `Digit0`…`Digit9` и
   `Numpad0`…`Numpad9` — цифра, остальные клавиши — `key` (стрелки, Enter, Escape, F2, Delete,
   пробел от раскладки не зависят). `keyComboOf` собирает сочетание из него.
2. **Ключи действий сверяются без регистра буквы.** `keys: ['Alt+Shift+K']` и `['Alt+Shift+k']`
   — одно сочетание: последняя буква ключа приводится к строчной.
3. **Свои сочетания грида — по коду.** Ctrl/Cmd+A — `KeyA`, Ctrl/Cmd+D — `KeyD`, Ctrl/Cmd+R —
   `KeyR`. Событие канала клавиш навигации несёт `code` (поле обязательное).
4. **Ввод текста — по символу.** Набор цифр в поле времени, подпись AM/PM, ввод в поле правки —
   это текст, а не сочетание: там нужна буква раскладки.
5. **Страж.** В коде библиотеки нет сравнения `KeyboardEvent.key` с буквой или цифрой и сравнения
   `key.toLowerCase()` события — сочетание с буквой пишется через `code`. Подпись нажатой клавиши в
   панели гайда — тоже по коду, у набранного текста — символ.

## Отвергнутые альтернативы

- **И код, и буква: сочетание срабатывает по любому.** На AZERTY Ctrl на клавише `KeyQ` даёт «a» —
  сработали бы оба сочетания, и Ctrl+Q приложения пропал бы. Один источник — код.
- **Буква раскладки с картой раскладок.** Карт столько, сколько раскладок, и они устаревают.

## Последствия

- **+** Сочетания работают на любой раскладке и на macOS с Option.
- **−** Ломающее изменение для авторов плагинов: сочетание действия с буквой совпадает по
  физической клавише (QWERTY-место), а не по символу раскладки; на AZERTY `Alt+A` — клавиша `KeyA`
  (там, где на AZERTY «q»).
- **−** Тесты и истории, которые шлют клавишу с буквой, задают `code`.

## Требования

| ID  | Требование                                                                                                                                                                                                     | Вид        |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| KC1 | Ctrl/Cmd+A выделяет все ячейки по коду клавиши `KeyA` на любой раскладке: и с буквой «a», и с буквой другой раскладки; клавиша с буквой «a» на другом месте выделения не трогает                               | визуальный |
| KC2 | `keyComboOf` берёт букву и цифру сочетания из кода клавиши (`KeyK` — `k`, `Digit1` и `Numpad1` — `1`), прочие клавиши — из `key`; действие с `keys: ['Alt+Shift+K']` срабатывает на Alt+Shift+K с любой буквой | модульный  |
| KC3 | В коде библиотеки нет сравнения `KeyboardEvent.key` с буквой или цифрой и сравнения `key.toLowerCase()` / `toUpperCase()` события                                                                              | модульный  |

## Сценарии

Нет: сценарии пользователя не меняются, меняется только раскладка, на которой они работают.

## Внедрение

Одним изменением: `keyNameOf` и `keyComboOf` в `core/keyboardActions.ts`, сверка ключей в
`findKeyboardAction`, Ctrl+A в `gridKeyDown.ts` и `plugins/cellSelection/keys.ts`, клавиша демо-плагина
историй `keyMarks` — по коду. Тесты — визуальный `key-codes` (KC1), модульный `keyCodes` (KC2–KC3).
Документация: ADR 0021 и ADR 0031 («Изменён»), карта наборов AGENTS.md.
