## Контекст

Текст заголовка, ячейки тела и футера живёт в `CellWrapperTitle` и обрезается
многоточием (`text-overflow: ellipsis`), когда не помещается в колонку или когда его
сужают кнопки ячейки, раскрывшиеся при наведении. Прочитать обрезанный текст можно
только расширив колонку. Нужен тултип с полным текстом — по умолчанию, без настройки
приложения.

`Tooltip` из `/ui` — компонент со своим состоянием на каждый триггер. Обернуть им каждую
ячейку — тысячи экземпляров на 1000×1000: цена монтирования и прокрутки.

## Решение

- **Один тултип на грид.** `DataGrid` монтирует компонент `OverflowTooltip`: нативные
  обработчики на контейнере прокрутки (шапка, тело, футер) и один ленивый попап — тот же
  `TooltipImpl`, что у `Tooltip`. Ячейки ничего не знают о тултипе.
- **Обрезка — в момент показа.** По `pointerover` обработчик находит
  `.data-grid__cell-wrapper-title` под указателем, а по истечении задержки сравнивает
  у него одного `scrollWidth > clientWidth`. Поэтому текст, суженный соседними
  кнопками (они раскрываются при наведении), тоже считается обрезанным. Необрезанный
  текст тултипа не получает.
- **Показ** — с задержкой `Tooltip` (200 мс); текст — `textContent` заголовка. Указатель
  может перейти на сам тултип (WCAG 1.4.13): закрытие с паузой 150 мс, как у `Tooltip`.
- **Клавиатура.** При фокусе ячейки, видимом как `:focus-visible` (`keyboardNavigation`),
  тултип показывается у её текста; уход фокуса и `Escape` его прячут.
- **Не показывается:** над интерактивным элементом внутри текста ячейки и над кнопками
  ячейки (у них свой тултип); у тач-указателя; пока зажата кнопка мыши (перетаскивание,
  выделение, ресайз); у ячейки в правке (редактор заменяет текст).
- **Прячется** при прокрутке, нажатии кнопки мыши, уходе указателя с текста и с тултипа,
  `Escape` и когда текст ушёл из DOM (окно виртуализации, смена данных).
- **Флаг ядра** `enableOverflowTooltip` у `useCreateTable`, по умолчанию включён;
  `false` — компонент не монтируется.
- Доступное имя ячейки не меняется: полный текст и так в DOM, `aria-describedby` не
  ставится.

## Границы

- Только однострочный текст в `CellWrapperTitle`. Служебные колонки (раскрытие,
  перетаскивание, действия) текста в нём не имеют.
- Своё содержимое тултипа (не `textContent`) — отдельной потребностью.

## Отвергнутые альтернативы

- **`Tooltip` на каждую ячейку** — состояние и обработчики на ячейку: цена монтирования
  и прокрутки на больших гридах.
- **`ResizeObserver` на каждом тексте**, чтобы знать обрезку заранее, — та же цена ради
  знания, нужного только при наведении.
- **Нативный `title`** — без темы и задержки, не появляется по клавиатурному фокусу,
  дублирует текст скринридеру.
- **Флаг по умолчанию выключен** — пользователь просил поведение по умолчанию.

## Последствия

- **+** Обрезанный текст читается без расширения колонки; никакой работы на ячейку.
- **−** Новый флаг ядра в публичном API (не ломающее изменение).
- **−** Над обрезанным текстом появляется тултип у всех потребителей; отключается флагом.

## Требования

| ID   | Требование                                                                                                                                                                      | Вид    |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| OT1  | Наведение на обрезанный текст ячейки тела через задержку показывает тултип с полным текстом; у необрезанного текста тултипа нет                                                 | visual |
| OT2  | То же для заголовка колонки и ячейки футера                                                                                                                                     | visual |
| OT3  | Текст, обрезанный кнопками ячейки, раскрывшимися при наведении, получает тултип                                                                                                 | visual |
| OT4  | При клавиатурном фокусе ячейки (`keyboardNavigation` включён) тултип показывается и прячется при уходе фокуса и по `Escape`; без навигации ячейки не фокусируются и тултипа нет | visual |
| OT5  | Над кнопкой ячейки или заголовка виден только тултип кнопки                                                                                                                     | visual |
| OT6  | Тултип прячется при прокрутке и нажатии кнопки мыши и не показывается, пока она зажата                                                                                          | visual |
| OT7  | Ячейка в правке и тач-указатель тултипа не получают                                                                                                                             | visual |
| OT8  | Текст ушёл из DOM (строка покинула окно виртуализации) — тултип исчезает                                                                                                        | visual |
| OT9  | `enableOverflowTooltip: false` отключает тултип; без флага он включён                                                                                                           | visual |
| OT10 | Открытый тултип проходит axe в обеих темах с `color-contrast`; доступное имя ячейки не меняется                                                                                 | visual |
| OT11 | Прокрутка и монтирование с тултипом не дороже, чем без него                                                                                                                     | perf   |
