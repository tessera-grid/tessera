# 0100 — Подсказки пропускают указатель насквозь

- **Статус:** Принято (решение автора 2026-10-13)
- **Дата:** 2026-10-13
- **Изменяет:** [ADR 0032](0032-wcag-aa-remainder.md) — W8: наводимой остаётся только
  подсказка обрезанного текста.
- **Связано:**
  - [ADR 0017](0017-ui-components.md) — примитив `Tooltip`.
  - [ADR 0075](0075-overflow-tooltip.md) — тултип обрезанного текста ячейки, не меняется.
  - [ADR 0083](0083-text-overflow.md) — `overflowOnly`: подсказка у обрезанного текста
    меню, панелей и плашек.

## Контекст

По W8 любая подсказка ловила указатель: уход с триггера закрывал её через 150 мс, а
указатель на подсказке держал её открытой (WCAG 1.4.13, «Hoverable»). Подсказка
кнопки раскрытия строки встаёт над строкой выше и перекрывает её кнопки: курсор,
идущий к соседней кнопке, попадает на подсказку, она не закрывается, а кнопка под ней
не получает ни наведения, ни нажатия.

Подсказки иконок и причины отказа — короткие подписи, дублирующие доступное имя или
описание триггера: читать их, наводя указатель на саму подсказку, незачем. Подсказка
обрезанного текста — другое дело: её текст бывает длинным, и пользователь ведёт по нему
курсором.

Как у других: в AG Grid подсказки по умолчанию неинтерактивны (`tooltipInteraction:
false`); у MUI, Radix и Base UI по умолчанию наводимы, отключается флагом
(`disableInteractive`, `disableHoverableContent`, `disableHoverablePopup`).

## Решение

- **Насквозь.** Подсказка `Tooltip` без `overflowOnly` не перехватывает указатель
  (`pointer-events: none` у позиционера и всего содержимого): наведение и нажатие в её
  области достаются элементу под ней. Уход указателя с триггера закрывает её сразу —
  ждать перехода на подсказку незачем.
- **Наводима только подсказка обрезанного текста** — `Tooltip` с `overflowOnly`
  (ADR 0083) и тултип ячейки (ADR 0075): закрытие с паузой 150 мс, указатель на
  подсказке держит её открытой (W8).
- `Escape`, потеря фокуса, нажатие на триггер закрывают любую подсказку, как прежде.
- Попап `TooltipImpl` получил флаг `interactive` (по умолчанию выключен); внутренний,
  публичный API не меняется.

### Отступление от WCAG 1.4.13

Для подсказок без обрезки критерий «Hoverable» осознанно не выполняется: указатель,
перешедший на подсказку, её закрывает. Текст таких подсказок доступен и без наведения
на них: он — доступное имя или описание триггера (`aria-label`,
`aria-describedby`) и показывается при фокусе с клавиатуры.

| ID  | Требование                                                                                                                                 | Вид        |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |

| TP2 | Указатель, перешедший с триггера на подсказку без `overflowOnly`, её закрывает, а наведение достаётся элементу под ней                     | визуальный |

## Последствия

- **+** Подсказки не мешают курсору: соседние кнопки строк и заголовков доступны сразу.
- **−** Текст подсказки без обрезки нельзя выделить мышью; WCAG 1.4.13 «Hoverable» для
  них не выполняется (см. выше).
