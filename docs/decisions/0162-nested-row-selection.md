# 0162 — Выбор вложенных строк: каскад и «только строка», в дереве SSRM

- **Статус:** Принято (решения — по итогам прожарки 2026-10-29)
- **Дата:** 2026-10-29
- **Изменяет:**
  - [ADR 0138](0138-server-side-row-model.md) §14 и SD45 — в дереве SSRM флажки не только у
    корней.
  - [ADR 0014](0014-row-selection.md) — аргумент `subRows` получает значение `'self'`: флажки
    у вложенных строк без каскада.
- **Связано:**
  - [ADR 0148](0148-group-selection-in-ssrm.md) — дерево переключений поверх «всё, кроме» для
    групп; узлы веток устроены так же.
  - [ADR 0120](0120-model-and-interface-plugins.md) — срез выбора аргументами
    `rowSelectionModel`.
  - [ADR 0157](0157-ssrm-row-transactions.md), [ADR 0159](0159-ssrm-row-dragging.md) —
    транзакции и перенос строк.

## Контекст

`rowSelection({ subRows: true })` даёт флажки у вложенных строк и каскад «родитель ↔
потомки» — поведение TanStack (`enableSubRowSelection`). В дереве SSRM флажки только у корней
(SD45): каскад по незагруженным потомкам не выразить списком `id`. Выбрать строки дерева по
одной, не трогая их детей, нельзя ни в одном режиме.

### Как у других

- **AG Grid SSRM** с деревом данных — `groupSelects: 'self' | 'descendants'`; состояние —
  дерево `toggledNodes` (`getServerSideSelectionState`), как у групп.
- **MUI X** — `rowSelectionPropagation` (потомки и родители) только по загруженным строкам.

## Решение

### 1. Аргумент `subRows`

`subRows?: boolean | 'self'` у `rowSelection` и `rowSelectionModel`:

- `true` — флажки у вложенных строк и каскад, как сейчас;
- `'self'` — флажки у вложенных строк, каждая выбирается сама: выбор строки не трогает
  потомков и предков, флажок родителя — без третьего состояния;
- без `subRows` — флажки только у корней.

Работает в клиентском режиме и в SSRM.

### 2. Каскад в SSRM

Выбор родителя выбирает всё поддерево, в том числе незагруженное; строки, пришедшие позже,
выглядят выбранными. Флажок родителя — в трёх состояниях (`aria-checked="mixed"` при
частичном выборе). Срез получает узлы веток по образцу узлов групп ADR 0148:

```ts
interface RowSelectionAll {
  all: boolean
  except: string[]
  groups?: RowSelectionGroup[]
  branches?: RowSelectionBranch[]
}
interface RowSelectionBranch {
  /** Строка-родитель ветки. */
  id: string
  /** Ветка выбрана целиком, кроме `except` и узлов `branches` внутри неё. */
  all: boolean
  except: string[]
  branches?: RowSelectionBranch[]
}
```

Узел ветки есть, только если её состояние отличается от родителя; совпавший узел без
исключений и подузлов удаляется. «Выбрать всё» ставит `all: true` и сбрасывает узлы; снятие —
пустой выбор. Без `subRows` срез прежний. `groups` и `branches` вместе не встречаются:
серверная группировка и дерево данных не совмещаются (осознанное ограничение).

### 3. «Только строка» в SSRM

Флажки у всех строк, выбор независим; срез — `id` или `{ all, except }`, как сейчас.

### 4. Как у групп

Счётчик — точный при известных размерах веток, иначе приблизительный, до короткого блока.
Сортировка, фильтр и поиск выбор не сбрасывают; серверная выгрузка получает срез с узлами
веток. `Space` на любой строке переключает её выбор, `aria-selected` — у строк. Транзакции и
перенос строк: выбор следует за `id`, удалённые строки выпадают из узлов.

## Границы

- **Выбор предков по выбранным потомкам** («все дети выбраны — родитель выбран»,
  `rowSelectionPropagation.parents` в MUI X) — нет; родитель показывает третье состояние.
- **`canSelectRow`** для незагруженных строк выбранной ветки не вызывается — запрет проверяет
  сервер, как у групп (ADR 0148).

## Отвергнутые альтернативы

- **Только каскад.** Нельзя отметить строку дерева, не выбрав её детей.
- **Только «сама строка».** Нельзя выбрать ветку с незагруженными потомками.
- **Новый аргумент вместо значения `subRows`.** Два аргумента об одном.

## Последствия

- **Публичный API:** `subRows` принимает `'self'`; `RowSelectionValue` — необязательное поле
  `branches`, тип `RowSelectionBranch`.
- SD45 и тест флажков только у корней меняют ожидания.
