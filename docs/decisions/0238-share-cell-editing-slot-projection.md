# 0238 — Общая проекция ячейки для слотов правки

- **Статус:** Отклонено. Исходные подписки слотов восстановлены.
- **Дата:** 2026-11-25
- **Слой:** плагин `cellEditing` — общая проекция ячейки для слотов правки; ядро — канал подписок на черновики.
- **Связано:** [ADR 0170](0170-body-contribution-channel.md), [ADR 0195](0195-node-subscriptions-by-declared-slices.md), [ADR 0234](0234-filter-tree-and-optional-acceleration.md).

## Контекст

Кнопка правки и владелец содержимого независимо подписывались на сессию.
Они и отметка черновика добавляли отдельные подписки на черновики. При
отборе с новым окном эти подписки создаются для вновь видимых ячеек.

На реальном FL35 при Chromium ×4 выполнено по восемь прогретых переходов
на набор и вариант. Время по React Profiler включает смонтированные ячейки.
Число подписок относится к вызовам подписки на атомы за переход.

| Метрика                                                  | Поиск с правкой, база → прототип | Все плагины, база → прототип |
| -------------------------------------------------------- | -------------------------------: | ---------------------------: |
| Новые ячейки                                             |                          70 → 70 |                    100 → 100 |
| Рендер новых ячеек, мс                                   |                      37,4 → 30,3 |                  87,8 → 72,7 |
| Самая длинная задача, мс                                 |                        232 → 190 |                    328 → 274 |
| До кадра, мс                                             |                        282 → 241 |                    402 → 344 |
| Подписки на атом сессии                                  |                          140 → 1 |                      120 → 1 |
| Подписки на атом черновиков, включая прочих потребителей |                         220 → 11 |                     200 → 21 |

Сырые замеры и сводка — `performance-results/edit-projection-summary.json`
и два файла `edit-projection-base.json` / `edit-projection-variant.json`.
Наборы прогнаны отдельно. Числа описывают этот стенд с инструментализацией.

## Решение

Восстановить гранулярные подписки в компонентах слотов. Кнопка правки,
владелец содержимого и отметка черновика читают нужные им части сессии
и черновика своей ячейки. Те же компоненты работают вне `BodyCell`.

В полном A/B подписка `BodyCell` на общую проекцию увеличила максимальную
задачу AO17 с 80,6 до 113,5 мс, а LM11 при отложенной отмене 5000 ячеек —
с 74,6 до 106,7 мс. При изоляции ADR на рабочей копии AO17 составил
105–112 мс с общей проекцией и около 76 мс с исходными подписками.
Для LM11 получено 93–100 и около 75 мс соответственно. Вынесение
проекции в отдельный узел слотов дало 120–124 мс в AO17.

## Требования

| ID   | Требование                                                          | Проверка  |
| ---- | ------------------------------------------------------------------- | --------- |
| EPJ1 | Слоты правки одной ячейки читают общую проекцию сессии и черновика. | отклонено |

Поведение правки сохраняют существующие сценарии CE1–CE6, AS2–AS6, ED5,
ED21, RX16 и проверки черновиков. В них видимость кнопки, редактора,
ожидания и отметок проверяется по существующим контрактам DOM.

## Последствия

Цена монтирования слотов возвращается к исходному уровню. Пакетный
отказ и отложенная отмена используют исходную гранулярность обновлений.
