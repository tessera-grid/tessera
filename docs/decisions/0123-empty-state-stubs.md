# 0123 — Заглушки пустой таблицы: реестр причин

- **Статус:** Принято (реализовано 2026-10-17; решения — по итогам прожарки 2026-10-17)
- **Дата:** 2026-10-17
- **Связано:**
  - [ADR 0045](0045-filtering.md) — заглушка пустого результата фильтра (FL27–FL28, FL41);
    **изменяется** здесь: `filterStub` заменяет `stubs.filtered`, запись `filtered` — у
    моделей фильтрации и поиска.
  - [ADR 0096](0096-load-error.md) — заглушка ошибки первой загрузки (LE8); **изменяется**
    здесь: `errorStub` заменяет `stubs.loadError`.
  - [ADR 0093](0093-visual-state-catalog.md) — каталог состояний: `body.empty` переезжает
    в `Core/Stubs — Default`.
  - [ADR 0035](0035-toolbar-and-column-visibility.md) — CV9 (последнюю видимую колонку
    скрыть нельзя) не меняется; «Показать все» (CV11).
  - [ADR 0060](0060-initial-loading-skeleton.md), [ADR 0122](0122-toolbar-before-data.md)
    — скелет первой загрузки и тулбар до данных главнее любой заглушки.
  - [ADR 0118](0118-column-footer.md) — §3: место заглушек над закреплённым футером и под
    незакреплённым.
  - [ADR 0010](0010-invert-core-plugins-registry.md), [ADR 0028](0028-define-plugin-authoring-api.md)
    — запись плагина и `definePlugin`: новое поле `stubs`.
  - [ADR 0017](0017-ui-components.md) — UI-кит: новый примитив `Stub`.
  - [ADR 0117](0117-story-controls.md) — истории по сценариям, `Default` — песочница фичи.

## Контекст

Что показать вместо строк, грид решает цепочкой условий в `DataGrid.tsx`: `noData`,
`filtered`, `loadError` — и три пропа на три случая: `stub` (узел приложения, своей
заглушки у библиотеки нет — без пропа видна пустая таблица), `filterStub` и `errorStub`.
Новая причина — новое условие и новый проп в ядре.

Причины не покрыты все. После загрузки без колонок (`columns: []` — сервер прислал данные,
а колонки нет) грид рисует пустую шапку и строки без ячеек, axe находит нарушение. Если
приложение скрыло все колонки своим состоянием `columnVisibility` (через меню это нельзя,
CV9), — то же самое, а вернуть колонки нечем, кроме меню «Колонки».

Иллюстрация пустой таблицы (`assets/404.svg`) есть только в обвязке историй
(`NoDataStub` в `_shims`).

### Как это сделано у других

- **MUI X** — слот на причину: `noRowsOverlay`, `noResultsOverlay` (фильтр ничего не
  нашёл), `noColumnsOverlay` (нет видимых колонок, с кнопкой «Manage columns»), тексты —
  ключи `localeText`; какую заглушку показать, грид решает сам.
- **AG Grid** — `noRowsOverlayComponent` и `localeText.noRowsToShow`; состояния «нет
  колонок» нет.
- **TanStack Table** — не решает: заглушки делает приложение.

## Решение

### 1. Реестр причин

Заглушка — запись реестра:

```ts
interface StubEntry {
  id: string // 'noData', 'noColumns', … — имя причины
  priority: number // меньше — главнее
  when: (table) => boolean // причина выполняется сейчас
  title: (labels) => string // из localization
  description?: (labels) => string
  illustration?: boolean // общая иллюстрация `icons.emptyState`
  action?: { label: (labels) => string; run: (table) => void }
  placement: 'grid' | 'body' // вместо таблицы или под шапкой
}
```

Грид берёт первую по приоритету запись, у которой выполнено `when`, и рисует её; без
подходящей — тело как есть. Условий по причинам вне реестра в коде грида нет: новая
причина — новая запись, а не новая ветка.

Заглушка `grid` встаёт на место контейнера таблицы в том же дереве грида: тулбар и нижняя
панель при переходе «заглушка ↔ таблица» не перемонтируются — поле поиска не теряет
ввод, кнопки не держат пропсы момента монтирования.

Записи ядра — `loadError`, `noColumns`, `noData`. Записи плагинов — по присутствию плагина
(ADR 0010): `filtered` — у `columnFilteringModel` и `quickSearchModel` (одна запись,
дедупликация по `id`), `columnsHidden` — у `columnVisibility`. Автор своего плагина
добавляет запись полем `stubs` в `definePlugin`.

Порядок встроенных:

| Приоритет | Причина         | Когда                                                 | Где    | Действие          |
| --------- | --------------- | ----------------------------------------------------- | ------ | ----------------- |
| —         | скелет          | `isSkeletonShown` (ADR 0060) — главнее любой заглушки | —      | —                 |
| 10        | `loadError`     | отказ загрузки без строк (ADR 0096)                   | `body` | «Retry»           |
| 20        | `columnsHidden` | колонки данных есть, видимых нет                      | `grid` | «Show all» (CV11) |
| 30        | `noColumns`     | видимых колонок данных нет (в т. ч. `columns: []`)    | `grid` | —                 |
| 40        | `filtered`      | строк нет при активном фильтре или поиске (ADR 0045)  | `body` | «Reset filters»   |
| 50        | `noData`        | строк нет                                             | `grid` | —                 |

`columnsHidden` главнее `noColumns`: с плагином «Колонки» пользователю есть чем вернуть
колонки; без плагина та же ситуация — `noColumns`.

### 2. Тексты и иллюстрация

Тексты — только из `localization`: новые ключи `noData` («No data», ключ уже был — объявление пустого результата),
`noColumnsTitle` («No columns»), `columnsHiddenTitle` («All columns are hidden»);
действия — существующие `showAllColumns`, `resetFilters`, повтор загрузки. Иллюстрация —
одна общая, `icons.emptyState`: по умолчанию `404.svg`, перенесённый в библиотеку, в
цветах темы; переопределяется через `icons`. Иллюстрации на каждую причину — позже.
Появление заглушки объявляется скринридеру её заголовком (вместо общего объявления
пустого результата).

### 3. Проп `stubs`

```tsx
<DataGrid
  table={table}
  stubs={{
    noData: <MyEmpty />,
    noColumns: ({ action }) => <MyNoColumns />,
  }}
/>
```

Ключ — `id` записи (встроенной или записи плагина), значение — `ReactNode` или функция от
`{ action }` (действие записи, если есть; у `loadError` ещё `{ error }`). Проп меняет вид
заглушки, но не выбор причины. Пропы `stub`, `filterStub`, `errorStub` удаляются.

### 4. Тулбар без видимых колонок

После загрузки, когда видимых колонок данных нет:

- поиск и «Экспорт» выключены — им не на что опереться;
- «Фильтры» доступны, пока есть активные фильтры: фильтр скрытой колонки остаётся активным
  (FL13), его нужно уметь снять;
- «Колонки» доступна, если колонки есть (скрыты), и выключена, если их нет совсем.

Во время первой загрузки — скелеты по ADR 0122.

### 5. Примитив `Stub`

Новый публичный примитив UI-кита `Stub` (`src/lib/ui/Stub`, экспорт из `/ui`): иллюстрация,
заголовок, описание, действие (`Button` кита); вид — только из токенов. Встроенные
заглушки рисуются им; приложение может собрать им свою заглушку для `stubs`.

## Отвергнутые альтернативы

- **Одна таблица причин в ядре.** Ядро знало бы про фильтры и видимость колонок; запись у
  плагина пропадает вместе с ним (ADR 0010).
- **Пропы на каждую причину** (`stub`, `filterStub`, `errorStub`, `noColumnsStub`, …) —
  новый проп на каждую причину; плагин свою причину добавить не может.
- **Снять CV9** — скрыть последнюю колонку через меню. Пользователь получал бы пустую
  таблицу по ошибке; приложение по-прежнему может скрыть всё своим состоянием.
- **Выключить «Фильтры» без колонок.** Фильтры скрытых колонок нельзя было бы снять.
- **`stubs` выбирает и причину.** Выбор — по состоянию таблицы; приложение меняет вид, а
  не порядок.

## Границы

- Иллюстрации на каждую причину — позже, пока одна общая.
- Заглушки строк внутри тела (ленивые дети, хвост ленты) — не заглушки пустой таблицы,
  не меняются.

## Последствия

- **Ломающие изменения публичного API:** удалены пропы `stub`, `filterStub`, `errorStub` —
  вместо них `stubs`; без `stubs` при пустых данных теперь заглушка библиотеки, а не пустая
  таблица. Отмечается в `CHANGELOG.md`.
- **Контракт плагина:** поле `stubs` в `TesseraFeatureEntry` и `definePlugin`; аугментация
  типов — id причин расширяемы.
- **ADR 0045, 0096, 0093** — правки отмечены в их заголовках.
- **Документация:** `docs/architecture/rendering.md` (заглушки), `plugins-and-slots.md`
  (поле `stubs`), roadmap — иллюстрации на причину.
- **Перф (TQ6)** неприменим: реестр — несколько дешёвых условий на рендер грида, а не
  массовое состояние.
