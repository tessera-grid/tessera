# 0085 — Немодальные меню грида

## Контекст

Меню грида — кебабы заголовка и строки, инлайн-меню заголовка, контекстное меню и меню
ручек — построены на `Menu` Base UI. По умолчанию оно модальное: под меню ложится
подложка на всю страницу с вырезом под кнопку-триггер, прокрутка страницы
блокируется. Нажатие мимо меню попадает в подложку — меню закрывается, и больше
ничего не происходит.

Поповеры грида — «Колонки», панели фильтров, сводка фильтров, панель действия
заголовка — на `Popover` Base UI, и они немодальные: это его умолчание. Поведение
всплывающих элементов в одном гриде разное: нажатие мимо панели «Колонки» доходит до
ячейки, нажатие мимо кебаба — нет.

Модальная подложка ломает меню в Firefox (ADR 0084). Base UI строит вырез в подложке
по `getBoundingClientRect()` триггера во время своего рендера. Firefox после частичной
перекладки отдаёт для кебаба в закреплённой справа ячейке (`position: sticky`)
незакреплённое положение (`x = 3104` вместо 344). Вырез уходит мимо, отпускание кнопки
мыши после открытия по нажатию попадает на подложку — и меню закрывается. Своего пути
поправить замер у Tessera нет: он внутри рендера Base UI, а открыть меню по клику
вместо нажатия Base UI не умеет.

### Как это сделано у других

- **AG Grid.** Меню колонки и контекстное меню немодальные: нажатие мимо закрывает меню
  и доходит до грида.
- **MUI X.** Меню колонки — `Popper` с `ClickAwayListener`, без подложки: клик мимо
  закрывает меню и срабатывает на своём месте.
- **Google Sheets.** Контекстное меню немодальное: клик по ячейке закрывает меню и
  выбирает ячейку.
- **Модальны** нативные меню ОС и `Menu` MUI Material — не гриды.
- **Прокрутка при открытом меню** у AG Grid и MUI X в документации не описана;
  Syncfusion закрывает контекстное меню при прокрутке, в сообществе Handsontable
  закрытие при прокрутке предлагают как исправление «застрявших» меню.

## Решение

### 1. Все меню грида немодальные

Четыре вида меню получают `modal={false}`: подложки нет, прокрутка страницы не
блокируется. Опции вернуть модальность нет — её нет у AG Grid и MUI X, а модальность и
есть источник ошибки Firefox; при нужде опция добавляется позже без поломок.

### 2. Нажатие мимо закрывает меню и доходит до цели

Одно нажатие мимо открытого меню закрывает его и срабатывает там, куда пришлось:
выбирает строку, делает ячейку активной, открывает другое меню. Так же уже ведут себя поповеры грида.

### 3. Прокрутка грида пользователем закрывает меню

Колесо или касание над гридом закрывают открытое меню: меню не висит над уехавшей
строкой и не прыгает за ней. Прокрутка, которую делает сам грид (клавиатурная
навигация, фокус ячейки), меню не закрывает — как ожидание контекстного меню (ADR 0061)
отменяет только прокрутка пользователем. Прокрутка страницы вне грида меню не
закрывает: позиционер Base UI ведёт его за своей кнопкой.

### 4. Клавиатура без изменений

`Escape` закрывает меню и возвращает фокус на триггер, стрелки и `Tab` внутри меню,
разделы (ADR 0079) работают как раньше. Если пользователь ушёл сам — нажал мимо,
увёл фокус, прокрутил грид, — фокус на триггер не возвращается: возврат посреди нажатия
мимо сорвал бы это нажатие (с `keyboardNavigation` — активной ячейкой), а после
прокрутки — прокрутил бы грид назад к кнопке.

Фокус возвращается в конце анимации закрытия. Если за это время пользователь нажал
другой триггер — кебаб другой строки, правый клик по ячейке, — фокус уже у него или у
его меню и остаётся там: возврат на прежний триггер увёл бы фокус из нового меню, и
оно закрылось бы как покинутое (в Firefox — чаще, в Chromium оставалось открытым без
фокуса). Base UI сам не возвращает фокус, ушедший к другому элементу, но только при
`finalFocus` по умолчанию; меню грида задают его функцией (возврат только без ухода), и
ту же проверку делает она: фокус внутри закрывающегося меню или потерян.

Так же ведут себя поповеры, которые закрывает их собственная кнопка: панель выгрузки после
запуска и панель действия заголовка через `close` (MM7). Они возвращают фокус на кнопку,
открывшую их, тоже явным `finalFocus` — с той же проверкой. «Колонки» и сводка фильтров
сами себя с анимацией не закрывают (`Escape` убирает их сразу, а после сброса всех
фильтров кнопка сводки выключена), и нажатие мимо фокус у новой цели не забирает.

### 5. Геометрия закреплённых ячеек в Firefox

Подложка — не единственная причина закрытия. Firefox пересчитывает положение
`sticky`-ячейки на главном потоке только при прокрутке; после любой перекладки внутри
ячейки `getBoundingClientRect()` и попадание указателя видят её на незакреплённом месте
(рисует её компоновщик верно — на экране сбоя нет). Немодальное меню Base UI тоже
сверяет отпускание кнопки с прямоугольником триггера и закрывается с причиной
`cancel-open`. Грид перед нажатием, отпусканием и `Enter`/`Space` над собой сдвигает
прокрутку на пиксель и обратно (`core/stickyGeometry.ts`) — положение пересчитывается
сразу, перерисовки и событий для приложения нет. Перф взаимодействия (I1–I6) в бюджете.

## Границы

- Поповеры грида остаются как есть — они уже немодальные; меняется только возврат
  фокуса у закрытых своей кнопкой (§4, MM7).
- Меню вне грида (выбор размера страницы — `Select` Base UI) не меняются.

## Отвергнутые альтернативы

- **Только кебабы немодальные.** Ошибка Firefox видна на кебабе закреплённой колонки,
  но подложка с вырезом у всех меню одна; поведение грида осталось бы разным.
- **Немодально, но первое нажатие мимо только закрывает меню** (свой перехват). Ведёт
  себя как сейчас, но поповеры остаются другими, и перехват нажатий — своя механика
  поверх Base UI.
- **Меню едет за кнопкой при прокрутке**, закрываясь, когда кнопка уходит из виду. Для
  контекстного меню (у точки) не подходит; два поведения вместо одного.
- **Опция `modalMenus`.** Не нужна сейчас (§1).

## Последствия

- **+** Меню не закрывается отпусканием кнопки в Firefox (MI24, NM19, MI9).
- **+** Меню и поповеры грида ведут себя одинаково; так же, как у AG Grid и MUI X.
- **+** Другое меню открывается одним нажатием, без лишнего клика на закрытие.
- **−** Смена поведения: нажатие мимо открытого меню теперь срабатывает (выбирает
  ячейку, сортирует). Публичный API не меняется.
- **−** Прокрутка страницы при открытом меню больше не блокируется.
