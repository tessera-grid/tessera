## Контекст

Экспорт — частый enterprise-запрос. Часть механики есть: сериализация TSV/HTML для
копирования ([`core/clipboard.ts`](../../src/lib/core/clipboard.ts)) и место для кнопки
([ADR 0035](0035-toolbar-and-column-visibility.md) заранее называл экспорт кандидатом
на `toolbarSlot`).

**Как это решают другие** (документация на 2026-10-02):

| Грид                | Охват строк                                                                                  | Колонки                                                    | Запуск                                                          |
| ------------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | --------------------------------------------------------------- |
| AG Grid             | `exportedRows: 'all' \| 'filteredAndSorted'`, `onlySelected`, `onlySelectedAllPages`         | видимые, `allColumns`, `columnKeys`                        | API; меню — только Enterprise; серверная модель — не из коробки |
| MUI X Data Grid     | выбранные, если есть, иначе отфильтрованные и отсортированные; `getRowsToExport`             | видимые, `allColumns`, `fields`, `disableExport` у колонки | меню в тулбаре; формулы экранируются по умолчанию               |
| Tabulator           | `rowRange`: `visible`, `active`, `selected`, `all`                                           | видимые, `download` у колонки                              | `table.download(type, filename, options, rowRange)`             |
| Mantine React Table | четыре кнопки: все данные, все строки (с фильтром и сортировкой), строки страницы, выбранные | видимые                                                    | кнопки в тулбаре, сам экспорт не встроен                        |
| Handsontable        | сырые данные, `range`                                                                        | `exportHiddenRows/Columns`                                 | API; `sanitizeValues` для формул                                |

Общее: охват строк — отдельный параметр с устойчивым набором значений (все данные,
с учётом сортировки и фильтров, страница, выбранные); результат задаётся **явной
настройкой**, а не молчаливым выводом из экрана; у большинства есть программный вызов
с параметрами. С данными на сервере ни один грид не справляется сам: выгружается то,
что загружено, либо разработчик пишет свой обработчик.

Два фактора определяют форму решения:

1. **Данные грида — не всегда все данные.** При серверной пагинации клиент видит одну
   страницу; выгрузить «всё» может только сервер.
2. **Excel (`.xlsx`) требует зависимости** (SheetJS/ExcelJS) либо ручной сборки OOXML.
   Новая зависимость — решение автора ([AGENTS.md §6](../../AGENTS.md)).

## Решение

### 1. Плагин `dataExport` (EX1–EX2)

Presence-based плагин `dataExport()` на `definePlugin`, без сервисной колонки.
Контрибьютит кнопку «Экспорт» в `toolbarSlot` (группа `data`, иконка `download`) и
метод таблицы `table.exportData(...)`. Подключение плагина не тянет в сборку другие
плагины: это для каждого экспорта `/plugins` проверяет `npm run check:tree-shaking`
(IV3, [ADR 0010](0010-invert-core-plugins-registry.md)).

```ts
dataExport({
  enabled?: boolean,
  formats?: ExportFormat[],                       // по умолчанию [csv]
  allow?: { rows?: ExportRows[]; columns?: ExportColumns[]; formats?: string[] },
  presets?: ExportPreset[],                       // быстрые наборы настроек
  filename?: string | ((settings: ExportSettings, format: ExportFormat) => string), // 'export'
  formatValue?: (ctx: ExportValueContext) => unknown,
  server?: boolean,                               // полного набора строк на клиенте нет
  onExport?: (request: ExportRequest) => void | Promise<void>,   // выгрузку делает потребитель
  onExported?: (request: ExportRequest) => void,                 // файл скачан клиентом
})
```

**Без тулбара нет только кнопки** ([ADR 0046](0046-toolbar-and-status-bar-visibility.md), PB8):
при `enableToolbar: false` плагин активен, `table.exportData()` работает. Исходное
решение (плагин инертен с `'noToolbar'`) отменено.

### 2. Настройки выгрузки — три независимые оси (EX3–EX5)

Выгрузка задаётся **настройками** `ExportSettings`, по одному значению в каждой оси;
результат определён ими, а не экраном:

```ts
interface ExportSettings {
  rows: 'all' | 'view' | 'page' | 'selected'
  columns: 'visible' | 'all'
  format: string // id формата из formats
}
```

**Ось «Строки» (`rows`):**

| Значение   | Что выгружается                                                                                                    | Нужен плагин                      |
| ---------- | ------------------------------------------------------------------------------------------------------------------ | --------------------------------- |
| `all`      | весь `data` в исходном порядке (вложенные `subRows` — в глубину), без сортировки, страниц и раскрытия              | —                                 |
| `view`     | с учётом сортировки (и фильтрации, когда появится), все страницы, независимо от раскрытия; строки-группы пропущены | `columnSorting` (позже — фильтры) |
| `page`     | строки текущей страницы                                                                                            | `pagination`                      |
| `selected` | выбранные строки всех страниц в порядке `view` (выбор хранится по id строки и переживает смену страницы)           | `rowSelection`                    |

Значение оси присутствует в панели, только если его плагин **активен**
(`getPluginDiagnostics()`: подключён и не инертен); порядок: `all`, `view`, `page`,
`selected`. `all` присутствует всегда.

**Ось «Колонки» (`columns`):** `'visible'` — видимые пользовательские листья в порядке
отображения (закрепление и перестановка учтены), `'all'` — и скрытые. Служебные колонки
(выбор, ручка, раскрытие, действия) не выгружаются никогда. Заголовок группы вложенной
шапки в CSV не пишется: одна строка заголовков — подписи листьев (`columnDef.header`,
если строка, иначе `id`).

**Ось «Формат» (`format`):** из `formats`; по умолчанию один CSV.

**Ограничения разработчика — `allow`** (списки по осям). Значение, которого нет в списке
оси, в панели показано **недоступным** (`disabled`). Без `allow` разрешено всё
присутствующее. Так разработчик серверного режима оставляет только то, что умеет его
бэкенд.

**Начальные значения** — первое доступное значение каждой оси (`rows` в порядке
`all`, `view`, `page`, `selected`; `columns` — `visible`; `format` — первый). Последний выбор пользователя запоминается панелью, пока таблица смонтирована, и подставляется при следующем открытии; если запомненное значение стало недоступно
(например, снят выбор строк) — берётся первое доступное.

**Значения ячеек.** Берётся значение ячейки (`cell.getValue()`), а не её отрисовка
(`renderComponent`/слоты); в `serialize` и `formatValue` приходит значение как задал
разработчик, без преобразований. Приведение к тексту — только внутри CSV (§4).
`formatValue({ value, row, column })` переопределяет значение. Исключение — колонки с
вариантами (`options` / `getOptionLabel`, [ADR 0048](0048-option-filtering.md), SF17):
выгружается подпись, у массива — подписи через «, »; подпись — данные, а не оформление.
`formatValue` получает исходное значение и по-прежнему перекрывает.

### 3. Кнопка и панель (EX6–EX9)

**Кнопка** «Экспорт» (F4). Если после присутствия и `allow` у каждой оси остаётся
**одно доступное значение** — клик сразу выгружает с ним, панель не показывается (так
работает и простейший случай «только все данные в CSV»). Иначе клик открывает
**панель** — поповер (Base UI `Popover`, лениво, как «Колонки»), выровненный по правому
краю кнопки:

- **Быстрые наборы** (если заданы `presets`) — ряд кнопок сверху. Клик по набору
  выставляет заданные в нём оси и **ничего не выгружает**; пользователь может
  дополнить остальное. Без `presets` ряда нет. Набор: `{ id, label, rows?, columns?, format? }`
  — задаёт только перечисленные оси; недоступное значение (нет плагина, не разрешено)
  не выставляется.
- **Оси** — группы переключателей (`radiogroup`, Base UI `RadioGroup`): «Строки»,
  «Колонки», «Формат» (оси «Формат» нет, если формат один). Недоступные значения —
  `disabled`; значения без активного плагина не показываются. «Выбранные строки»
  недоступны, пока ничего не выбрано.
- **«Выгрузить»** — выполняет выгрузку с текущими настройками и закрывает панель.
- `Escape` закрывает панель и возвращает фокус на кнопку; `Tab` ходит по группам и
  кнопкам.

Подписи значений — из локализации; подпись `view` называет то, что учитывается:
«С учётом сортировки», «С учётом фильтров», «С учётом сортировки и фильтров»
(`exportView(features)`).

### 4. Формат CSV (EX19–EX22)

CSV по RFC 4180: разделитель `,`, перевод строки `CRLF`, поле с `,` `"` CR LF
заворачивается в кавычки с удвоением внутренних. Первая строка — заголовки. UTF-8
**с BOM** по умолчанию (`bom`: Excel иначе читает кириллицу в ANSI).
Приведение значения к тексту: `null`/`undefined` → пусто, `Date` → ISO-8601,
`boolean` → `true`/`false`, объект/массив → `JSON.stringify`, остальное — `String`.

**Защита от формул (CSV injection).** Excel, Google Sheets и LibreOffice выполняют поле,
начинающееся с `=`, `+`, `-`, `@`, как формулу; чужой ввод в данных так может утечь
соседние ячейки. Текстовое поле, начинающееся с этих символов, `\t` или `\r`, получает
префикс `'`. Числа и даты не трогаются. **Защита включена по умолчанию; отключить её —
`sanitizeFormulas: false` у формата — выбор и ответственность разработчика.**

### 5. Форматы и скачивание (EX23–EX25)

```ts
interface ExportFormat {
  id: string
  label: string
  extension: string // без точки
  mimeType: string
  serialize: (data: ExportData) => string | Uint8Array | Blob
}
interface ExportData {
  columns: { id: string; header: string }[]
  rows: unknown[][]
}
```

Встроенный — только `csv` (`exportFormats.csv({ bom?, sanitizeFormulas? })`). **Excel не
входит в этот ADR:** свой генератор `exportFormats.xlsx()` без зависимостей —
[ADR 0073](0073-xlsx-export.md).

Скачивание: `Blob` + временная ссылка `<a download>`, имя — `filename` + `.extension`;
`URL.revokeObjectURL` после клика. После скачивания вызывается `onExported`.

### 6. Серверный режим (EX26–EX29)

`server: true` — договор на время жизни таблицы
([ADR 0039](0039-reactive-plugin-arguments.md)); режим выбирает разработчик, интерфейс
панели одинаковый, различается место выполнения. Выгрузка выполняется там, где есть
данные:

| Значение оси «Строки»     | Где    | Что происходит                                                                                              |
| ------------------------- | ------ | ----------------------------------------------------------------------------------------------------------- |
| `page`                    | клиент | `data` — это и есть текущая страница в порядке сервера; файл скачивается, затем `onExported`                |
| `all`, `view`, `selected` | сервер | клиент ничего не скачивает и вызывает `onExport(request)`; для `selected` в запросе `rowIds` всех выбранных |

`ExportRequest` = `{ settings, format, columns, rowIds?, rowCount?, filename? }` — в
`onExport` выбранные настройки и колонки, в `onExported` ещё `rowCount` и `filename`.
Допустимые разработчиком значения (`allow`) задают, что умеет его сервер. Пока промис от
`onExport` не завершён, кнопка `aria-busy`, а «Выгрузить» с серверным значением строк
заблокирована (локальный `page` доступен). Отказ промиса снимает занятость и пишется в
`logError`. Если ни одно значение строк не выполняется на клиенте, а `onExport` не задан,
выгрузка бесполезна: `diagnose` → `'noOnExport'`.

### 7. Программный вызов (EX30)

`table.exportData(arg?)` запускает тот же путь, что «Выгрузить», без кнопки тулбара: для
собственных кнопок потребителя.

- `arg` — объект `Partial<ExportSettings>`: недостающие оси берутся по умолчанию (§2);
- `arg` — строка: id быстрого набора;
- без `arg` — настройки по умолчанию.

Возвращает промис, завершающийся с `onExport` (для клиентской выгрузки — сразу).
Недоступное значение (нет плагина, не разрешено, `selected` без выбора) или неизвестный
набор — `logError`, ничего не выгружается. Запомненный выбор панели вызов не меняет.
Метод доступен и без тулбара (инертна только кнопка).

### 8. Доступность и локализация (EX31–EX32)

Кнопка — F4: подпись — доступное имя и тултип; панель — `role="dialog"` с именем из
локализации; оси — `radiogroup` с подписью. Ключи локализации: `export` («Export»),
`exportRows` («Rows»), `exportColumns` («Columns»), `exportFormat` («Format»),
`exportPresets` («Quick sets»), `exportRun` («Export»), значения оси «Строки» —
`exportAll` («All rows»), `exportView(features)` («With sorting», «With sorting and
filters»), `exportPage` («Current page»), `exportSelected` («Selected rows»), оси
«Колонки» — `exportColumnsVisible` («Visible columns»), `exportColumnsAll` («All
columns»). Иконка: `download`. Кнопка и панель проходят axe с `color-contrast` в обеих
темах.

## Границы

- **Excel/`.xlsx`, PDF** — отдельным `ExportFormat`/ADR; зависимость — по решению автора.
- **Выбор колонок списком** и `disableExport` у колонки — позже, по потребности.
- **Выгрузка выделенного диапазона ячеек** — это копирование ([ADR 0029](0029-cell-range-selection.md)).
- **Стриминг больших выгрузок** (чанки, Worker) — пока синхронная сериализация в
  клике; потолок фиксирует EX33.
- **Стили и форматирование ячеек** — вне CSV.
- **Фильтрация** ([ADR 0045](0045-filtering.md), FL25): `view` учитывает фильтры и
  поиск, `selected` выгружает и выбранные строки, скрытые фильтром.
- **Выгрузка нескольких файлов за раз** — не входит: одна настройка — один файл.

## Последствия

- **+** Результат выгрузки задан настройками, а не скрыт в состоянии экрана.
- **+** Пользователь сам собирает комбинацию (строки × колонки × формат), разработчику
  не нужно перечислять их вручную.
- **+** Один интерфейс для клиента и сервера; разработчик ограничивает допустимое.
- **+** Дешёвый старт: CSV на чистых функциях, новых зависимостей нет.
- **−** Синхронная сериализация блокирует главный поток на больших таблицах (EX33).
- **−** Расширение публичного API: плагин, `table.exportData`, `ExportSettings`,
  `ExportPreset`, `ExportFormat`, ключи локализации и иконка; новый поповер.
