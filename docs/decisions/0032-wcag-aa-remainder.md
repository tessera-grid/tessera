# 0032 — Доступность: остаток до WCAG 2.1 AA

- **Статус:** Принято (W1–W17 реализованы; открыта только ручная проверка
  скринридерами)
- **Дата:** 2026-09-26
- **Связано:**
  - [ADR 0020](0020-accessibility.md) — структурная доступность (роли, имена,
    индексы, axe); этот ADR продолжает его список `A<n>`.
  - [ADR 0031](0031-wcag-keyboard.md) — WCAG 2.1.1 (клавиатура) закрыт с
    `keyboardNavigation`.
  - [ADR 0029](0029-cell-range-selection.md) — выделение диапазона ячеек;
    [ADR 0004](0004-core-on-tanstack-table.md) — загрузка и скелетоны.
  - [ADR 0009](0009-test-coverage-visual-and-performance.md) — один тест на
    требование; префикс требований этого ADR — `W<n>`.
  - [ADR 0034](0034-wcag-22-dragging-and-target-size.md) — продолжение до
    WCAG 2.2 AA: альтернатива перетаскиванию (2.5.7) и размер целей (2.5.8).

## Контекст

После ADR 0031 аудит по WCAG 2.1 (A и AA) выявил пробелы вне клавиатуры. Часть из
них — точечные ошибки семантики, которые правятся без проектных решений:

- **Поле редактора** `cellEditing` имело захардкоженную английскую подпись
  `"edit cell value"` мимо `localization` и без имени колонки (2.4.6, 3.1.2;
  нарушение контракта переопределения подписей).
- **Индикатор загрузки** `role="progressbar"` без доступного имени, а грид при
  загрузке не сообщал о занятости (4.1.2).
- **Скелет первой загрузки** рендерился как `role="table"` без строк и ячеек —
  скринридер зачитывал пустую «вторую таблицу» (1.3.1, 4.1.2).
- **Выделенные ячейки** `cellSelection` были отмечены только `data-`атрибутом и
  цветом (1.3.1, 4.1.2, 1.4.1).

Остальное (объявления `aria-live`, уровни вложенности, ошибки ввода, смена уровня
вложенности с клавиатуры, контраст и масштабирование) требует решений или
проверки и ведётся отдельно.

## Решение

### W1 — подпись поля редактора

Новый ключ локализации `editCellValue: (column: string) => string` (по умолчанию
`` column => `Edit ${column}` ``). Имя колонки — строковый `columnDef.header`,
иначе `column.id`. Подпись вычисляет `CellEditField` и отдаёт редактору новым
полем `label` аргумента `CellEditor` (аддитивно); встроенный `CellEditInput`
ставит её в `aria-label`.

### W2 — состояние загрузки

`LinearProgress` принимает `label` → `aria-label`; грид передаёт
`localization.loading` (по умолчанию `'Loading'`). Пока индикатор показан, корень
таблицы/грида несёт `aria-busy="true"`.

### W3 — скелет скрыт от вспомогательных технологий

Корень скелета больше не `role="table"`: его визуальные строки и ячейки помечены
`aria-hidden`, а рядом — визуально скрытый `role="status"` с
`localization.loading`. Скринридер слышит «загрузка», а не пустую таблицу.

### W4 — выбранные ячейки

С `keyboardNavigation` (`role="gridcell"`) выбираемая ячейка `cellSelection` несёт
`aria-selected`, отражающий выделение; корень грида — `aria-multiselectable`,
если активен `rowSelection` **или** `cellSelection`. В `role="table"` атрибут не
ставится: у `role="cell"` его нет по ARIA.

### W5–W8 — по результатам проверки (решения автора)

- **W5, чекбокс:** `--tsr-comp-control-border` = `--tsr-sys-fg` 55% (вместо
  `--tsr-sys-border`) — ≥ 3:1 к фону в обеих темах. Токен общий: рамки меню
  действий (`ActionMenu`) тоже стали темнее.
- **W6, контур фокуса:** `--tsr-comp-focus-ring` = сплошной `--tsr-sys-ring`
  (было 40% прозрачности).
- **W7, выделение ячеек:** `--tsr-comp-cell-selected-border-color` = сплошной
  `--tsr-sys-info` (было 55%); фон выделенных ячеек не меняется.
- **W8, подсказка:** уход указателя с триггера закрывает её через 150 мс, а
  указатель на самой подсказке держит её открытой; `Escape` и потеря фокуса
  закрывают, как прежде.

Все три токена — публичные `--tsr-comp-*`: потребитель по-прежнему может их
переопределить, но тогда контраст — его ответственность.

### W9 — канал объявлений (`aria-live`)

Грид держит одну визуально скрытую область `role="status"` (`aria-live="polite"`)
и даёт метод `table.announce(message)` — для плагинов и потребителя. Повтор того
же текста объявляется снова. Ядро само объявляет (подписи — ключи
`localization`, переопределяемы):

- смену сортировки — `announceSort(column, direction)`;
- число выбранных строк — `announceSelection(count)`;
- копирование — `announceCopy(cells)`;
- окончание загрузки — `announceLoaded(rows)`, пустой результат — `noData`.

Опция `useCreateTable({ enableAnnouncements: false })` отключает объявления
ядра; `table.announce` при этом по-прежнему работает.

### W10 — иерархия строк (`treegrid`)

С `keyboardNavigation` и `rowExpanding` или `rowGrouping` корень грида —
`role="treegrid"`; каждая строка тела несёт `aria-level` (глубина + 1),
`aria-setsize` и `aria-posinset` (среди соседей того же родителя в текущей
модели строк). Без плагинов иерархии роль остаётся `grid`; без
`keyboardNavigation` (`role="table"`) атрибуты уровня не ставятся — у строк
таблицы их нет по ARIA.

### W11 — ошибки ввода в редакторе

`cellEditing({ validate(value, ctx) })` возвращает текст ошибки или
`null`/`undefined`. При ошибке коммит не выполняется, редактор остаётся открытым,
поле встроенного редактора несёт `aria-invalid="true"` и `aria-describedby` на
видимый текст ошибки (`role="alert"`). Alert-область есть в DOM всегда, меняется
только её текст: вставку новой области с текстом скринридеры объявляют ненадёжно
([ADR 0033](0033-a11y-tree-and-virtual-screen-reader.md)). Свой редактор получает
поле `error` аргумента `CellEditor`.

### W12 — смена уровня вложенности строки с клавиатуры

Расширяет KB4 ([ADR 0031](0031-wcag-keyboard.md)) и снимает исключение
2.1.1: в `rowDragging` `Alt+Shift+→` вкладывает строку последней подстрокой в
предыдущую соседнюю **группу** (строку с `getCanExpand()`), `Alt+Shift+←`
выносит подстроку на уровень выше сразу после родителя. Правила — как у DnD:
группа в группу не вкладывается; изменение — через `onRowOrderChange`; фокус
следует за строкой.

### W13–W15 — по решениям автора

- **W13, пустые заголовки служебных колонок:** служебная колонка объявляет в
  `columnDef.serviceLabel` ключ `localization` (`expandColumn`,
  `reorderColumn`, `rowActionsColumn`), и `HeadCell` выводит его визуально
  скрытым текстом. Ядро имён плагинов не знает — подпись задаёт плагин-владелец
  колонки. У колонки выбора подписи нет: имя заголовку даёт чекбокс «Select all
  rows», а подпись его дублировала (найдено эмулятором, ADR 0033).
- **W14, футер в навигации:** при `enableFooter` строка футера входит в модель
  навигации сразу после последней строки тела (`↓` с последней строки,
  `Ctrl+End`); ячейки футера — `gridcell` с roving `tabindex`. Как и шапка, футер
  sticky — по вертикали не доводится. Выделение ячеек на футер не
  распространяется.
- **W15, `Escape` в меню заголовка:** закрывает меню и возвращает фокус на
  кнопку-триггер (паттерн APG Menu Button); следующий `Escape` — на ячейку.
  Причина прежнего поведения — перенаправление входа в грид: меню в портале
  размонтировано до возврата фокуса, источник фокуса `null`, и навигация
  принимала это за вход извне. Теперь фокус без источника на триггер
  (`aria-haspopup`) не перенаправляется; вход по `Tab` источник имеет всегда.

### W16, W17 — по находкам эмулятора (решения автора, ADR 0033)

- **W16, фокус на строке `treegrid`** (паттерн APG Treegrid). В `treegrid` у
  строк тела есть второй режим фокуса — **на самой строке** (`columnIndex = -1`),
  тогда скринридер озвучивает уровень, позицию и раскрытие строки:
  - `←` на первой ячейке строки — фокус на строку;
  - на строке: `→` — свёрнутую раскрыть, иначе фокус на первую ячейку; `←` —
    раскрытую свернуть, иначе фокус на родительскую строку; `↑`/`↓` — соседняя
    строка (фокус остаётся на строках); `Home`/`End` — первая / последняя строка;
  - раскрытие идёт тем же путём, что кнопка (с `onExpandRow`): канал
    `keyboardActions` получил флаг `expands`, ядро ищет у строки действие с ним и не
    знает имени плагина;
  - строка — roving-участник навигации (`tabindex`, контур фокуса); вне
    `treegrid`, в шапке и футере режима строки нет.
- **W17, имя заголовка колонки** — только его текст: `columnheader` ссылается
  `aria-labelledby` на блок заголовка, кнопки сортировки/закрепления в имя не
  попадают (они — виджеты режима действия). Служебные колонки — как в W13.

### Открыто

- **Проверка реальными скринридерами** (NVDA / JAWS / VoiceOver) — ручная.

## Последствия

- **+** Подписи и состояния, которые раньше были только визуальными или
  английскими, доступны и локализуемы.
- **−** Аргумент `CellEditor` получил поле `label` — аддитивное изменение
  публичного контракта `cellEditing`; свой редактор должен поставить его в
  доступное имя поля.
- **−** DataGrid возвращает фрагмент: первым идёт визуально скрытая live-область
  (W9), чтобы она переживала переход в заглушку. Абсолютно спозиционирована —
  в раскладку родителя не вмешивается.
- **−** С `keyboardNavigation` и иерархией строк роль корня — `treegrid`, а не
  `grid` (W10); поиск корня по `[role="grid"]` у потребителя должен учесть это.
- **−** Контракт `cellEditing` расширен: опция `validate`, поле `error` аргумента
  `CellEditor` (аддитивно).
