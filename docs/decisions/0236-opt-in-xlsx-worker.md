# 0236 — Опциональный Worker для клиентского XLSX

- **Статус:** Принято.
- **Дата:** 2026-11-25
- **Слой:** плагин `dataExportModel` — параметры XLSX-формата, подготовка данных и упаковка файла в Worker.
- **Связано:** [ADR 0073](0073-xlsx-export.md), [ADR 0234](0234-filter-tree-and-optional-acceleration.md), [ADR 0235](0235-export-and-sort-acceleration.md).

## Контекст

На 126 668 узлах при ×1 передача порциями сократила самую длинную задачу
с 82 до 14 мс, время до файла изменилось с 870 до 950 мс. При ×4 время до
файла сократилось с 4 028 до 1 597 мс. По памяти выигрыш не подтверждён.
Отмена порционного прототипа прерывала сборку. Подготовка индекса поиска
занимала 857–896 мс ради выигрыша около 20 мс на прогретом запросе.
В измеренных сумме и CRC-32 Wasm с копированием оказался медленнее JS.

## Решение

Разрешение задаётся для конкретного XLSX-формата через
`exportFormats.xlsx({ worker: true })`. Значения по умолчанию и
`worker: false` используют штатный генератор в главном потоке.
Отдельный публичный переключатель Wasm появится при принятии конкретного
Wasm-бэкенда. Worker для поиска и проверенные ядра Wasm остаются исследованием.

Встроенный формат лениво создаёт Worker для каждой выгрузки. Строки
передаются порциями с подтверждением получения. Worker вызывает существующий
генератор XLSX, главному потоку остаются доступ к модели, скачивание и хуки.
Отмена завершает Worker. Недоступность Worker и значения, для которых нельзя
гарантировать эквивалентность после передачи, используют штатный генератор.
Настройки листа и часовой пояс передаются вместе со снимком. ESM и CJS
загружают встроенный код Worker отдельным ленивым модулем. Если политика CSP
блокирует создание Worker, выгрузка выполняется в главном потоке.

## Требования

| ID  | Требование                                                                                | Проверка |
| --- | ----------------------------------------------------------------------------------------- | -------- |
| XZ1 | Без разрешения или при `worker: false` экспорт работает без создания Worker.              | browser  |
| XZ2 | XLSX из Worker побайтно совпадает со штатным экспортом поддерживаемого снимка.            | browser  |
| XZ3 | При отмене активной сборки Worker завершается и файл не возвращается.                     | browser  |
| XZ4 | При недоступности Worker штатный сериализатор возвращает файл.                            | browser  |
| XZ5 | Пользовательская функция разбора даты сохраняет результат и исполняется в главном потоке. | browser  |

## Последствия

Ускоренный режим выбирает разработчик. Он сокращает блокировку главного
потока и позволяет прервать расчёт, при этом передача и хранение снимка
могут увеличить полную задержку и память. CSV и серверная выгрузка
продолжают использовать собственные пути.
