# 0042 — Дымовые тесты демо-историй поведения

- **Статус:** Принято (реализовано); с [ADR 0093](0093-visual-state-catalog.md) дымовые
  тесты — `play` своих историй, отдельных файлов тестов нет (VR13).
- **Дата:** 2026-09-30
- **Связано:** [ADR 0009](0009-test-coverage-visual-and-performance.md) — покрытие
  тестами; [ADR 0039](0039-reactive-plugin-arguments.md),
  [ADR 0040](0040-action-sessions.md), [ADR 0041](0041-async-business-callbacks.md) —
  поведение, которое показывают истории.

## Контекст

Демо-истории с логикой (на 2026-10-08 — **Cells/Editing**, **Rows/Expanding**,
**Plugin API**, **Panels/Pagination — Server**; до перегруппировки историй — группа Sessions & Async) — не обёртки над
аргументами, как остальные истории, а маленькие приложения: имитация сервера, журнал колбэков, данные,
которые демо держит само. В них своя логика, и она может сломаться отдельно от
библиотеки. Так уже было: правку в «Cells/Editing — Server (async)» закрывала гонка фокуса
(ADR 0021, KN30), а все тесты библиотеки были зелёными.

Требования ADR 0040/0041 покрыты своими тестами; истории показывают их людям. Если
история не работает, человек видит сломанную библиотеку.

## Решение

Каждая история группы получает дымовой визуальный тест: история рендерится и её главный
сценарий даёт то, что обещает описание истории, — в интерфейсе и в журнале колбэков.
Взаимодействие — в темпе человека (`humanClick`, ADR 0021, KN30). Задержки сервера в
тестах сокращены аргументами истории, логика та же.

Тесты не дублируют требования ADR 0039–0041: они проверяют сборку демо (данные демо,
журнал, контролы), а не контракт библиотеки.

| DS4 | «Rows/Expanding — Lazy load (async)»: раскрытие ждёт подгрузки (`aria-busy`), затем строка раскрыта; в журнале `onExpandRow` и `loaded`                             | visual |
| DS5 | «Plugin API — Arguments on the fly»: `maxDepth` ниже раскрытого уровня прячет раскрытие, возврат значения — возвращает                                              | visual |
| DS6 | «Panels/Pagination — Server»: следующая страница и сортировка приходят с «сервера», итог — из `paginationRowCount`; в журнале `onPageChange` и `onToggleColumnSort` | visual |
