# 0059 — Шаг отступа вложенности: 16px и токен темы

- **Статус:** Принято (реализовано 2026-10-07; решения — по итогам обсуждения 2026-10-07)
- **Дата:** 2026-10-07
- **Изменён:** 2026-10-14 — уровень броска перетаскиваемой строки выбирается по тексту
  облака с шагом отступа ([ADR 0108](0108-row-drop-preview.md), PV10); шаг RE63
  остаётся запасным, когда геометрию не измерить. Шаг читается длиной, вычисленной
  браузером: с линиями дерева токен — `calc()`.
- **Изменён:** 2026-11-09 — колонка отступа — первая колонка данных на экране, а не первая по
  объявлению (RE80): при закреплении слева другой колонки отступ и линии дерева оставались в
  прежней, уехавшей вправо (замечание автора). Шаг RE63 считает ведущие служебные колонки в
  том же порядке отображения.
- **Связано:**
  - [ADR 0015](0015-row-expanding.md) — отступ вложенности первой колонки; здесь
    меняется его шаг (32 → 16 px) и источник (константа → токен).
  - [ADR 0016](0016-row-grouping.md) — строки групп стоят на том же отступе.
  - [ADR 0058](0058-tree-lines.md) — линии дерева: шаг линий равен шагу отступа.
  - [ADR 0006](0006-dnd-with-dnd-kit.md) — индикатор вложенности при перетаскивании
    строки смещается на тот же шаг.
  - [ADR 0019](0019-token-architecture.md) — трёхуровневые токены `--tsr-comp-*`.

## Контекст

Отступ вложенности — `ROW_NESTING_INDENT_PX = 32` px на уровень, константа ядра. Её
делят три места: `padding-left` первой пользовательской колонки (в JS), смещение
строки-оверлея по уровням при перетаскивании (в JS) и шаг линий дерева (в CSS).

На глубоком дереве 32 px съедают ширину первой колонки: на глубине 3 это 96 px, и
текст обрезается многоточием. Шаг больше, чем у распространённых гридов и деревьев
(редакторы кода — около 8 px, гриды — 16–28 px), и тема не может его поменять.

Решено (обсуждение 2026-10-07): шаг по умолчанию 16 px, переопределяемый токеном
темы; отступ, линии и перетаскивание берут его из одного источника.

## Решение

### 1. Токен шага

`--tsr-comp-row-nesting-indent` (уровень компонента, ADR 0019), по умолчанию `16px`.

- **Отступ.** Ячейка первой пользовательской колонки строки глубины `d` получает
  `padding-left: calc(var(--tsr-comp-row-nesting-indent) * d)` — шаг считается в CSS,
  JS передаёт только глубину. Строки групп `rowGrouping` — так же.
- **Линии дерева** (ADR 0058) идут с шагом токена: линия по центру каждого шага,
  ширина слоя — шаг × глубина.
- **Перетаскивание строки.** Смещение оверлея по уровню — реальная ширина ведущих
  служебных колонок плюс шаг. Шаг JS читает из темы смонтированного грида
  (`readGridToken`, как длительности подсветки ADR 0056); без грида — запасные 16 px.

Константа ядра остаётся запасным значением шага (16) для кода без смонтированного
грида.

### 2. Ломающее изменение вида

У существующих гридов с деревом отступ станет вдвое меньше. До 1.0 допустимо;
прежний вид возвращается темой: `--tsr-comp-row-nesting-indent: 32px`.

## Границы

- **Расширение первой колонки по глубине дерева** — не входит: меняет ширину колонки
  при раскрытии и спорит с ручным изменением ширины.
- **Горизонтальная прокрутка внутри ячейки** — не входит.
- **Куда уходит отступ при перестановке колонок** — по-прежнему первая колонка по
  определению колонок (ADR 0058, §3); не меняется.

## Отвергнутые альтернативы

- **Опция плагина `rowExpanding({ indent })`** — шаг — оформление, а не поведение;
  ему место в теме, как остальным размерам (ADR 0019). Опция не дошла бы до
  `rowGrouping` и перетаскивания без связи между плагинами.
- **Оставить 32 px** — проблема ширины на глубоком дереве остаётся у всех по
  умолчанию.
- **8 px, как в редакторах кода** — в гриде рядом шеврон в отдельной колонке и
  крупный текст ячеек; уровни на 8 px различимы хуже.

**Проверка RE63 модульная.** Перетаскивание вложенной строки в браузерном тесте
упирается в поведение самого плагина (уровень вложенности при переносе ограничен,
ADR 0006); предмет требования — источник шага, его проверяет модульный тест на
реальном канале токенов (`readGridToken`). Шаг читается заново на старте каждого
перетаскивания.

## Последствия

- **+** Первая колонка теряет на отступ вдвое меньше; шаг настраивается темой.
- **+** Отступ, линии дерева и перетаскивание согласованы одним источником.
- **−** Перетаскивание читает токен из DOM грида (при старте перетаскивания).
- **Публичный API:** токен `--tsr-comp-row-nesting-indent`; ломающее изменение
  вида — шаг 32 → 16 px.

## План внедрения

1. Токен в трёх уровнях темы; `padding-left` ячейки отступа — от токена и глубины.
2. Линии дерева — шаг от токена.
3. `getRowDraggableOffsetLeft` — шаг из `readGridToken`, запасное значение 16.
4. Тесты: `row-expanding` (RE61), `row-expanding-tree-lines` (RE62), модульный
   `rowNesting` (RE63–RE64); существующие тесты отступа — на шаг из токена.
5. Документация: ADR 0015 и 0058 (ссылка, шаг), `theming-and-overrides.md` (токен),
   roadmap («Сделано»), AGENTS.md, README решений.
