# 0190 — Выгрузка в серверной модели строк без серверного режима

- **Статус:** Принято (решения — по итогам прожарки 2026-11-06)
- **Дата:** 2026-11-06
- **Слой:** плагин `dataExportModel` — оси и загрузка строк; плагин `dataExport` — подписи. Ядро не
  меняется: строки отдаёт `loadRange` источника (ADR 0146).
- **Изменяет:**
  - [ADR 0138](0138-server-side-row-model.md) — §10 и SD30: выгрузка в SSRM не только серверная.
  - [ADR 0044](0044-export.md) — ось «Строки» в серверной модели строк.
- **Связано:**
  - [ADR 0158](0158-ssrm-pagination.md) — выгрузка страницы с догрузкой (SP12).
  - [ADR 0146](0146-cell-selection-in-ssrm.md) — предел строк `maxCopyRows`.
  - [ADR 0169](0169-data-mode.md) — `dataMode.export`.
  - [ADR 0153](0153-cancel-long-operations.md) — отмена.
  - [ADR 0177](0177-pending-and-failure-on-the-object.md) — отказ процесса.

## Контекст

ADR 0138, §10 решил: строк у грида нет, значит, выгрузка только серверная. Без `dataMode.export: 'server'`
инертен весь плагин, и недоступна даже страница, которую клиент уже умеет собирать (SP12). Приложение
без своего сервиса выгрузки лишено её совсем, хотя `getRows` отдаёт все нужные строки.

### Как у других

- **AG Grid** — в SSRM CSV и Excel выгружают только данные на экране.
- **MUI X** — рецепт: временно загрузить все строки и выгрузить их.

## Решение

### 1. Значения оси «Строки»

Без `dataMode.export: 'server'` плагины активны, предупреждения нет.

- **`page`** — страница, с догрузкой, как при серверной выгрузке (SP12).
- **`view`** — вся выборка в её порядке, на всех страницах: корни и раскрытые ветки. Свёрнутых веток в
  списке нет, поэтому они не входят.
- **`all`** и **`selected`** недоступны с причиной: `getRows` не отдаёт строки без фильтров, а
  незагруженные строки по `id` не найти. Их выгружает только сервер.

### 2. Предел

`dataExport({ maxLoadedRows })`, по умолчанию 10 000, как `maxCopyRows`: при блоках по 100 строк это
100 запросов. Известный итог сверх предела — отказ с причиной без запросов. Итог неизвестен — загрузка
останавливается на пределе, отказ с причиной, файла нет. Частичного файла нет: неполная выгрузка
выглядела бы как полная.

### 3. Ожидание, отмена, отказ

Как у прочей выгрузки: кнопка занята, «стоп» прерывает запросы (ADR 0153), смена выборки тоже. Отказ
блока — причина на кнопке (FB6), файла нет.

### 4. API

`table.exportData('view')` идёт тем же путём, `onExported` получает число строк.

## Границы

- `all` и `selected` на клиенте — нет.
- Частичный файл с пометкой — нет.
- Выгрузка свёрнутых веток — нет: их строки надо было бы запрашивать по одной ветке.

## Отвергнутые альтернативы

- **Только данные на экране, как AG Grid.** Файл зависит от прокрутки, а выглядит как полный.
- **Только `page`.** Приложению без сервиса выгрузки нечем выгрузить выборку.
- **Без предела.** Миллион строк означает десять тысяч запросов по нажатию одной кнопки.
- **Значение `view` недоступно сверх предела.** Итог часто неизвестен, а при известном человек не поймёт
  причину без подсказки; отказ называет её словами.

## Последствия

- **Изменение поведения:** в SSRM без серверной выгрузки кнопка появляется в тулбаре, а плагин не инертен.
- **Публичный API:** новый аргумент `maxLoadedRows`.
- **Перф:** сборка файла та же; нагрузка на сервер ограничена пределом и двумя параллельными запросами.
- База паритета (ADR 0187): `inertOnServer` у плагинов выгрузки и запись `exportWithoutServerFlag`
  меняются на различие значений оси.

## Внедрение

Этап один.

- **Загрузка.** `RowSource.loadList(limit, signal)`: `BlockTree.loadList` идёт по списку блок за блоком
  с раскрытыми ветками, потому что `loadRange` не выходит за известный конец списка.
- **Оси.** Значение `view` есть в SSRM и без сортировки и фильтров; тогда оно и есть весь список,
  подпись — как у `all`, а `all` не показывается.
- **Смена выборки** — `cancelPending` выгрузки по срезам `LIST_SLICES`, тем же, что у выбора страницы.
- **Тесты:** модульный `serverExport.dom` (XV1–XV5, XV8), визуальный `server-export` (XV6–XV7, XV9), перф
  XV10 — в `interaction`. TQ1 — мутациями: оси, загрузка страницы, раскрытые ветки, предел до запросов и
  по ходу, число строк, `signal` запроса, смена выборки, отказ блока, недоступное значение. Истории S1–S3 и
  `Playground` — раздел «Data loading/Server row model/Export», близнецы шагов.
