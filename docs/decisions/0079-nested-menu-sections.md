# 0079 — Вложенные разделы меню действий со сменой содержимого на месте

- **Статус:** Принято (решения — по итогам прожарки 2026-10-09)

## Контекст

Меню действий одноуровневое: `menuItems` разворачивает действие в несколько строк
одного списка, `panel` открывает произвольную панель. Сгруппировать действия
(«Закрепить → Слева / Справа / Открепить», «Экспорт → CSV / Excel») или выбрать из
списка с сервера («Переместить в → папки») нельзя.

Base UI умеет вложенность только подменю, выпадающим вбок (`Menu.SubmenuRoot`). Кебаб
часто стоит у правого края грида — подменю упирается в край экрана; на тач-устройствах
оно неудобно. Нужна смена содержимого в том же окне. Варианты анимации сравнивались на
живом прототипе (сдвиг, затухание, постоянный размер, выпадение вбок).

## Решение

### 1. Раздел у дескриптора

```ts
interface MenuSection<TCtx> {
  title: string
  items: MenuAction<TCtx>[] | ((signal: AbortSignal) => Promise<MenuAction<TCtx>[]>)
}
submenu?: (ctx, labels) => MenuSection<TCtx>
hint?: (ctx, labels) => string | undefined
```

- Действие с `submenu` — пункт-раздел: у правого края шеврон (`icons.submenu`), перед
  ним мелким текстом необязательное значение `hint` («Pin … Left»). Нажатие открывает
  раздел, `onSelect` не вызывается.
- Пункты раздела — те же `MenuAction` с тем же контекстом: раздел может содержать свой
  раздел, глубина не ограничена (в документации советуем не больше трёх уровней).
- Выбор пункта раздела выполняет его действие и закрывает всё меню.
- `id` пункта уникален в пределах меню: по нему ведутся ожидание и отказ (ADR 0078).

### 2. Смена содержимого на месте

- Вход: прежний уровень уезжает влево, новый приезжает справа; возврат — в обратную
  сторону. Окно плавно подстраивает ширину и высоту под уровень. Длительность и кривая —
  токены движения; при уменьшенном движении смена мгновенная.
- Уходящий уровень — снимок разметки без обработчиков: Base UI ведёт по пунктам только
  текущего уровня, стрелки не попадают в уходящий.
- Окно остаётся прижатым к кебабу и не выходит за край экрана — позиционер Base UI
  пересчитывает положение при смене размера.
- Ловушка: фокус на первом пункте въезжающего уровня, пока тот ещё за краем окна,
  прокручивает контейнер с `overflow: hidden` — сдвиг пропадает, уровень встаёт на
  место сразу. Поэтому окно — `overflow: clip`, а фокус ставится с `preventScroll`.

### 3. Навигация

- Первая строка раздела — «‹ Название», под ней разделитель (`Menu.Separator`, как
  между подгруппами), а не граница строки: подсветка строки остаётся скруглённой.
  Нажатие возвращает уровень выше.
  Доступное имя — «Back, <название>».
- `ArrowRight` и `Enter` на пункте-разделе — вход; `ArrowLeft` и `Escape` — уровень
  выше; `Escape` на корне закрывает меню.
- Фокус: при входе — на первый пункт раздела, при возврате — на пункт, из которого
  заходили.
- Пункт-раздел несёт `aria-haspopup="menu"`; у меню при входе `aria-label` — название
  раздела, вход объявляется live-областью.
- Меню закрывается целиком (выбор, клик мимо, кебаб): при следующем открытии — корень.

### 4. Асинхронный раздел

- `items` промисом: раздел открывается сразу со скелетом строк, пункты появляются после
  ответа.
- Загрузка начинается при наведении и фокусе на пункте-разделе и переиспользуется при
  входе; закрытие меню прерывает её (`signal`). Результат живёт до закрытия меню —
  кеширует приложение.
- Отказ: строка «Couldn't load» с иконкой ошибки и текстом в тултипе и
  `aria-describedby`; её нажатие загружает заново.
- Пункты раздела получают все состояния ADR 0078: проверку доступности (сессия
  проверяет пункты раздела при входе), причины, ожидание и отказ. Ожидание и отказ
  пункта раздела видны и на кебабе: кебаб собирает состояния всех действий своего
  меню, а не только корня.

### 5. Где действует

Кебабы заголовка и строки, контекстное меню. Действие с `submenu`, показанное
инлайн-кнопкой, открывает мини-меню, корень которого — его раздел. Мини-меню
`inlineAsMenu` и панели тулбара не затронуты.

### 6. Меню, которое не закрывается

Расставить несколько меток или переключить пару флагов, каждый раз проходя путь до
раздела заново, неудобно. Поэтому закрытие после выбора настраивается
(решение — по итогам прожарки 2026-10-09, вариант «раздел + пункт»):

- `MenuSection.closeOnSelect` — умолчание для пунктов раздела;
  `MenuAction.closeOnSelect` — у пункта, переопределяет умолчание раздела. Без обоих —
  `true`, как прежде (NM7).
- Пункт с `closeOnSelect: false`: выбор (клик, `Enter`, `Space`) выполняет действие,
  меню остаётся на том же уровне, фокус — на том же пункте.
- Состояние пункта обновляется сразу — галочка `active`, а при возврате и `hint`
  родителя, — даже если оно живёт у приложения, а не в таблице: меню перерисовывает
  пункты само после выбора.
- Асинхронное действие такого пункта показывает лоадер прямо в пункте, отказ — иконкой
  ошибки с текстом в тултипе (ADR 0078); меню не закрывается.
- Пункт с признаком `active` и `closeOnSelect: false` — флажок в меню: роль
  `menuitemcheckbox` и `aria-checked`. Скринридер объявляет «отмечено» без отдельного
  объявления.
- Открывать меню снова на последнем уровне отвергнуто: при нажатии на кебаб человек
  ждёт корень, а не глубину, из которой ушёл давно.

## Границы

- Переделка встроенных плагинов (закрепление и сортировка — разделами) — нет.
- Поиск внутри длинного раздела — нет.
- Выпадающие вбок подменю — нет.

## Отвергнутые альтернативы

- **Выпадение вбок (`Menu.SubmenuRoot`)** — упирается в край экрана у кебаба справа,
  неудобно на тач-устройствах.
- **Затухание вместо сдвига** — читается как «содержимое заменили», а не «зашли
  внутрь»; направление не видно.
- **Постоянный размер окна** — пустота в коротких разделах.
- **Лоадер на пункте и вход после загрузки** — при медленном сервере клик долго висит.
- **Гибрид: ждать ответа до 150 мс, потом скелет** — опробован и отвергнут: задержка
  входа ощущается как лаг пунктов. Скелет при быстром ответе мелькает — это принято.
- **Уходящий уровень живыми пунктами** — Base UI зарегистрировал бы их в навигации, и
  стрелки на время анимации попадали бы в уходящий уровень.

## Последствия

- `MenuAction` получает `submenu`, `hint` и `closeOnSelect`, `MenuSection` — `closeOnSelect`; новые подписи `localization`, иконки
  `submenu` и `menuBack`.
- Запись среза `actionStatus` хранит своё действие и признак меню: кебаб собирает
  состояния по цели, включая пункты разделов.
- Меню (кебаб, контекстное) хранит стек уровней; закрытие сбрасывает его по окончании
  анимации закрытия.

## План внедрения

1. Типы `submenu`/`hint`, модель стека и разрешения раздела, состояние меню.
2. `ActionMenuSections`: уровень, снимок уходящего, размер, клавиши, фокус.
3. Кебаб, контекстное меню, инлайн-кнопка с разделом; кебаб собирает состояния по цели.
4. Тесты, история, документация.
