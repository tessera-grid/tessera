## Контекст

Подписи таблицы задаёт проп `<DataGrid localization>` — `Partial<TableLabels>`, слитое
поверх английских `DEFAULT_LABELS`. Из 174 подписей 41 — функции:
`selectedRows: count => …`, `pageRange: (from, to, total) => …`. Поэтому словарь
приложения в формате «ключ → строка» (файл переводов, ресурс i18n-системы) таблице не
передать: на каждую подпись с числом нужна своя функция в коде.

- **Формы числа зашиты в функции** по английской логике (`count === 1 ? … : …`); русскому
  нужны три формы — «1 строка, 2 строки, 5 строк».
- **Числа форматируются в `en-US`** (`toLocaleString('en-US')`) при любом переводе.
- **Составные подписи** выбирают текст условием внутри функции (`filters`, `announceSort`,
  `loadedRows` и др.) — шаблоном без условий их не выразить.
- **Названия возможностей в `exportView`** («sorting», «filters») зашиты в коде
  (`VIEW_FEATURES`) и не переводятся.

### Как это сделано у других

- **AG Grid** — `localeText`: плоский словарь «ключ → строка» с подстановками
  `${variable}`, колбэк `getLocaleText`; готовые словари — отдельным пакетом.
- **MUI X** — `localeText`: ключ → строка или функция (функции — для чисел и форм числа);
  готовые словари (`ruRU` и др.) в пакете.
- **TanStack Table** — подписей нет.

## Решение

### 1. Значение подписи — строка или функция

Значение каждой подписи — строка-шаблон или функция. Функция вызывается как сейчас, с
позиционными параметрами: кто передаёт функции, правит словарь только для разбитых
ключей (§6). Строка без подстановок выводится как есть.

### 2. Подстановки

`{имя}` в строке заменяется значением параметра с тем же именем. Имена параметров
задаёт тип подписи: у каждой подписи с параметрами они записаны в `TableLabels`
(например, `pageRange` — `{from}`, `{to}`, `{total}`). Подстановка без такого параметра
остаётся текстом как есть.

### 3. Формы числа

У подписи с параметром `count` разрешитель ищет ключ с суффиксом формы
`Intl.PluralRules(locale).select(count)` — `_one`, `_two`, `_few`, `_many`, `_other`, — затем
ключ без суффикса. При `count = 0` в любом языке сначала ищется `_zero`. Так устроены
файлы переводов i18next и похожих систем: словарь приложения ложится без переделки.

```json
{
  "selectedRows_one": "Выбрана {count} строка",
  "selectedRows_few": "Выбрано {count} строки",
  "selectedRows_many": "Выбрано {count} строк",
  "selectedRows_other": "Выбрано {count} строки"
}
```

### 4. Числа и списки

Число в подстановке форматируется `Intl.NumberFormat(locale)`, список строк —
`Intl.ListFormat(locale)` (`{columns}` у `searchColumnsHint`). Форматтеры кешируются по
локали.

### 5. Проп `locale`

`<DataGrid locale>` — тег языка BCP 47, по умолчанию `'en-US'`: язык форм числа, чисел и
списков. Смена `locale` и `localization` на лету перерисовывает подписи, таблица не
пересоздаётся.

### 6. Составные подписи — отдельными ключами

| Было                                         | Стало                                                                                                                  |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `filters(active, hidden)`                    | `filters`, `filtersActive` `{count}`, `filtersActiveHidden` `{count}` `{hidden}`                                       |
| `announceSort(column, direction)`            | `announceSortAscending` `{column}`, `announceSortDescending` `{column}`, `announceSortCleared`                         |
| `loadedRows(loaded, total?)`                 | `loadedRows` `{count}`, `loadedRowsOf` `{count}` `{total}`                                                             |
| `loadedRowsShort(loaded, total?)`            | `loadedRowsShort` `{count}`, `loadedRowsOfShort` `{count}` `{total}`                                                   |
| `announceLoadError(reason?)`                 | `announceLoadError`, `announceLoadErrorReason` `{reason}`                                                              |
| `announceLoadFailed(reason?)`                | `announceLoadFailed`, `announceLoadFailedReason` `{reason}`                                                            |
| `exportView(features)` и `VIEW_FEATURES`     | `exportView` `{features}` — список из `exportViewSorting` и `exportViewFiltering`                                      |
| `serverActionFailed(kind)` — текст по `kind` | `serverActionFailedSorting`, `serverActionFailedFiltering`, `serverActionFailedSearch`, `serverActionFailedPagination` |
| `announceChildrenLoaded(count)` с «No rows»  | `announceChildrenLoaded_zero` и формы `announceChildrenLoaded` `{count}`                                               |

### 7. Умолчания — шаблонами

Английские `DEFAULT_LABELS` записаны строками-шаблонами, без функций, с формами слова
`_one` и `_zero`, где они нужны: словарь умолчаний — образец формата для приложения. Ключ
без суффикса — форма «остальные числа»: она же запасная для языка с другим набором форм.
Готовые к вызову английские подписи — `resolveLabels(undefined, 'en-US')`. В пакете — только английский словарь; русский словарь
историй — образец в документации.

### 8. Тип и проверка словаря

Тип словаря — плоские ключи подписей и ключи форм числа только у подписей с `count`.
Неизвестный ключ в переданном словаре — предупреждение в dev: ловит опечатки словаря,
загруженного из JSON.

### 9. Истории

Раздел `Tessera/Customization/Localization`: `Playground` и по истории на сценарий; туда
переезжает история `Core/Localization`.

## Границы

- ICU MessageFormat, вложенные ключи, готовые словари в пакете.
- Локаль календарей дат — опция таблицы `dateLocale` (объект локали
  календаря из строки не получить).
- Письмо справа налево.

## Отвергнутые альтернативы

- **ICU MessageFormat** (`{count, plural, …}`) — мощнее, но это свой парсер синтаксиса;
  суффиксы форм проще и совпадают с форматом файлов i18next.
- **i18next и другие фреймворки** — запрещены ADR 0003.
- **Вложенные ключи** (`export.rows`) — сложнее тип и слияние; AG Grid тоже плоский.
- **Функции с объектом параметров** — сломали бы всех, кто передаёт функции; имена
  параметров нужны только шаблонам.
- **Готовые словари в пакете** (как `ruRU` у MUI X) — переводы в `dist` без потребности.

## Последствия

- **+** Словарь приложения «ключ → строка» переводит всю таблицу без кода.
- **+** Формы числа и числа — по языку, а не по-английски.
- **−** Ломающее изменение `TableLabels`: ключи §6 разбиты и переименованы; кто передаёт
  для них функции, правит словарь.
- **−** Ломающее изменение `DEFAULT_LABELS`: это словарь строк-шаблонов, а не готовые
  подписи; вызывать его значения нельзя.
- **−** Английский текст меняется: числа больше 999 — с разделителем тысяч (`1–25 of
12,340`), перечень колонок поиска — по `Intl.ListFormat` (`Name, City, and Age`).
- **+** Потребители подписей не меняются: разрешитель отдаёт тот же объект `TableLabels`,
  подпись-шаблон становится функцией с позиционными параметрами.
