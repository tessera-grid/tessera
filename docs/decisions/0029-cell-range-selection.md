# 0029 — Выделение диапазона ячеек и копирование в буфер (плагин cellSelection)

- **Статус:** Принято
- **Дата:** 2026-09-22
- **Связано:**
  - [ADR 0010](0010-invert-core-plugins-registry.md) — форма плагина
    (`definePlugin`, presence-based). Как и `keyboardNavigation`, плагин
    **сознательно расширяет** контракт: выделение — свойство самого DOM-узла
    ячейки (обводка, обработчики мыши, roving `tabindex`), а не сервисной колонки,
    поэтому требует минимальных, аддитивных и инертных без плагина швов ядра.
  - [ADR 0021](0021-keyboard-navigation.md) — клавиатурная навигация (срез 1
    реализован: стрелки схлопывают выделение, Shift+стрелки расширяют
    диапазон). Понятие «активная (focused) ячейка» и roving `tabindex` —
    **общее** с этим ADR. Здесь focused-ячейка появляется как **anchor последнего
    диапазона** (её даёт stock-фича), но клавиатурное перемещение стрелками не
    вводится: когда `keyboardNavigation` появится, он становится единым владельцем
    клавиатурного резолвера, а focused-ячейка cellSelection — той же активной
    ячейкой (см. «Границы» и «Открытые вопросы»).
  - [ADR 0026](0026-migrate-to-tanstack-v9.md) — v9 даёт stock-фичу
    `cellSelectionFeature`; ячейки читают «я выделена?» гранулярно через
    `useSelector` (TanStack Store), без глобального ре-рендера.
  - [ADR 0005](0005-virtualization-tanstack-virtual.md) — выделение хранится в
    **модельных id** (не индексах окна), поэтому переживает анмаунт/маунт строки
    при прокрутке. Буфер обмена читает значения из модели, а не из DOM, — пиновка
    узла в `rangeExtractor` для копирования не нужна.
  - [ADR 0022](0022-plugin-compatibility-contract.md) — контракт совместимости:
    плагин инертен без импорта и при `enabled: false`.
  - [ADR 0019](0019-token-architecture.md) — цвета выделения заведены как
    `--tsr-comp-*` поверх `--tsr-sys-*` (info-акцент), light/dark — автоматически.
  - [ADR 0009](0009-test-coverage-visual-and-performance.md) — три вида покрытия
    (visual + perf + unit-logic), одно требование — один тест `CR<n>`.

## Контекст

По паритету с рынком (`docs/roadmap.md` → «Паритет») выделение прямоугольного
диапазона ячеек с копированием в буфер — базовая табличная возможность (есть у AG
Grid, MUI X, react-data-grid). У Tessera её не было. Роадмап отмечал, что на v9
это **дёшево** — благодаря stock-фиче `cellSelectionFeature`.

Проверка подтвердила: `cellSelectionFeature` из `@tanstack/react-table@9` несёт
почти всю механику:

- слайс состояния `cellSelection` (массив прямоугольников `anchor`/`focus`,
  реактивный через `table.atoms.cellSelection`);
- по-ячеечные `cell.getIsSelected()` / `getIsFocused()` / `getSelectionEdges()`
  (готовый spreadsheet-контур без опроса соседей) / `getTabIndex()` /
  `getCanSelect()`;
- готовые обработчики мыши `cell.getSelectionStartHandler()` (→ `mousedown`) и
  `cell.getSelectionExtendHandler()` (→ `mouseenter`): shift-click,
  ctrl/cmd-мульти-диапазон, drag, и **сам** вешает document-level `mouseup`
  (drag, отпущенный вне таблицы, корректно завершается);
- «сырьё» для буфера `table.getSelectedCellRangesData()` →
  `Array<region><row><col>` значений в row-major; сериализацию в текст фича
  **намеренно** оставляет приложению (разделитель, представление null и quoting —
  прикладные решения).

Наша задача — **интеграционные швы**, а не механика выделения.

## Решение

Ввести плагин **`cellSelection()`** — presence-based запись `definePlugin`
([ADR 0010](0010-invert-core-plugins-registry.md)) **без сервисной колонки**,
регистрирующий stock-`cellSelectionFeature`, плюс минимальные швы ядра для DOM.

### Объём первого среза (MVP)

- **Мышь:** клик (одна ячейка), shift-клик (расширить прямоугольник),
  ctrl/cmd-клик (добавить/вычесть диапазон), drag (протянуть выделение).
- **Буфер — только копирование:** `Ctrl/Cmd+C` копирует выделение как **TSV**
  (`text/plain`) и как **HTML-таблицу** (`text/html`, rich-paste в
  Excel/Sheets).
- **Вне MVP (в роадмап):** перемещение/расширение выделения **стрелками
  клавиатуры** (общий владелец — будущий `keyboardNavigation`,
  [ADR 0021](0021-keyboard-navigation.md)) и **вставка** (`Ctrl/Cmd+V` → запись в
  ячейки через `cellEditing` — тянет валидацию и bulk-edit).

### Опции плагина

```ts
cellSelection({
  enabled, // false — плагин инертен (present-but-disabled)
  rangeSelection, // shift-расширение прямоугольника (по умолчанию true)
  dragSelection, // протяжка мышью (по умолчанию true)
  multiRange, // ctrl/cmd мульти-диапазон (по умолчанию true)
  canSelectCell, // предикат выбираемости ячейки
})
```

Значения складываются в стоковые опции фичи (`enableCellSelection` /
`enableCellRangeSelection` / `enableCellSelectionDrag` /
`enableMultiCellRangeSelection`). При `enabled: false` все `enable*` жёстко
`false` (v9 фиксирует набор фич на маунте — рантайм-гейт только опцией, как в
[ADR 0010](0010-invert-core-plugins-registry.md)). Дефолтный предикат исключает
**сервисные колонки** (действия строки/заголовка) из выбираемых.

### Швы ядра (аддитивны, инертны без плагина)

Ядро **не импортит плагин** (инвариант R1 [ADR 0010](0010-invert-core-plugins-registry.md)
сохранён): швы читают **presence по наличию метода/слайса**, ровно как `DataGrid`
уже читает слайс `rowDragging` через `?.`.

1. **`useCellSelection(cell)` (`core/cellSelection.ts`).** Гранулярная подписка
   ячейки: `useTableState` с selector'ом, возвращающим членство
   (`isSelected`/`isFocused`/кромки/`tabIndex`) — ре-рендерится только та ячейка,
   чьё членство изменилось. Без фичи selector возвращает `null` (стабильно по
   `shallowEqual` → ноль ре-рендеров). Возвращает и мышиные обработчики
   (`getSelectionStartHandler`/`getSelectionExtendHandler`).
2. **`BodyCell` применяет результат.** При наличии — `data-cell-selected` /
   `data-cell-focused`, CSS-переменные кромок (`--tsr-sel-edge-*`), `onMouseDown`
   (+ фокус ячейки для нативного `copy`-события) / `onMouseEnter`, roving
   `tabindex`. Без плагина — ничего из этого (атрибуты/обработчики отсутствуют).
   Нативный focus-контур ячеек гасится (свой индикатор несёт `data-cell-focused`);
   выбираемые ячейки получают `user-select: none` (по наличию `tabindex`), чтобы
   клик/shift/drag выделяли **ячейки, а не текст** — без плагина текст выделяется
   как обычно.
3. **`DataGrid` вешает `onCopy`.** Если у таблицы есть
   `getSelectedCellRangesData` (presence фичи) — контейнер прокрутки ловит
   нативное `copy`-событие (всплывает от сфокусированной ячейки),
   сериализует выделение (`core/clipboard.ts`) и кладёт в `clipboardData`. Если у
   пользователя есть неспавшееся текстовое выделение — уступаем нативному
   копированию текста. Слайс `cellSelection` исключён из корневой подписки
   `DataGrid` (как `rowSelection`): корню незачем ре-рендериться на выделение —
   его несут сами ячейки.
4. **Авто-прокрутка у края (`core/cellSelectionAutoScroll.ts`).** Стоковая фича
   расширяет выделение только по `mouseenter` ячейки — у края/за пределами таблицы
   ячеек под курсором нет. Хук (presence-gated, активен только пока
   `_isSelectingCells`) в `requestAnimationFrame`-цикле прокручивает контейнер со
   скоростью по заходу в краевую зону и **до-расширяет** активный диапазон
   публичным `selectCellRange` к ячейке под курсором, **клампнутым** в границы
   контейнера (за краем берётся крайняя видимая ячейка). rAF корректно
   приостанавливается, когда грид не виден.

### Сериализация буфера (`core/clipboard.ts`, generic)

- **TSV:** колонки — `\t`, строки — `\n`, непересекающиеся регионы — пустая
  строка между ними. `null`/`undefined` → пустая строка. Поля с `\t`/`\n`/`"`
  оборачиваются в `"…"` с удвоением внутренних `"` (CSV-совместимый quoting).
- **HTML:** `<table><tr><td>…` на регион (экранирование `& < >`).
- Функции чистые, живут в `core/` (ядро их импортит, плагин — реэкспортит для
  потребителя), поэтому R1 не нарушается.

### Цвета (токены) и anchor

`--tsr-comp-cell-selected-bg` (полупрозрачный info-тинт — **накладывается**
`background-image`-градиентом поверх фона, не затирая подложку закреплённых
ячеек) и `--tsr-comp-cell-selected-border-color` (кромка диапазона, рисуется
`box-shadow: inset` — не влияет на модель бокса). Оба — поверх `--tsr-sys-info`,
dark пересчитывается сам ([ADR 0019](0019-token-architecture.md)).

**Активная (anchor) ячейка — как в Excel/Google Sheets:** отдельного индикатора
нет; она распознаётся тем, что **не заливается тинтом** (`background-image: none`
для `data-cell-selected` + `data-cell-focused`), оставаясь видимой внутри залитого
диапазона. Рамка одна — общие кромки прямоугольника. Так anchor не выглядит
«оторванным» отдельным бордером.

## Границы

- **Клавиатура/стрелки** — вне MVP (роадмап; владелец — `keyboardNavigation`,
  [ADR 0021](0021-keyboard-navigation.md)). `Ctrl/Cmd+C` работает через нативное
  `copy`-событие сфокусированной ячейки, поэтому полноценный клавиатурный резолвер
  для MVP не нужен.
- **Вставка** — вне MVP (роадмап): требует `cellEditing`/валидации.
- **`role="grid"`** — не вводим здесь: полноклавиатурный композит APG Grid — зона
  `keyboardNavigation` ([ADR 0021](0021-keyboard-navigation.md)); контейнер
  остаётся `role="table"` ([ADR 0020](0020-accessibility.md)).
- **Группировка:** при активной группировке ячейки строк-групп технически
  выбираемы (значения — отображаемые); специального гейта нет. Уточнить при
  проработке pivot, если понадобится.

## Последствия

- **+** Закрывает рыночный пробел «range/cell-selection + clipboard (copy)»
  малой ценой: механику несёт stock-фича, мы даём швы.
- **+** Opt-in и tree-shakeable: без импорта — ноль обработчиков/атрибутов/веса.
- **+** Реактивность гранулярна: на смену выделения ре-рендерятся только
  затронутые ячейки, не сетка.
- **+** Выделение в модельных id — переживает виртуализацию; копирование читает
  модель, пиновка узла не нужна.
- **−** Второй после `keyboardNavigation` кандидат на «focused-ячейку»: вводим
  общий контракт заранее (focused = anchor последнего диапазона), чтобы будущий
  клавиатурный плагин его переиспользовал, а не конфликтовал.
- **−** `onCopy` через нативное событие завязан на фокус сфокусированной ячейки;
  крайние случаи потери фокуса — предмет теста CR9/CR12.

(vitest-browser, реальный Chromium); unit-logic — `__tests__/cellSelection.test.ts`;
perf — общая матрица ([ADR 0009](0009-test-coverage-visual-and-performance.md)).

## План внедрения

- **Фаза 1 — швы ядра (аддитивно).** `core/clipboard.ts` (сериализация +
  `copy`-хендлер), `core/cellSelection.ts` (`useCellSelection`, no-op без фичи).
  Без плагина поведение не меняется; `tsc` и существующие тесты зелёные.
- **Фаза 2 — плагин + применение в DOM.** `plugins/cellSelection`,
  `BodyCell` применяет `useCellSelection`, `DataGrid` вешает `onCopy` и исключает
  `cellSelection` из корневой подписки; токены + CSS.
- **Фаза 3 — история и тесты.** Story `CellSelection`; visual CR1–CR7/CR9/CR12,
  unit CR8/CR10/CR11, perf CR13.

См. [ADR 0021](0021-keyboard-navigation.md) о будущем клавиатурном владельце
focused-ячейки, [ADR 0019](0019-token-architecture.md) о токенах и
[ADR 0010](0010-invert-core-plugins-registry.md) об инварианте «ноль правок
ядра», который этот план ослабляет так же осознанно и ограниченно.
