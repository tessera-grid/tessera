# 0071 — Лёгкая ячейка тела

- **Статус:** Отклонено (2026-10-08): выигрыш не подтвердился замером, код откачен
- **Дата:** 2026-10-08
- **Связано:**
  - [ADR 0004](0004-core-on-tanstack-table.md) — ячейка тела ядра.
  - [ADR 0028](0028-define-plugin-authoring-api.md) — слоты ячейки.
  - [ADR 0054](0054-lazy-row-children.md) — приход ленивых детей (RE38).

## Контекст

Профиль рендера прихода ответа на 100 000 корней (RE38, 2026-10-08, ×4 CPU) после
ADR 0067–0070: модели строк ~25 мс, основная цена — монтирование строк, въехавших в окно.
Строка — ~88 компонентов React; из них ~34 выглядели лишними:

- `RenderSlot` для пустых левого и правого слотов — монтируется и возвращает `null`;
- `CellWrapperContent` и `CellWrapperTitle` — memo-компоненты ради одного `div` с
  классами;
- `RenderCellSlot` без владельцев `cellSlot` — возвращает содержимое как есть.

Гипотеза: цена строки пропорциональна числу компонентов (~0,1 мс на компонент под ×4),
и минус ~40% компонентов даст −10…20% к монтированию строки.

## Что проверено

Ячейка тела без пустых слотов и компонентов-обёрток (та же разметка обычными
элементами); модульные тесты числа компонентов и разметки — зелёные, на мутациях
красные. Замер вперемешку с HEAD, два раунда, ×4 CPU, прод-сборка:

| Кейс | Новая ячейка, мс | HEAD, мс  |
| ---- | ---------------- | --------- |
| I7   | 162 / 182        | 166 / 164 |
| I8   | 127 / 133        | 130 / 137 |
| RE38 | 209 / 220        | 215 / 205 |
| P1   | 96 / 102         | 93 / 101  |
| P3   | 169 / 166        | 167 / 168 |
| P9   | 370 / 393        | 388 / 355 |

Разница — в пределах шума, в обе стороны.

## Решение

Не делать: код откачен.

## Вывод

Цена монтирования строки не пропорциональна числу компонентов. Пустой `RenderSlot` и
memo-обёртка вокруг `div` почти бесплатны; «~0,1 мс на компонент» — среднее, в котором
доминируют тяжёлые компоненты (ячейка с подписками на срезы, кнопки на Base UI,
`useSortable` dnd-kit) и создание DOM в коммите (~34 мс на приход RE38). Дальнейшее
облегчение строки начинать с разбивки по этим компонентам, а не со счёта компонентов.

Попутно — ловушка профиля рендера: компонент, пропущенный React или выданный memo без
отрисовки, остаётся в дереве со старым временем; честный подсчёт сравнивает объекты с
прошлым коммитом и требует флаг выполненной работы.
