# ADR 0233 — Управление таблицей во время демонстрации

- **Статус:** Принято.
- **Слой:** обвязка историй (`src/lib/stories`) — панель демонстрации, воспроизведение шагов и управление вводом.
- **Заменяет:** [ADR 0117](0117-story-controls.md), SN42, границу блокировки ввода в SN43 и возможность перехода через список во время действия в SN76.

## Контекст

История демонстрирует пользовательский сценарий. Ввод во время подготовки шага
или автовоспроизведения может изменить таблицу, пока она ещё нужна демонстрации.
Раскрытая панель на низком экране может скрывать область действия.

## Решение

Панель сохраняет управление переходами и паузой. После шага пользователь может
попробовать таблицу и вернуть состояние демонстрации кнопкой «Вернуть шаг».
При паузе начатое действие доходит до устойчивого результата.

| ID   | Требование                                                                                                                                                                                                                         | Проверка |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| SN42 | Во время воспроизведения ввод в таблицу заблокирован. Пауза сразу останавливает продвижение и возвращает ввод после завершения уже начатого действия, а на готовом шаге — сразу. После последнего шага ввод возвращается.          | visual   |
| SN43 | Ручной переход защищает таблицу и её поповеры от пользовательского ввода на время подготовки и действия. После готовности пользовательский ввод снова доходит до таблицы. Кнопки панели доступны согласно правилам навигации.      | visual   |
| SN77 | При старте показа и переходе страница прокручивается к таблице, если большую часть её доступной высоты скрыла панель или область окна. Видимая таблица не вызывает прокрутку.                                                      | visual   |
| SN78 | Пока шаг готовится, выполняется или показывает действие, кнопки «Назад», «Далее» и переход к шагу по списку недоступны. По завершении они доступны согласно позиции шага. «Пауза» и «Сначала» работают и во время выполнения шага. | visual   |

## Последствия

Код демонстрации по-прежнему может выполнять действия и ставить фокус.
Шаги, которым для своего действия нужно реальное касание браузера, сохраняют
внутренний канал ввода. Блокировка относится к обвязке Storybook.
