# 0002 — Виртуализация через TanStack Virtual

- **Статус:** Принято
- **Дата:** 2026-08-02

## Контекст

Производительность на больших наборах данных была первоочередной целью. Рендерить
все строки (а для плоских заголовков — и все колонки) невозможно, поэтому
виртуализация была необходима. Кандидаты, которые мы оценивали:

- **react-virtuoso** — эргономичный, но виртуализирует только по **Y**
  (в стиле списка). Tessera нужна ещё и виртуализация **колонок**, а не только
  строк.
- **react-window / react-virtualized** — уже устаревшие.
- **TanStack Virtual** — низкоуровневый и без навязанных мнений, виртуализирует
  любую ось и естественно сочетается с ядром TanStack Table
  ([ADR 0001](0001-core-on-tanstack-table.md)).

## Решение

Используем **TanStack Virtual** и для виртуализации **строк** (всегда), и для
виртуализации **колонок** (только для плоских заголовков). Принимаем его
низкоуровневую природу как цену за тот контроль и производительность, которые он
даёт.

## Последствия

- **+** Виртуализированы обе оси; хорошая измеренная производительность на больших
  таблицах.
- **+** Единая ментальная модель и жизненный цикл с ядром TanStack Table.
- **−** Это **низкоуровневый инструмент**: корректная настройка (извлечение
  диапазона, измерение, паддинги) потребовала значительных усилий на тюнинг и
  остаётся самой деликатной частью пути рендеринга.
- **−** Виртуализация колонок отключена для **вложенных (многоуровневых)
  заголовков**, которые используют CSS-раскладку `grid` — другой путь
  рендеринга. Именно поэтому вложенные заголовки пока не сочетаются с
  закреплением/перетаскиванием колонок (известное ограничение).
- См. [virtualization.md](../architecture/virtualization.md) про виртуализаторы и
  [rendering.md](../architecture/rendering.md) про разделение раскладки flex vs grid.
