# 0218 — Перенос текста и высота строк и шапки по содержимому

- **Статус:** Принято (решения — по итогам прожарки 2026-11-12)
- **Дата:** 2026-11-12
- **Слой:** плагин `textWrap` — поля колонки `wrapText`, `autoHeight`, `wrapHeaderText`,

## Контекст

Ячейка, шапка и футер держат текст в одну строку и сокращают его через `…` с тултипом
(ADR 0075, ADR 0083). Высота строки фиксирована (ADR 0004, R7) и задаётся `rowHeight`
(ADR 0077). Длинный текст — комментарий, адрес, описание сделки — в таблице прочесть нельзя,
только по наведению; плотную таблицу с двумя-тремя строками в ячейке не собрать.

Задача (прожарка 2026-11-12): прочесть длинный текст прямо в таблице и показывать несколько строк в
ячейке фиксированной высоты. Произвольное содержимое ячейки (`renderComponent`) меряется тем же
механизмом, отдельной работы не требует.

Сейчас:

- строка тела — `position: absolute` высотой `--tsr-comp-row-height` с `contain: layout paint`;
  центральные ячейки тоже стоят `absolute` по своему `left` — высоту строки содержимое ячеек не
  задаёт, замер строки целиком бесполезен;
- виртуализатор строк уже меряет строки (`measureElement`, при прокрутке вверх — из кэша), оценка
  равна `rowHeight`;
- геометрия в десяти местах считает умножением на `rowHeight`: PageUp/PageDown
  (`keyboardNavigation/geometry.ts`), удержание первой строки экрана при вставках и удалениях
  (`rowVirtualizer.ts`, ADR 0157/0194), стопка липких строк групп (`StickyRows.tsx`, ADR 0160),
  число строк скелета (`skeletonOptions.ts`).

### Как у других

- **AG Grid** — `wrapText` переносит текст в фиксированной высоте; `autoHeight` у колонки задаёт
  высоту строки по содержимому: ячейки слушают свой размер и **рисуются всегда**, вне виртуализации
  колонок. Незамеренные строки — высотой `rowHeight`, замер ленивый. `getRowHeight` — высота от
  приложения. `wrapHeaderText` + `autoHeaderHeight` — шапка по наибольшему заголовку, растёт при
  сужении колонки. Предела строк нет.
- **MUI X v9** — `getRowHeight: () => 'auto'` на всю таблицу, ленивый замер; ползунок «плывёт», и
  документация это признаёт; оценка — `getEstimatedRowHeight` (по умолчанию 52px). Виртуализация
  колонок при `'auto'` выключена; `virtualizeColumnsWithAutoRowHeight` мерит по видимым колонкам, и
  высота меняется при горизонтальной прокрутке.
- **TanStack Virtual** — `estimateSize` + `measureElement` (ResizeObserver); при смене размера
  элементов выше экрана позиция прокрутки поправляется, видимое не сдвигается.

## Решение

### 1. Две ступени

- **Перенос в фиксированной высоте** — `wrapText: true` у колонки. Текст переносится по словам,
  видно столько целых строк, сколько помещается в `rowHeight`, последняя кончается `…`; полный
  текст — в тултипе обрезанного текста (ADR 0075). Виртуализацию не задевает.
- **Высота по содержимому** — `autoHeight: true | { maxLines }` у колонки. Высота строки —
  наибольшая высота содержимого её колонок `autoHeight`, но не меньше `rowHeight`. Колонка
  `autoHeight` переносит текст сама.

Высота строки, заданная приложением функцией (`getRowHeight` AG Grid), — вне объёма, пункт roadmap.

### 2. Плагин и поля колонки

Плагин `textWrap({ estimatedRowHeight, maxLines, headerMaxLines })`:

- `estimatedRowHeight` — оценка высоты незамеренной строки, по умолчанию `rowHeight`;
- `maxLines` — предел строк ячейки `autoHeight`, по умолчанию 10; колонка задаёт свой
  `autoHeight: { maxLines }`;
- `headerMaxLines` — предел строк заголовка, по умолчанию 3.

Поля колонки `wrapText`, `autoHeight`, `wrapHeaderText`, `autoHeaderHeight` объявляет карта фичи
плагина. Без плагина они не действуют: строки и шапка фиксированной высоты, модуль замера в сборку
не попадает.

### 3. Предел строк

Ячейка `autoHeight` растёт не выше `maxLines` строк, дальше `…` и тултип. Без предела одна запись
дала бы строку выше области прокрутки: клавиатура и `scrollToRow` упирались бы в строку, которую
не видно целиком.

### 4. Замер

- **Ячейки, а не строка.** Плагин слушает размер содержимого ячеек колонок `autoHeight`
  (ResizeObserver) и сообщает высоту строки — наибольшую из них и `rowHeight` — источнику размеров
  ядра; виртуализатор берёт размер строки оттуда. Строка ставит свою высоту, все её ячейки —
  во всю высоту (фон, рамки, выравнивание кнопок), закреплённые и центральные одинаково.
- **Только отрисованные строки.** Весь список не меряется никогда: незамеренная строка — высотой
  оценки, полная высота тела до замеров — число строк × оценка.
- **Без кадра наложения.** Новая высота строки и позиции строк ниже приходят в одной отрисовке:
  кадра, где строки наложены друг на друга, нет.
- **Пачка замеров — одна пересборка мест** (правка вендора, ADR 0143). Высоты строк уходят
  виртуализатору пачкой `resizeItems`: одно уведомление, как у замеров его собственного
  ResizeObserver. Если с прошлой сборки менялись только размеры от `resizeItem`, места
  пересобираются без ключей и оценок: размер прежний, кроме изменённых строк, начало —
  нарастающим итогом. Иначе 100 000 строк читали бы ключ и оценку каждой на каждую изменённую
  строку (AH34–AH35, AH33).
- **Колонки вне окна.** Колонки `autoHeight` рисуются всегда, как в AG Grid: они входят в набор
  колонок, которые экстрактор окна колонок держит вне окна (ADR 0217). Остальные колонки
  виртуализируются. Высота строки не меняется при горизонтальной прокрутке.

### 5. Кэш замеров

- Размер хранится по id строки: строка, ушедшая из окна и вернувшаяся, после сортировки, фильтра и
  смены страницы — прежней высоты с первого кадра, без перемера.
- Строка перемеряется при смене её данных, ширины колонки `autoHeight` (протяжкой и на лету), видимости
  колонки и `rowHeight`. Сброшенный размер служит оценкой этой строки, пока её не перемерят: при
  протяжке ширины полная высота не падает к минимуму.
- Пока ячейка строки в правке, высота строки держится; после сохранения строка перемеряется.

### 6. Прокрутка

- **Видимое не сдвигается.** Замер строк выше экрана (прокрутка вверх в незамеренную область,
  приход блока SSRM выше экрана) поправляет позицию прокрутки на разницу: верхняя видимая строка
  остаётся на месте. Поправка — только за строку целиком выше экрана, и при первом замере тоже:
  строка у верхнего края стоит на месте и растёт вниз (AH11). Правило передаётся опцией вендора
  `shouldAdjustScrollPositionOnItemSizeChange` (AH36); без строк по содержимому — правило
  виртуализатора.
- **Ползунок плывёт** по мере замеров — как в MUI; это «Осознанное ограничение» roadmap. Оценка
  `estimatedRowHeight`, близкая к средней высоте, его уменьшает.
- **Растянутая область** (ADR 0142): коэффициент `k` пересчитывается при смене итога; колесо — 1:1,
  видимые строки не прыгают при замерах. Поправка на высоту строк выше экрана посреди щелчка колеса
  сдвигает идущую анимацию слоя прокрутки, а не обрывает её (`scrollLayer.adjustTo`).
- **Серверная модель** (ADR 0138): незагруженные строки, скелеты и пустые рамки строк отказавшего
  блока — высотой оценки; пришедшие строки меряются при отрисовке. Ключ строки — индекс: высота
  строки доходит до виртуализатора только замером (`resizeItem`, с поправкой прокрутки), его кэш по
  индексу переживает уход блока; оценка по id применяла бы высоту перезагруженной строки молча. После
  вставок и удалений кэш сбрасывается, строки у окна объявляют свои высоты заново.

### 7. Геометрия по позициям виртуализатора

Арифметика `× rowHeight` заменяется позициями виртуализатора (`start`/`size` строки) у всех таблиц —
с плагином и без:

- **PageUp/PageDown** листают на высоту видимой области в пикселях: активной становится строка,
  чья полоса содержит место на видимую высоту от начала активной (Excel, AG Grid). При одной
  высоте строк итог прежний.
- **Стрелка** к строке выше видимой области ставит её верхом к краю.
- **`scrollToRow`** к незамеренной строке едет по оценке, после замера — одна поправка, и строка
  встаёт по выравниванию; у плавной прокрутки поправка в конце без обратного рывка.
- **Удержание первой строки экрана** при вставках и удалениях выше (ADR 0157/0194) — по её
  замеренной высоте.
- **Липкие строки групп** (ADR 0160) выталкиваются по фактическому началу следующей строки.

### 8. Строки фиксированной высоты

Строки групп, хвоста ленты и футер — высотой `rowHeight`: растут только
строки данных. Стопка липких групп поэтому остаётся на уровнях `× rowHeight`. Скелет первой загрузки
рисует строки высотой `estimatedRowHeight` с одной полоской, их число — по высоте области.

### 9. Движение, перетаскивание, правка

- **Движение строк** (ADR 0107): строки едут к замеренным позициям; «призраки» уходящих строк
  сохраняют последнюю высоту. Смена высоты строки от содержимого (сохранили правку, сузили колонку) —
  геометрия без смены модели, без анимации (как RM7).
- **Перетаскивание строки**: слот броска — высотой с перетаскиваемую строку, соседи сдвигаются на
  неё; облако прежнее, однострочное.
- **Правка**: редактор прежний, однострочный; многострочный редактор длинного текста — вне объёма.

### 10. Шапка

- `wrapHeaderText` переносит подпись заголовка. Без `autoHeaderHeight` она остаётся в высоте
  `headerHeight` с `…` и тултипом.
- `autoHeaderHeight`: высота уровня шапки — наибольшая по всем его листьям, включая колонки вне окна
  виртуализации колонок: их заголовки шапка рисует всегда (тела колонок — нет). Горизонтальная
  прокрутка высоту шапки не меняет.
- Устройство: атрибут и пробу в ячейку заголовка плагин кладёт вкладом `head` канала вклада
  (ADR 0170); высоты уровней — в хранилище ядра (`core/headSizes.ts`), грид отдаёт их переменными
  `--tsr-comp-head-level-<N>-height`. Обёртка подписи не ниже строки шапки, а не своего уровня: иначе
  уровень не опустился бы. Рост шапки от замера наблюдателем — в следующем кадре: синхронный менял
  бы ячейки заголовка, за которыми следят другие наблюдатели грида.
- Во вложенной шапке у каждого уровня своя высота; растянутый лист занимает сумму высот своих
  уровней; кнопки заголовка встают по высоте.
- Предел — `headerMaxLines`, дальше `…` и тултип. Протяжка ширины перемеряет шапку и строки по ходу.

## Границы

- Высота строки от приложения функцией (`getRowHeight` AG Grid) — пункт roadmap.
- Многострочный редактор длинного текста (`agLargeTextCellEditor` AG Grid) — пункт roadmap.
- Перенос текста в выгрузке Excel — нет.
- Высота футера по содержимому — нет: итоги — числа.
- Высота строк групп, скелета, ошибки и хвоста ленты по содержимому — нет.

## Отвергнутые альтернативы

- **Режим на всю таблицу (`getRowHeight: 'auto'` MUI).** Мерил бы все ячейки строки, а не те
  колонки, где текст длинный, — дороже на широкой таблице.
- **Мерить только видимые колонки (`virtualizeColumnsWithAutoRowHeight` MUI).** Высота строки
  менялась бы при горизонтальной прокрутке.
- **Выключить виртуализацию колонок при авто-высоте (MUI по умолчанию).** На 1000 колонок отрисовка
  строки стоила бы всех колонок.
- **Оценка — средняя по замеренным строкам.** Каждый замер сдвигал бы итог всех незамеренных строк
  разом — ползунок прыгал бы сильнее.
- **Сброс кэша к оценке при протяжке ширины.** Полная высота падала бы к минимуму и росла обратно по
  мере прокрутки.
- **Строка в потоке (`position: static` ячеек) и замер строки целиком.** Ломает раскладку
  центральных ячеек по `left` и закрепление без перемонтирования (ADR 0011, CP38).
- **Без предела строк (AG Grid, MUI).** Одна запись даёт строку выше области прокрутки.
- **PageUp/PageDown на число строк.** При разной высоте листает неровно: страница из коротких строк
  — несколько строк экрана, из высоких — больше экрана.
- **Высота шапки по видимым заголовкам.** Шапка прыгала бы при горизонтальной прокрутке.
- **В ядре без плагина.** `DataGrid` без плагинов тяжелел бы ради редкой настройки.

## Последствия

- **+** Длинный текст читается в таблице; плотная таблица с несколькими строками в ячейке — одним
  полем колонки.
- **+** Геометрия клавиатуры, удержания прокрутки и липких строк перестаёт зависеть от одной высоты
  строк — задел под master-detail.
- **−** Ползунок плывёт по мере замеров; `estimatedRowHeight` его уменьшает.
- **−** Колонки `autoHeight` рисуются всегда: десятки таких колонок на широкой таблице дороже.
- **−** PageUp/PageDown меняют семантику со строк на пиксели (KN6); при одной высоте строк итог
  прежний.

## План внедрения

1. **Ядро и тело.** Источник размеров строк по id, оценка, набор колонок вне окна (общий с
   ADR 0217); геометрия по позициям виртуализатора (PageUp/PageDown, стрелки, `scrollToRow`,
   удержание первой строки, липкие строки, скелет). Плагин `textWrap`: перенос и предел, замер ячеек
   `autoHeight`, кэш по id и сброс. AH1–AH14, AH17–AH23.
2. **Режимы.** Растянутая область и SSRM, движение строк, перетаскивание, правка; аргументы плагина
   — в базу паритета моделей (ADR 0187). AH15–AH16, AH24–AH26.
3. **Шапка.** `wrapHeaderText`, `autoHeaderHeight`, уровни вложенной шапки, предел. AH27–AH30.
4. **Истории и проверки.** Истории S1–S7 с гайдами, axe и перф. AH31–AH33. Пункт roadmap «Высота
   строки по содержимому» вычёркивается, в «Осознанные ограничения» — плывущий ползунок, в «Паритет с
   рынком» — `getRowHeight` и многострочный редактор.
