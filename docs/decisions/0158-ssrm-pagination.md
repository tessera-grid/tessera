# 0158 — Пагинация в серверной модели строк

- **Статус:** Принято (решения — по итогам прожарки 2026-10-29)
- **Дата:** 2026-10-29
- **Изменяет:**

  - [ADR 0038](0038-pagination-and-status-bar.md) — второй серверный режим пагинации:
    данные страниц запрашивает грид.
- **Связано:**

    страницах.
  - [ADR 0040](0040-action-sessions.md) — сессия правки; известная проблема «правка при
    серверной пагинации завершается при уходе со страницы».
  - [ADR 0104](0104-scroll-to-row.md) — прокрутка к строке на другой странице.
  - [ADR 0157](0157-ssrm-row-transactions.md) — транзакции сдвигают границы страниц.

## Контекст

Серверная пагинация есть с ADR 0038: `pagination({ server: true, rowCount })`, а `data` —
текущая страница, которую приложение получает само; смена страницы — серверное действие
(ADR 0116). В SSRM пагинация инертна (SD26): приложение, которому нужны страницы, теряет
то, что даёт серверная модель, — запросы данных самим гридом, кэш посещённого, группы и
ленивые ветки, выбор `{ all, except }`, выделение с копированием, транзакции. В режиме без
SSRM грид не знает строк других страниц, и правка завершается при уходе со страницы
(известная проблема, ADR 0040).

### Как у других

- **AG Grid SSRM** — пагинация поверх кэша блоков: `paginationPageSize` не зависит от
  `cacheBlockSize`, данные запрашивает грид `getRows`. При неизвестном итоге кнопка
  последней страницы погашена до последнего блока. С группами страница считает строки
  верхнего уровня, дети раскрытой группы удлиняют её страницу; `paginateChildRows: true`
  режет по всем строкам.
- **MUI X** — серверный источник данных строится вокруг страниц: запрос — страница, кэш
  страниц с TTL.

## Решение

### 1. Страница — строки верхнего уровня

`pagination()` в SSRM активна. Страница — `pageSize` строк верхнего уровня сквозного
списка; дети раскрытых групп и ветки ленивых детей — на странице родителя и удлиняют её.
Раскрытие не сдвигает границы страниц.

### 2. Блоки и кэш

Блоки — по `blockSize`, независимо от размера страницы: запрашиваются блоки, пересекающие
страницу. Кэш (LRU по `maxBlocks`) держит посещённые страницы. Уход со страницы прерывает
`signal` её блоков в пути, поздний ответ кэш не меняет.

### 3. Переход

Новая страница показывается сразу; её незагруженные строки — скелеты, отказ блока — строки
ошибки с повтором (SD11). Посещённая страница открывается из кэша без запроса. Смена
сортировки, фильтра, поиска или размера страницы — переход на первую страницу, как в
клиентской пагинации.

### 4. Итог

Неизвестный итог: пейджер показывает «1–N из многих», кнопка последней страницы
недоступна до короткого блока; после него — итог, кнопка доступна.

### 5. Внутри страницы

Строки страницы виртуализированы, как в SSRM. Клавиши ходят в пределах страницы;
`aria-rowindex` — сквозной, `aria-rowcount` — итог. `scrollToRow` и `scrollToRowIndex` к
строке другой страницы переходят на неё.

### 6. Выбор, выделение, транзакции, правка

Выбор `{ all, except }`, выделение диапазона и транзакции (ADR 0157) — по сквозному
списку; транзакция сдвигает границы страниц. Черновик правки переживает уход со страницы и
возврат, пока её блок в кэше; блок строки в правке не вытесняется (SD9).

### 7. Флаг `server`

`pagination({ server: true })` в SSRM — одно dev-предупреждение, флаг не действует: данные
запрашивает грид. Режим без SSRM остаётся с прежним контрактом ADR 0038.

## Границы

- **Автоподбор размера страницы по высоте** (`paginationAutoPageSize` в AG Grid) — нет.
- **Страницы, режущие детей групп** (`paginateChildRows`) — нет.
- **Правка в режиме без SSRM** — по-прежнему завершается при уходе со страницы.

## Отвергнутые альтернативы

- **Переход как серверное действие** — прежняя страница под свечением до ответа, отказ
  откатывает страницу. В SSRM незагруженные строки уже показываются скелетами, а посещённое
  приходит из кэша: ждать нечего, откатывать некуда.
- **Страница по всем строкам списка.** Раскрытие группы переносило бы строки на соседние
  страницы.
- **Оба режима опцией.** Больше работы и тестов без явной нужды.
- **Правка завершается и в SSRM.** Кэш блоков знает строки других страниц — причины
  завершать сессию нет.

## Последствия

- SD26 и тест инертности пагинации в SSRM меняют ожидания.
- Известная проблема правки при серверной пагинации сужается до режима без SSRM.
