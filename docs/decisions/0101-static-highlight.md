# 0101 — Подсветка без блика, с плавным появлением

- **Статус:** Принято (решение автора 2026-10-13)
- **Дата:** 2026-10-13
- **Изменяет:** [ADR 0080](0080-highlight-api.md) — §5 «Блик» снят; HL8, HL23, HL24
  сняты; HL9, HL19, HL21 переформулированы; §6 — подсветка проявляется тем же
  переходом, каким гаснет.
- **Связано:**
  - [ADR 0094](0094-loading-glow.md), [ADR 0095](0095-pending-and-error-light.md) —
    движущийся свет в гриде означает загрузку и ожидание.
  - [ADR 0087](0087-forced-colors.md) — HC5: подсветка в высокой контрастности.

## Контекст

Опция `shimmer` у `table.highlight` пускала по заливке бегущую полосу: один проход,
`N` или бесконечно. На колонке, где полоса шла по заголовку, ячейкам и футеру в одной
фазе, это читалось как загрузка, а не как подсветка: движущийся свет в гриде уже
означает обновление данных (ADR 0094) и ожидание (ADR 0095). Подсветка — это
состояние «эта цель отмечена», а не процесс.

Блик стоил заметной машинерии: синхронизация фазы через `animationstart`
(`ShimmerSync`), таймер окончания в срезе, псевдоэлементы и `container-type` у строки,
ячейки, заголовка и футера, пять токенов, отключение на время прокрутки ради HL19.

## Решение

- **Подсветка — только статичная заливка.** Опции `shimmer`, типа `HighlightShimmer`,
  токенов `--tsr-comp-highlight-<tone>-shimmer`, `-shimmer-width`, `-shimmer-period`,
  атрибутов `data-highlight-shimmer`/`data-highlight-start` и компонента `ShimmerSync`
  больше нет.
- **Затухание остаётся.** Снятая подсветка (`duration`, `until`, `clear()`) уходит
  переходом `--tsr-comp-highlight-fade-duration`: мягкий уход заливки на загрузку не
  похож.
- **Появление — тем же переходом.** Прежде заливка вставала мгновенно, а гасла
  плавно. Переход слоя (`--tsr-highlight-row`/`-cell`/`-column`, зарегистрированы
  `@property` с прозрачным начальным значением) висит на самих `data-highlight` и
  `data-column-highlight`, а не только на атрибутах снятия. Элемент, смонтированный
  уже подсвеченным (строка или колонка вернулась в окно виртуализации), не
  проявляется: у нового элемента нет прошлого стиля, переход браузер не запускает.
  Подсветка, снятая и поставленная заново в одном такте (поиск), не мигает — атрибут
  не меняется. `prefers-reduced-motion` — мгновенно, общим правилом темы.
- Вспышку («что-то изменилось») приложение делает подсветкой с `duration`.

### Ломающее изменение

`HighlightOptions.shimmer` и экспорт `HighlightShimmer` удалены из публичного API (до
1.0 допустимо). Вызов с `shimmer` перестаёт проходить проверку типов; в рантайме
лишнее поле игнорируется — остаётся заливка.

## Требования

| ID   | Требование                                                                                                                                    | Вид    |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| HL25 | Подсветка статична: пока она держится, у строки, ячейки, заголовка, ячеек тела и футера цели нет CSS-анимаций — ни при постановке, ни позже   | visual |
| HL26 | Подсветка проявляется переходом `--tsr-comp-highlight-fade-duration`; строка, вернувшаяся в окно виртуализации, — сразу залитой, без перехода | visual |

Тест — `stories/__tests__/visual/highlight.test.tsx`.

## Последствия

- **+** Подсветка не спорит с индикаторами загрузки и ожидания.
- **+** Меньше кода и токенов; прокрутке с подсветкой нечего отключать.
- **+** Появление и уход заливки симметричны.
- **−** Привлечь внимание движением больше нельзя — только тоном, `label` и
  временем жизни.
