# 0077 — Высота строк и шапки, ширина колонок по умолчанию

- **Статус:** Принято (решения — по итогам прожарки 2026-10-09)
- **Дата:** 2026-10-09
- **Связано:**
  - [ADR 0004](0004-core-on-tanstack-table.md) — R6 (высота строки шапки), R7 (высота
    строки тела фиксирована), R8 (ширина колонки по `columnDef.size`).
  - [ADR 0013](0013-column-sizing.md) — изменение ширины колонок, `minSize`/`maxSize`.
  - [ADR 0034](0034-wcag-22-dragging-and-target-size.md) — зона нажатия 24×24.
  - [ADR 0060](0060-initial-loading-skeleton.md) — скелет первой загрузки по высоте строки.
  - [ADR 0018](0018-external-theming.md) — переопределение токенов темы.

## Контекст

Высота строки задана токеном `--tsr-comp-row-height` (50px): им пользуются строки тела,
шапки и футера, ячейки и скелет. Переопределение токена в CSS меняет тело (виртуализатор
меряет строки), но три места держат 50 в коде: высота шапки (`число уровней × 50`),
оценка виртуализатора (`ESTIMATE_SIZE`) и запасное значение постраничной клавиатуры. На
100 000 строк неверная оценка даёт неверную полную высоту, и ползунок прокрутки прыгает
по мере замеров. Отдельной высоты у шапки нет.

Ширина колонок задаётся `columnDef.size`/`minSize`/`maxSize` и параметром
`useCreateTable({ defaultColumn })`, но параметр не описан и не покрыт тестами, а
переданный объект заменяет умолчания Tessera целиком (`{ size: 200 }` теряет `minSize`).
Умолчание `minSize: 150` не даёт колонке быть уже 150px: `size: 100` молча становится 150.

Решено (прожарка 2026-10-09): высота — число от приложения, режимов плотности нет;
отдельная высота шапки; высота фиксированная; смена на лету — как у ширины колонок;
наименьшая высота — по размерам кнопок и контура фокуса; `defaultColumn` — публичный,
дополняет умолчания; умолчание `minSize` опускается до 48px.

## Решение

### Высота строк и шапки

- **`useCreateTable({ rowHeight, headerHeight })`**, px. `rowHeight` — строки тела,
  футера и скелета (по умолчанию 50); `headerHeight` — каждая строка шапки, во вложенной
  шапке тоже (по умолчанию — как `rowHeight`).
- **Источник правды — токены.** Пропы выставляют `--tsr-comp-row-height` и новый
  `--tsr-comp-head-row-height` на корне грида. Шапка переопределяет у себя
  `--tsr-comp-row-height` значением `--tsr-comp-head-row-height`, поэтому её строки и
  ячейки берут высоту шапки без отдельных правил. Без пропов токены можно
  переопределить в CSS темы — результат тот же.
- **Числа для раскладки** (оценка виртуализатора, высота шапки
  `--tsr-comp-head-height`) берутся из пропов, а без них — из вычисленных токенов корня
  до первой отрисовки (`useLayoutEffect`). Полная высота тела верна с первого кадра.
- **Смена на лету** — как у ширины колонок: таблица не пересоздаётся, строки и шапка
  перерисовываются по новой высоте, виртуализатор сбрасывает кэш замеров. Позиция
  прокрутки в пикселях сохраняется; первую видимую строку не удерживаем.
- **Наименьшая высота** — по текущим размерам: самая высокая кнопка строки — кнопка
  раскрытия (36px: отступ 8 + значок 20 + 8), снаружи у неё контур фокуса 2px, а ячейка
  обрезает выступающее. Тело — **40px**, шапка (кнопки 32px) — **36px**. Меньшее
  значение прижимается к минимуму, в dev — предупреждение. Ячейки служебных колонок
  отступают только по горизонтали: по высоте содержимое центрируется, и вертикальный
  отступ не съедает место кнопки.
- Высота остаётся фиксированной (R7).

### Ширина колонок

- **`useCreateTable({ defaultColumn: { size, minSize, maxSize } })`** — публичное:
  значения для колонок без своих. Переданное **дополняет** умолчания Tessera, а не
  заменяет.
- **Умолчания:** `size` 150 (TanStack), `minSize` **48** (было 150; 48 — наименьшая
  ширина текста ячейки), `maxSize` 750.
- Порядок: `columnDef` → `defaultColumn` → умолчания. Ширина, натянутая пользователем,
  живёт в срезе `columnSizing` (`state`/`onColumnSizingChange`) и важнее всех.
- Смена `defaultColumn` на лету меняет колонки, которые пользователь не растягивал.

## Границы

- Режимы плотности (compact/standard/comfortable) — не делаем; при нужде — кнопкой
  тулбара поверх `rowHeight`.
- Высота по содержимому и автоподбор ширины колонки — в roadmap.
- Строки ниже 40px требуют компактных кнопок — отдельной потребностью.

## Отвергнутые альтернативы

- **Только CSS-токен** — без числа в JS виртуализатор и шапка не знают высоту до
  замера; прыжок ползунка остаётся.
- **Только проп** — ломает переопределение темы через CSS (ADR 0018).
- **Удерживать первую видимую строку при смене высоты** — ширина колонок так не
  делает; поведение было бы разным.
- **Отклонять значение ниже минимума** — прижатие к минимуму предсказуемее.
- **Оставить `minSize: 150`** — `size` меньше 150 требовал бы явного `minSize`.

## Последствия

- **+** Высота задаётся одним числом, шапка — отдельно, большие данные не прыгают.
- **+** `defaultColumn` описан и предсказуем.
- **−** Изменение поведения: колонки по умолчанию можно сузить до 48px (было 150);
  `size` меньше 150 теперь соблюдается.
- **−** Новые пропы `rowHeight`/`headerHeight` и токен `--tsr-comp-head-row-height` —
  не ломающие.
