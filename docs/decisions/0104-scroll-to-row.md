## Контекст

Публичного способа прокрутить грид к строке нет. Приложение не может показать
найденную запись, только что добавленную строку или строку из уведомления, а подсветка
(ADR 0080) не докручивает к цели вне окна виртуализации. Строки смонтированы только в
окне, поэтому `element.scrollIntoView` не работает: строки нет в DOM.

### Как это сделано у других

- **AG Grid** — `ensureNodeVisible(node, 'top' | 'middle' | 'bottom')` и
  `ensureIndexVisible`; при пагинации сам переключает страницу, свёрнутые группы не
  раскрывает.
- **MUI X** — `apiRef.scrollToIndexes({ rowIndex, colIndex })`: строка и колонка разом,
  только видимые строки.
- **TanStack Virtual** — `scrollToIndex(i, { align: 'start' | 'center' | 'end' | 'auto',
behavior })`.

## Решение

### 1. API

```ts
table.scrollToRow(rowId, {
  align?: 'auto' | 'start' | 'center' | 'end', // 'auto' по умолчанию
  behavior?: 'instant' | 'smooth', // 'instant' по умолчанию
  columnId?: string, // ещё и горизонталь к колонке
  expandParents?: boolean, // раскрыть свёрнутых предков
}): Promise<boolean>
```

Метод ядра, без плагина, как `table.highlight`: доступен приложению и плагинам. По id, а
не по индексу: индекс меняется с сортировкой и фильтром. Промис — `true`, когда строка
смонтирована и стоит на месте; `false` — показать нельзя.

`align: 'auto'` не двигает уже видимую строку; строку ниже окна ставит к нижнему краю,
выше — к верхнему. «Окно» — тело между липкой шапкой и липким футером.

### 2. Где строка

- **В текущей модели строк** — прокрутка.
- **На другой странице пагинации** — страница переключается сама (как у AG Grid), затем
  прокрутка. Страница — по индексу корня строки: Tessera режет страницы по корням.
- **В свёрнутом родителе или группе** — `false` без смены раскрытия; с
  `expandParents: true` предки раскрываются одним обновлением среза `expanded`, как
  программный `table.setExpanded`: `onExpandRow` не вызывается — предки строки уже
  загружены, иначе её не было бы в модели. Раскрытие меняет состояние пользователя,
  поэтому — только по просьбе. Предок, которого раскрыть нельзя (`maxDepth`), — `false`
  без смены раскрытия.
- **Отфильтрована, ещё не загружена** (ленивые дети, лента, серверная страница) **или её
  нет** — `false`: фильтры и загрузку не трогаем, приложение догружает само и вызывает
  снова.

### 3. Как крутит

Два хода. Виртуализатор строк (`scrollToIndex`) приводит строку в окно монтирования, затем
по DOM строка доводится до места относительно липких шапки и футера — их виртуализатор не
знает; той же геометрией клавиатурная навигация доводит активную ячейку. При разной
высоте строк (ADR 0077) первый ход может промахнуться — довод повторяется, пока строка не
встанет.

По умолчанию прыжок мгновенный: строки на новом месте монтируются до входа в быструю
прокрутку и приходят с содержимым, как у кнопки «наверх» (BT6). `behavior: 'smooth'` —
плавно, промис после окончания.

`columnId` добавляет горизонталь: виртуализатор колонок, затем довод между закреплёнными
ячейками строки. Закреплённая колонка горизонталь не трогает, скрытая — `false`.

Фокус и активная ячейка клавиатурной навигации не меняются (как у AG Grid). Новый вызов
до конца прошлого побеждает: прошлый промис — `false`.

### 4. Связь с гридом

Таблица не знает о смонтированном гриде. `DataGrid` регистрирует «окно прокрутки» —
контейнер и виртуализаторы строк и колонок — на хранилище таблицы и снимает при
размонтировании; без окна `scrollToRow` — `false`.

### 5. Подсветка

`table.highlight(target, { reveal: true })` докручивает к цели: к строке, к ячейке
(строка и колонка), к колонке — только по горизонтали.

## Границы

- Догрузка ленивых детей, ленты или серверной страницы ради прокрутки — нет.
- Прокрутка к строкам шапки и футера — нет.
- Объявление скринридеру — нет: фокус не меняется, прокрутка — визуальная.
- Отдельный публичный `scrollToColumn` — нет; горизонталь — через `columnId` и `reveal`.

## Последствия

- **+** Приложение показывает нужную строку одной строкой кода, подсветка — с докруткой.
- **+** Страница переключается сама; раскрытие — только по просьбе.
- **−** Поиск строки вне текущей модели — обход дерева до раскрытия, O(n) на вызов.
