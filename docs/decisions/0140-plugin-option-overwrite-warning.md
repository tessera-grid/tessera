# 0140 — Предупреждение о перезаписи опций и хуков плагинов

- **Статус:** Принято (решения — по итогам прожарки 2026-10-26)
- **Дата:** 2026-10-26
- **Изменён:** 2026-10-31 — OW3: `manualFiltering` выставляет ядро, общая опция фильтров и поиска — только `filterFromLeafRows` ([ADR 0169](0169-data-mode.md)).
- **Связано:**
  - [ADR 0010](0010-invert-core-plugins-registry.md) — плагин — запись, опции и хуки
    складываются по порядку `plugins`.
  - [ADR 0022](0022-plugin-compatibility-contract.md) — договор совместимости плагинов.
  - [ADR 0028](0028-define-plugin-authoring-api.md) — `definePlugin`, DP5: дубль `id`.
  - [ADR 0138](0138-server-side-row-model.md) — случай, на котором край нашёлся.

## Контекст

Сборка таблицы складывает опции таблицы записей плагинов и их хуки через `Object.assign`
по порядку `plugins`: одноимённую опцию двух плагинов молча берёт последний. Так инертная
лента, подключённая после `serverRowModel`, перетирала его итог `getTotalRowCount`
(ADR 0138, SD26) — грид показывал не тот итог без единого сигнала.

Среди встроенных плагинов есть и задуманно общие опции: фильтры колонок и быстрый поиск
оба задают `filterFromLeafRows` и `manualFiltering` — режим данных у них общий.

Хуки `definePlugin` кладёт под ключ `id` записи, поэтому две записи с разными `id` в
хуки друг друга не пишут; дубль `id` уже предупреждает DP5. Перезапись хуков остаётся у
записи, собранной без `definePlugin`, которая пишет под чужой ключ.

### Как у других

TanStack Table складывает опции фич тем же «последний побеждает»; AG Grid и MUI X —
монолиты без плагинов, общих опций у них нет. Правил слияния ни у кого нет.

## Решение

1. **Порядок не меняется:** значение опции и хука — от последней записи в `plugins`.
2. **Предупреждение разработчику** в консоли браузера (логгер грида, ADR 0036): две записи
   с разными `id` задают одну опцию таблицы с разными значениями (`Object.is`) — в
   сообщении ключ и `id` обоих плагинов. То же для ключа хуков. Один раз на набор.
3. **Одинаковое значение — не перезапись.** Фильтры колонок и быстрый поиск задают
   `filterFromLeafRows` и `manualFiltering` всегда одним значением — режим данных у них
   общий; такие ключи не предупреждают, списка исключений не нужно.

## Границы

- Правила слияния значений (булевы через ИЛИ, функции цепочкой) — нет.
- Фичи (`features`) — нет: одинаковые ключи у модели и интерфейса — один и тот же
  объект.

## Отвергнутые альтернативы

- **Правила слияния по ключу.** Неявно для автора плагина и плохо объяснимо.
- **Только описать.** Ошибка остаётся молчаливой — как с итогом ленты.

## Последствия

- **+** Перезапись опции чужим плагином видна сразу, с именами обоих.
- **−** Плагин, который задаёт чужую опцию другим значением намеренно, всё равно
  предупреждает: значение от последнего — это и есть перезапись.
- **±** Обвязка историй подменяла слайсы хуков плагинов записью `demoHooks` (ADR 0027,
  «Последствия») — колбэки из аргументов фабрики пропадали; теперь демо-колбэки идут
  аргументами фабрик.
- **Публичный API:** без изменений; новое предупреждение в консоли разработчика.

## Требования

| ID  | Требование                                                                                                                                                                  | Вид       |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| OW1 | Две записи с разными `id` задают одну опцию таблицы с разными значениями (`Object.is`): предупреждение в консоли с ключом и `id` обоих; значение — от последней в `plugins` | модульный |
| OW2 | Две записи с разными `id` пишут хуки под одним ключом: предупреждение в консоли с ключом и `id` обоих; хуки — от последней                                                  | модульный |
| OW3 | Записи, задающие одну опцию одинаковым значением, не предупреждают: фильтры колонок и быстрый поиск вместе (`filterFromLeafRows`) — без предупреждений                      | модульный |
| OW4 | Все встроенные плагины в одной таблице не дают ни одного предупреждения о перезаписи                                                                                        | модульный |
