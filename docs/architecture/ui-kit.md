# UI-кит: как разрабатывать компоненты

Гайд для контрибьютора, который добавляет или меняет визуальный компонент Tessera: кнопку,
поле, флажок, плашку, бейдж, заглушку. Собирает правила из ADR, AGENTS.md и стражей кода в
одном месте. Источник истины по каждому правилу — указанный ADR; при расхождении правьте
гайд.

## 1. Где живёт компонент

- **Кит — `src/lib/ui`.** Каждый новый визуальный компонент добавляется сюда, а не
  собирается по месту в плагине или гриде (AGENTS.md, §6 «UI-кит»).
- **Слой.** `ui/` импортирует только `util/`: ни ядра, ни грида, ни плагинов, ни `shared/`
  ([ADR 0163](../decisions/0163-layer-boundaries-and-guards.md),
  [ADR 0166](../decisions/0166-shared-layer-utils-and-kit.md)). Нарушение роняет страж
  `layerBoundaries` в `npm test`. Отсюда следствия:
  - тексты компонент получает **пропами** (`label`, `title`, `labels`), словарь таблицы
    читает вызывающий код;
  - иконки — через `useIcons()` из `ui/icons` (переопределяются пропом `icons` у
    `DataGrid`);
  - тема портала — `usePortalThemeClass()` и `usePortalThemeData()` из `ui/theme`.
- **Публичность.** Компонент, нужный авторам плагинов и приложениям, экспортируется из
  [`src/ui.ts`](../../src/ui.ts) (вход `/ui`). Экспорт без истории роняет страж `uiStories`.
  Решение о публичности — за автором проекта: спросите, если не уверены.
- **Презентационность.** Компонент не знает о таблице, её состоянии и плагинах — его можно
  отрисовать и проверить отдельно ([ADR 0017](../decisions/0017-ui-components.md)).

## 2. Прежде чем писать

1. **Сначала существующий примитив.** Посмотрите `src/lib/ui` и соседние плагины. Подходит
   готовый — используйте его; не хватает пропа — расширьте его, а не копируйте стили.
2. **Новому компоненту — спецификация.** Как любая потребность библиотеки — сначала
   прожарка и ADR с требованиями ([ADR 0001](../decisions/0001-spec-driven-development.md)),
   затем код, тесты и история.
3. **Неясно — к человеку.** Вид, поведение, публичность или расхождение с китом решает
   автор: остановитесь и уточните до реализации.
4. **Вид подбирается в истории кита.** Пока вид не принят, тесты не пишутся; сначала
   история `UI.<Компонент>` с нужными состояниями, показ, ОК — потом тесты.

## 3. Стек и стили

- **Поведение — Base UI.** Роли, `aria-*`, фокус, клавиатура, порталы и позиционирование
  берутся из примитива Base UI. Своя логика доступности не пишется
  ([ADR 0003](../decisions/0003-formalize-tech-stack.md), [ADR 0017](../decisions/0017-ui-components.md)).
- **Стили — CSS Modules + `clsx`.** Tailwind-утилиты и `cva` в компонентах библиотеки не
  применяются (ADR 0003). Никакого CSS-in-JS и сторонних UI-китов.
- **Тонкая обёртка.** Компонент добавляет к примитиву стили и узкий стабильный контракт
  пропов; произвольные атрибуты (`className`, `data-*`, `aria-*`) проходят насквозь,
  `ref` — через `forwardRef` (запись в чужой ref — `ui/assignRef`).
- **Ref на последнее значение** — `util/useLatest`, а не запись `ref.current` в рендере
  (правила React Compiler в линте).

## 4. Токены

Три уровня, ссылки строго вниз ([ADR 0019](../decisions/0019-token-architecture.md),
[ADR 0018](../decisions/0018-external-theming.md)):

| Уровень   | Префикс        | Что                                                       |
| --------- | -------------- | --------------------------------------------------------- |
| Primitive | `--tsr-ref-*`  | сырые шкалы, без смысла и без светлой/тёмной темы         |
| Semantic  | `--tsr-sys-*`  | роли; только здесь светлая и тёмная тема и мост к shadcn  |
| Component | `--tsr-comp-*` | привязка к части грида; цвет — только через `--tsr-sys-*` |

Правила для компонента:

- **Только `--tsr-comp-*`.** Цвет, радиус, высоту, отступ, тень, кегль берите из токенов
  своей роли. Нет нужного токена — заведите `--tsr-comp-*` поверх `--tsr-sys-*` (цвет) или
  `--tsr-ref-*` (размер), а не литерал.
- **Никаких значений «на глаз».** Не подбирайте радиус, высоту или отступ вычислением или
  литералом, если в ките есть токен этой роли (`--tsr-comp-control-radius`,
  `--tsr-comp-button-size`, `--tsr-comp-popup-padding` и т. п.). Своя локальная
  переменная компонента (`--_track-w`) допустима для внутренней геометрии.
- **Тема — не в компоненте.** Блоков `.dark` в CSS компонента нет: тёмную тему переключает
  уровень `sys`. Приложение переопределяет вид переменными на `.data-grid-theme`.
- **Движение — только токены.** Длительности и кривые — `--tsr-comp-motion-duration`,
  `--tsr-comp-motion-easing`, `--tsr-comp-motion-easing-out` и собранные из них
  `*-transition`; литералов `ms` и `cubic-bezier` нет. Уменьшенное движение гасит тема одним
  правилом — компонент `prefers-reduced-motion` сам не обрабатывает (ADR 0017, MO1–MO6).

Подробно — [theming-and-overrides.md](theming-and-overrides.md).

## 5. Семейства и общий вид

Компоненты одной роли делят признаки — цвет покоя, наведение, выключенное, фокус, переход,
радиус. Новый член семейства вносится в список семейства в `theming-contracts.test.tsx` и
обязан пройти его контракт (ADR 0017, TC-1…TC-10):

| Семейство            | Члены                                                         |
| -------------------- | ------------------------------------------------------------- |
| F1 icon-контролы     | `IconButton`, `SortButton`, `PinButton`, `GroupButton`, ручка |
| F2 action-кнопки     | `RowButton`, `CellButton`                                     |
| F3 форм-контролы     | `SelectCheckbox`, `Switch`                                    |
| F4 кнопки тулбара    | `ToolbarButton`                                               |
| F5 кнопки с подписью | `Button`                                                      |

- **Плоские кнопки без тени.** Тень `shadow-action` — у всплывающих поверхностей и у
  варианта «поверх контента» (`overlay`).
- **Поповеры, меню, панели** берут вид из одного источника — `ui/Popup/Popup.module.css`
  через `composes` и токены `--tsr-comp-popup-*`; зазор до якоря — `POPUP_SIDE_OFFSET`.
  `composes` без переобъявления тех же свойств (страж `cssComposes`, PP10).
- **Порталы.** Всё, что рендерится в портал (поповер, меню, тултип), ставит себе класс и
  данные темы грида: `usePortalThemeClass()` и `usePortalThemeData()` — иначе тёмная тема и
  повышенный контраст в портал не попадут ([ADR 0090](../decisions/0090-theme-source-and-switching.md)).

## 6. Кнопки

Единая система — [ADR 0097](../decisions/0097-text-button.md),
[ADR 0098](../decisions/0098-button-system.md), [ADR 0128](../decisions/0128-derived-button-contract.md),
[ADR 0129](../decisions/0129-button-active-state.md):

- **Две базы.** `IconButton` (формы `circle` и `square`, варианты `ghost` и `overlay`) и
  `Button` (подпись, варианты `outline` и `ghost`). Размер, формы и палитра — общие токены
  `--tsr-comp-button-*`.
- **Производные — из базы.** Кнопка грида или плагина рендерит базу или её производную и
  задаёт только своё поведение и содержимое: своих размеров, форм, цветов и тултипов у неё
  нет. Нативный `<button>` в `grid`, `plugins` и `shared` — только в исключении с причиной
  (стражи BN8 и UB6 в `uiKitButtons`).
- **Тултип — в базе.** `label` у `IconButton` (имя и тултип), `tooltip` у `Button`;
  `tooltipWhenDisabled` — тултип у выключенной кнопки (`aria-disabled`, кнопка остаётся в
  порядке фокуса). Без подписи тултипа обёртки нет. Свой `Tooltip` вокруг кнопки — нельзя.
- **Общие пропсы производных** — `DerivedButtonProps`: `disabled`, `tooltipWhenDisabled`,
  `pending`, `failure`, `onClick`, `data-testid`; показ по наведению — `revealOnHover`.
- **Включённое** — `active`, `count`, `activeIcon`, `indicator` базы: цвет
  `control-active-color` и бабл-точка или число. Узел бабла — только у кнопки, которой
  передан `active`.
- **Без префикса `is`** в именах пропсов: `pinned`, `grouped`, `expanded`, как `disabled`.

## 7. Состояния

Набор состояний кнопки: покой, наведение, включённое, открытый поповер, фокус, ожидание,
отказ, выключенная. Старшинство: **ожидание и отказ главнее** бабла включённого состояния.

### Ожидание

[ADR 0127](../decisions/0127-initiator-pending-and-failure.md),
[ADR 0136](../decisions/0136-outcome-on-target-not-button.md),
[ADR 0176](../decisions/0176-cell-action-status.md):

- **Дуга по форме элемента** — `PendingArc` (`ui/buttonStates`): над бледной дорожкой
  бежит дуга с хвостом, радиус берётся из `border-radius` элемента (не больше половины
  меньшей стороны — иначе SVG скругляет эллипсом).
  - У кнопок — **по краю** кнопки (прозрачный контур).
  - У контролов с заливкой и рамкой — флажок, переключатель — **снаружи**, с зазором в
    толщину дуги: `placement="outside"`.
- **Занятость** — компонент в ожидании выглядит и ведёт себя как занятый:
  - **приглушён ровно так же, как выключенный** — цвет ожидания и выключенного совпадает.
    У кнопок — значок и подпись цветом `--tsr-comp-control-disabled-color` (ADR 0127,
    IR31). У флажка и переключателя — `opacity: var(--tsr-comp-disabled-opacity)` всего
    элемента, тем же правилом, что `:disabled`. Дуга при этом не гаснет: она не ребёнок
    контрола, а соседний слой в общей обёртке (`usePendingControl` отдаёт `host`, `control`
    и `arc`). Гасить части по отдельности нельзя — цвет разойдётся с выключенным;
  - `aria-busy`, нажатия не меняют значение;
  - курсор обычный, наведение не подсвечивает;
  - кольцо фокуса — снаружи дуги;
  - после ответа приглушение снимается, дуга плавно гаснет (фаза `leaving`), после
    отказа — останавливается и гаснет (`stopping`).
- **Готовые хуки:** `useButtonStates` — для кнопок (дуга, отмена «стопом»
  [ADR 0153](../decisions/0153-cancel-long-operations.md), угасание); `usePendingControl` —
  для контролов-значений (флажок, переключатель). Свою анимацию загрузки компонент не
  пишет.
- **Обрезка.** Дуга снаружи выходит за бокс элемента. Если предок обрезает содержимое
  (`overflow: hidden` ради многоточия), снимите обрезку на время ожидания через
  `:has([data-pending-arc][data-placement='outside'])`, как у обёртки текста ячейки
  (`grid/CellWrapperTitle`). `overflow-clip-margin` нельзя — его нет в Safari.

### Отказ и итог

- **Отказ** — проп `failed` останавливает дугу; отметки отказа на кнопке нет, кнопка не
  вспыхивает и не краснеет контуром ([ADR 0177](../decisions/0177-pending-and-failure-on-the-object.md)).
  Причину слышно объявлением, видно на объекте и в реестре отказов.
- **Отметка ячейки** — `CellIssue`: треугольник в правом верхнем углу ячейки, кнопка с зоной
  24×24; наведение — подсказка с причиной, нажатие — ленивый поповер с причиной и действиями.
  `tone: 'draft'` — тот же треугольник цвета несохранённого `--tsr-comp-draft-color` (ADR 0178,
  §4); отказ главнее черновика. Поповер один на все роли: заголовок (`title`), тело — причина или
  строки `details`, под разделителем кнопки справа, главная (`primary`) — с рамкой. Тот же цвет —
  у бабла тона `draft` (точка `IconButton` с `draft`, счётчик пульта). Полых форм у бабла нет:
  состояние различает тон заливки.
- **Итог — на цели**, а не на кнопке: вспышка ячейки, строки, колонки
  ([ADR 0134](../decisions/0134-outcome-flash.md)) или красный свет таблицы (ADR 0136).

### Выключенное

- F1, F2, F4, F5 гаснут **цветом** `--tsr-comp-control-disabled-color`, курсор обычный.
- Форм-контролы F3 — прозрачностью `--tsr-comp-disabled-opacity`.
- Пункт меню гаснет цветом, а не прозрачностью.

### Загрузка, ошибка, пусто

- **Загрузка** — `Skeleton`: размеры из токенов, общая волна грида
  ([ADR 0121](../decisions/0121-shared-skeleton-wave.md)). Для списков — строки-скелеты, а
  не текст «Загрузка…»; скринридеру — роль `status` и скрытая подпись.
- **Ошибка загрузки** — блок `LoadErrorBlock` (значок, текст, причина, кнопка повтора),
  общий с ошибкой подгрузки строк; плашка поверх — `Alert`
  ([ADR 0096](../decisions/0096-load-error.md)).
- **Пусто** — `Stub` ([ADR 0123](../decisions/0123-empty-state-stubs.md)).

## 8. Доступность

- **Роли и имена** — от Base UI; доступное имя — `label` или `aria-label`. Цвет не
  единственный носитель смысла (WCAG 1.4.1).
- **Фокус** — кольцо `--tsr-comp-focus-ring` толщиной `--tsr-comp-focus-ring-width`, только
  с клавиатуры (`:focus-visible`). Тултип открывается фокусом только после клавиатурного
  ввода (ADR 0017).
- **Зона нажатия не меньше 24×24** — прозрачный `::before` с отрицательным `inset`, вид не
  меняется ([ADR 0034](../decisions/0034-wcag-22-dragging-and-target-size.md), TS1–TS2).
- **Контраст** — пороги WCAG в обеих темах; новое видимое состояние попадает в реестр
  каталога и матрицу контраста ([ADR 0089](../decisions/0089-contrast-matrix.md)).
- **Высокая контрастность** — только системные цвета под `@media (forced-colors: active)`;
  слоям на масках и градиентах (дуга, скелет) — `forced-color-adjust: none` и системный
  цвет (`Highlight`, `GrayText`) ([ADR 0087](../decisions/0087-forced-colors.md)).
- **Повышенный контраст** — рычаги тонов темы под `prefers-contrast: more`
  ([ADR 0088](../decisions/0088-increased-contrast.md)); компонент берёт токены и
  своих правил режима обычно не пишет.

## 9. Браузеры

Порог — `browserslist` в `package.json` (Chrome и Edge 111, Firefox 128, Safari 17.1).
`npm run check:browsers` проверяет собранный CSS: свойство вне порога роняет шаг
([ADR 0084](../decisions/0084-cross-browser-support.md)). `:has()` допустим;
`overflow-clip-margin` — нет. Поведение, зависящее от движка (фокус, раскладка),
проверяется и в `npm run test:browsers`.

## 10. История кита

[ADR 0117](../decisions/0117-story-controls.md), [ADR 0128](../decisions/0128-derived-button-contract.md) §5:

- **Файл** `src/lib/stories/UI.<Компонент>.stories.tsx`, заголовок `Tessera/UI/<Компонент>`,
  холст `__mocks__/UiCanvas` (`host` — `cell`, `head`, `row`, `body` — рамка места, где
  компонент живёт в гриде).
- **`Playground` — первая история**, контролы по пропам (`defaultControls(...)`), клик
  меняет состояние через `useArgs`.
- **Истории состояний** — по одной на состояние (`Checked`, `Disabled`, `Pending`,
  `Always visible`…), вкладки Controls нет (`noControls()`, SN30).
- **Базы** показывают все варианты, формы и состояния историей `Variants`, цикл ожидания и
  отказа — `Async action`; производные показывают только свои состояния.
- **Каталог.** Каждая история — тест каталога: рендер без `console.error`, axe с
  `color-contrast` в обеих темах ([ADR 0093](../decisions/0093-visual-state-catalog.md)).
  Новое состояние реестра каталога — `vrStates(...)` и близнец высокой контрастности в
  `HighContrast.vr.stories.tsx`. Бюджет снимков — `scripts/catalog.ts`.

## 11. Тесты

Три вида ([ADR 0009](../decisions/0009-test-coverage-visual-and-performance.md)), по тесту на
требование, честно ([ADR 0043](../decisions/0043-honest-test-coverage.md)):

- **Визуальный** (`src/lib/stories/__tests__/visual/`) — вид, раскладка, роли и поведение
  настоящими событиями: `userEvent`, `humanClick` там, где важен фокус. Наборы кита:
  `ui-components`, `button`, `button-system`, `derived-buttons`, `button-states`,
  `pending-arc`, `active-state`, `segments`, `alert`, `cell-action-status`; общий вид —
  `theming-contracts`, `theming-popups`, `theming-motion`. Высокая контрастность —
  `commands.forcedColors(true)`; axe в обеих темах — `inBothThemes` из `a11y-helpers`.
- **Модульный** (`src/lib/__tests__/`) — логика, невидимая в DOM: стражи `uiStories`,
  `uiKitButtons`, `derivedButtons`, `cssComposes`.
- **Перф** — когда компонент множится массово (тысячи ячеек): прокрутка с состоянием против
  той же выборки без него, как AV11 у бабла.
- **TQ1** — каждый тест показан красным мутацией; откат — из своей копии файла, не
  `git checkout`.

## 12. Ловушки

- **Скрытое поле формы.** Флажок, переключатель и Combobox Base UI рендерят скрытый
  `<input aria-hidden="true">` — соседом сразу за контролом. Поиск «поля» в тестах и
  гайдах — `input:not([aria-hidden="true"])`; сам контрол в обёртке — её первый элемент, а
  не сосед дуги.
- **Абсолютный слой обрезается** предком с `overflow: hidden` (обёртка текста ячейки) —
  см. «Обрезка» в §7.
- **Зона нажатия на всю ячейку** — слой `::before` с `inset: 0` у содержимого: ячейка с
  `contain` — блок для абсолютных потомков.
- **Ширина списка Select** — замером триггера (`useTriggerWidth`), а не
  `var(--anchor-width)`: иначе «ResizeObserver loop» в отчётах приложений (PP8).
- **Узлы на каждую ячейку дороги.** Значок, бабл, дуга монтируются только там, где нужны
  (наведение, `active`, ожидание) — цена прокрутки ([ADR 0149](../decisions/0149-plugin-cost-on-scroll.md)).

## 13. Чек-лист нового компонента

- [ ] Подходящего примитива в `src/lib/ui` нет; ADR с требованиями принят.
- [ ] Модуль в `src/lib/ui/<Компонент>/`, импорты только из `util/` и кита.
- [ ] Поведение — примитив Base UI; стили — CSS Module на `--tsr-comp-*`, без литералов.
- [ ] Тексты — пропами, иконки — `useIcons()`, портал — класс и данные темы грида.
- [ ] Состояния из общих хуков (`useButtonStates`, `usePendingControl`), а не свои.
- [ ] Член семейства — в списке `theming-contracts`.
- [ ] Фокус, имя, зона 24×24, `forced-colors`, контраст в обеих темах.
