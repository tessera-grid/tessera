# Управление таблицей: клавиатура и мышь

Гайд для тех, кто работает с гридом Tessera руками: как ходить по таблице,
выделять, сортировать, править и переставлять. Спецификации — ADR
[0021](../decisions/0021-keyboard-navigation.md),
[0031](../decisions/0031-wcag-keyboard.md),
[0032](../decisions/0032-wcag-aa-remainder.md),
[0034](../decisions/0034-wcag-22-dragging-and-target-size.md).

## Что должно быть включено

Клавиатурное управление работает **только с плагином `keyboardNavigation()`**. Без
него грид — таблица для чтения: мышью всё работает, а `Tab` в ячейки не заходит.

Каждая возможность — свой плагин. Например, выделение ячеек требует
`cellSelection()`, правка — `cellEditing()`. Если плагина нет, его клавиши ничего
не делают.

### Где попробовать в Storybook

```bash
npm run storybook
```

Стенды с включённой клавиатурной навигацией — в разделе **Tessera → Common → Screen
readers** (только в `npm run storybook`) и в **Tessera → DataGrid**:

| История                         | Что пробовать                                             |
| ------------------------------- | --------------------------------------------------------- |
| **Screen readers — Grid**       | всё основное: ячейки, выделение, сортировка, правка, меню |
| **Screen readers — Tree grid**  | группы и уровни строк                                     |
| **Screen readers — Row moving** | перестановка строк и колонок                              |
| **Keyboard Navigation**         | базовая навигация                                         |

В остальных историях клавиатурной навигации нет.

Откройте историю кнопкой «Open canvas in new tab» (иконка справа вверху). Иначе
`Tab` сначала обходит панели самого Storybook и до таблицы доходит не сразу.

## Главная идея: активная ячейка

- **Вся таблица — одна остановка `Tab`.** `Tab` входит в таблицу, следующий `Tab`
  выходит из неё. По ячейкам ходят **стрелками**, как в Excel.
- **Активная ячейка** — та, на которой фокус. Она обведена рамкой. Все клавиши
  действуют на неё.
- **Таблица помнит место.** Вышли по `Tab`, вернулись по `Shift+Tab` — фокус на той
  же ячейке.
- **Два режима.** Обычно фокус на ячейке (режим навигации). Чтобы нажать кнопку
  внутри ячейки, войдите в неё (режим действия) — см. ниже.

## Быстрый старт

1. Кликните на странице перед таблицей, нажмите `Tab` — фокус в шапке таблицы.
2. `↓` — первая строка данных. `→` / `←` — соседние ячейки.
3. `Shift+→`, `Shift+↓` — выделение растёт диапазоном.
4. `Ctrl+C` — копировать выделенное.
5. `Tab` — выйти из таблицы.

## Перемещение

| Клавиши                                       | Что делает                                     |
| --------------------------------------------- | ---------------------------------------------- |
| `Tab` / `Shift+Tab`                           | войти в таблицу / выйти из неё                 |
| `←` `→` `↑` `↓`                               | на соседнюю ячейку                             |
| `Ctrl+←` / `Ctrl+→` (или `Home` / `End`)      | первая / последняя ячейка строки               |
| `Ctrl+↑` / `Ctrl+↓`                           | первая строка (шапка) / последняя строка       |
| `Ctrl+Home` / `Ctrl+End`                      | первая ячейка шапки / последняя ячейка таблицы |
| `Alt+↑` / `Alt+↓` (или `PageUp` / `PageDown`) | на экран вверх / вниз                          |

На macOS вместо `Ctrl` — `Cmd`.

Шапка и строка итогов (футер) — такие же строки: в шапку попадают `↑` с первой
строки, в футер — `↓` с последней.

## Выделение ячеек

Нужен плагин `cellSelection()`.

| Клавиатура                                   | Мышь         | Что делает                             |
| -------------------------------------------- | ------------ | -------------------------------------- |
| стрелка                                      | клик         | выделить одну ячейку                   |
| `Shift+стрелка`                              | `Shift+клик` | расширить диапазон на ячейку / до цели |
| `Ctrl+Shift+стрелка`                         | протяжка     | расширить до края таблицы / протянуть  |
| `Ctrl+A`                                     | —            | выделить всё                           |
| `Ctrl+C`                                     | —            | копировать выделенное                  |
| `Ctrl+Shift+Enter` (или `Shift+F10`, `Menu`) | правый клик  | контекстное меню («Copy»)              |

Выделение **идёт за фокусом**: обычная стрелка переносит его на новую ячейку.
Чтобы выделить диапазон, держите `Shift`. Если фокус ушёл туда, где ячейки не
выделяются (колонка чекбоксов, ручек, действий, шапка, итоги), выделение
снимается.

## Выбор строк

Нужен плагин `rowSelection()`.

| Клавиатура                          | Мышь             | Что делает                   |
| ----------------------------------- | ---------------- | ---------------------------- |
| `Space` на любой ячейке строки      | клик по чекбоксу | выбрать строку / снять выбор |
| в шапке `Ctrl+Enter`, затем `Space` | клик по чекбоксу | выбрать все строки           |

## Кнопки внутри ячейки (режим действия)

В заголовке есть кнопки: сортировка, закрепление, ручки. Бывают они и в ячейках
тела. Стрелки их пропускают, до них добираются так:

1. На ячейке нажмите `Ctrl+Enter` (или `F2`). Если у ячейки нет своего действия
   на `Enter`, хватит и `Enter`.
2. `Tab` / `Shift+Tab` ходят **по кнопкам этой ячейки** по кругу.
3. `Enter` или `Space` нажимает кнопку.
4. `Escape` — обратно на ячейку, дальше снова стрелки.

Если открыто меню, первый `Escape` закрывает его и возвращает фокус на кнопку,
второй — на ячейку.

## Шапка: сортировка, закрепление, ширина

`Enter` на заголовке сразу сортирует: это главное действие заголовка. До
остальных кнопок (закрепление, ширина, меню) — через `Ctrl+Enter` (или `F2`):
фокус встаёт на первую кнопку, `Tab` переходит к следующей, `Escape` возвращает
на заголовок.

| Клавиатура                                                    | Мышь                            | Что делает                                |
| ------------------------------------------------------------- | ------------------------------- | ----------------------------------------- |
| `Enter` на заголовке                                          | клик по кнопке сортировки       | следующий порядок сортировки              |
| `Shift+Enter` на заголовке                                    | `Shift+клик`                    | добавить колонку к сортировке             |
| `Ctrl+Enter` → `Tab` до «Pin column» → `Enter`                | клик по кнопке закрепления      | закрепить колонку слева / справа          |
| `Ctrl+Enter` → `Tab` до ручки ширины → `←` `→` (`Shift` — ×5) | протянуть правую границу        | уже / шире                                |
| на ручке ширины `Home`                                        | клик по границе → «Reset width» | ширина по умолчанию                       |
| —                                                             | клик по границе                 | меню «Wider» / «Narrower» / «Reset width» |

## Перестановка колонок и строк

Нужны `columnDragging()` / `rowDragging()`.

| Клавиатура                              | Мышь                             | Что делает                             |
| --------------------------------------- | -------------------------------- | -------------------------------------- |
| `Alt+Shift+←/→` на заголовке            | тянуть ручку ⠿ в заголовке       | сдвинуть колонку                       |
| `Alt+Shift+↑/↓` на ячейке строки        | тянуть ручку ⠿ слева в строке    | сдвинуть строку среди соседей          |
| `Alt+Shift+→` / `Alt+Shift+←`           | тянуть ручку вправо / влево      | вложить в группу выше / вынести из неё |
| `Ctrl+Enter` → `Tab` до ручки → `Enter` | **клик** по ручке (без протяжки) | меню команд перестановки               |

Меню на ручке: у колонки — «Move left» / «Move right», у строки — «Move up» /
«Move down», а в дереве ещё «Indent» / «Outdent». Недоступная команда видна, но
неактивна (например, «Move up» у первой строки).

Протяжка начинается после сдвига мыши на 5 px. Простой клик по ручке открывает
меню, а не начинает перетаскивание.

Фокус едет вместе с переставленной строкой или колонкой.

## Дерево и группы

Нужны `rowExpanding()` или `rowGrouping()`.

| Клавиатура                              | Мышь            | Что делает                           |
| --------------------------------------- | --------------- | ------------------------------------ |
| `Enter` на ячейке со стрелкой раскрытия | клик по стрелке | раскрыть / свернуть                  |
| `←` на первой ячейке строки             | —               | фокус на саму строку                 |
| на строке: `→`                          | —               | раскрыть; если раскрыта — в ячейку   |
| на строке: `←`                          | —               | свернуть; если свёрнута — к родителю |
| на строке: `↑` `↓` `Home` `End`         | —               | по строкам                           |

Фокус на строке нужен скринридеру: он зачитывает уровень, позицию и раскрыта ли
строка.

## Правка ячеек

Нужен `cellEditing()`.

| Клавиатура                 | Мышь                    | Что делает                          |
| -------------------------- | ----------------------- | ----------------------------------- |
| `Enter` или `F2` на ячейке | клик по кнопке правки ✎ | открыть редактор                    |
| `Enter` в редакторе        | —                       | сохранить (если значение допустимо) |
| `Escape` в редакторе       | клик мимо               | отменить                            |

Если значение недопустимо, под полем появится ошибка, а редактор останется
открытым. После закрытия фокус возвращается на ячейку.

## Частые вопросы

- **`Tab` перескакивает через таблицу или ходит по кнопкам.** Не подключён
  `keyboardNavigation()`. В Storybook откройте одну из историй выше.
- **`Tab` не ходит по ячейкам.** Так и задумано: по ячейкам ходят стрелки, `Tab`
  выходит из таблицы.
- **Стрелки прокручивают страницу.** Фокус не в таблице — нажмите `Tab`, чтобы
  войти. В NVDA при необходимости включите режим фокуса (`Insert+Space`).
- **Не видно кнопок в заголовке.** Они появляются при наведении мыши или когда
  ячейка в фокусе с клавиатуры.
- **На клавиатуре нет F-ряда, `Home`, `End`, `PageUp`, `PageDown`.** У каждой
  такой клавиши есть замена из основного блока: `Ctrl+Enter` вместо `F2`,
  `Ctrl+стрелки` вместо `Home` / `End`, `Alt+↑/↓` вместо `PageUp` / `PageDown`,
  `Ctrl+Shift+Enter` вместо `Shift+F10`.
- **`Alt+Shift+стрелка` переключает раскладку.** На Windows не должна. Если у вас
  переключает — пользуйтесь меню на ручке.
