# Ручная проверка на скринридерах

Автоматические проверки ([ADR 0033](../decisions/0033-a11y-tree-and-virtual-screen-reader.md))
подтверждают, **что** грид отдаёт скринридеру и что произносит эмулятор. Как это
звучит в настоящих NVDA, JAWS и VoiceOver, они не показывают: у каждого скринридера
свои режимы, своё озвучивание таблиц и свои горячие клавиши. Этот гайд — сценарий
ручного прохода, по итогам которого можно заявлять соответствие WCAG 2.2 AA.

**Когда проводить:** перед заявлением соответствия, перед релизом, после изменений
ролей, навигации, объявлений или меню на ручках (ADR 0020, 0021, 0031, 0032,
0034).

**Сколько времени:** около 40 минут на одну связку «скринридер + браузер».

## 1. Окружение

### Матрица

Минимум — первые две строки; остальные — по возможности.

| Скринридер                | Браузер | ОС      | Приоритет   |
| ------------------------- | ------- | ------- | ----------- |
| NVDA (последняя)          | Chrome  | Windows | обязательно |
| NVDA                      | Firefox | Windows | обязательно |
| JAWS (демо-режим, 40 мин) | Chrome  | Windows | желательно  |
| VoiceOver                 | Safari  | macOS   | желательно  |
| Экранный диктор           | Edge    | Windows | по желанию  |

### Установка и настройка

- **NVDA** — бесплатно, [nvaccess.org](https://www.nvaccess.org/download/).
  Включите **просмотр речи**: меню NVDA (`Insert+N`) → Инструменты → Просмотр речи.
  Всё произнесённое пишется в окно — его текст и копируйте в отчёт.
  - `Insert+Space` — переключение режима обзора и режима фокуса. В гриде NVDA
    переходит в режим фокуса сам; если стрелки листают страницу, а не ячейки —
    нажмите `Insert+Space`.
  - `Insert+↑` — повторить текущий элемент; `Insert+Tab` — где фокус.
- **JAWS** — демо-режим работает 40 минут, затем нужна перезагрузка Windows.
  История речи: `Insert+Space`, затем `H`.
- **VoiceOver** — `Cmd+F5`. Панель субтитров показывает речь на экране. Команды
  `VO` = `Ctrl+Option`. В таблицах `VO+стрелки` ходят по ячейкам в режиме чтения.
- **Экранный диктор** — `Ctrl+Win+Enter`.

Язык речи — английский: подписи Tessera по умолчанию английские.

### Запуск стенда

```bash
npm run storybook
```

Storybook откроется на `http://localhost:6006`. В боковой панели — раздел
**Tessera → DataGrid**, истории для проверки:

| История                        | Что в ней                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------------ |
| **Accessibility — Grid**       | навигация, сортировка, выбор строк и ячеек, правка с проверкой, закрепление, ширина, меню, футер |
| **Accessibility — Tree grid**  | группировка по `gender` с раскрытием — `treegrid`, уровни строк, фокус на строке                 |
| **Accessibility — Row moving** | дерево строк, перестановка строк и колонок с клавиатуры                                          |
| **Loading**, **Skeletons**     | состояние загрузки                                                                               |

Откройте историю кнопкой «Open canvas in new tab» (иконка в правом верхнем углу)
— так в фокус не попадают панели Storybook. Обновляйте вкладку перед каждым
разделом чеклиста.

## 2. Чеклист

Колонка «Ожидается» описывает **смысл** речи, а не дословную фразу: скринридеры
формулируют по-разному и в разном порядке. Пример — ориентир, как это звучит в NVDA.

### A. Структура и навигация — «Accessibility — Grid»

| ID  | Действие                               | Ожидается                                                                                                                                                     |
| --- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M1  | С пустого места страницы нажмите `Tab` | Вход в грид: имя таблицы «Data table», роль (grid/таблица), активная ячейка шапки. Пример: «Data table, grid, row 1, Select all rows, check box, not checked» |
| M2  | `→` по заголовкам                      | Имя колонки **без** текста кнопок («Country», а не «Country Sort descending»), состояние сортировки, номер колонки                                            |
| M3  | `↓` в тело, затем `→`                  | Содержимое ячейки и **заголовок её колонки** при смене колонки, номер строки при смене строки                                                                 |
| M4  | `PageDown`, затем `Ctrl+End`           | Прыжок на страницу и в последнюю ячейку; позиция озвучивается; контур фокуса виден                                                                            |
| M5  | `Tab` из грида                         | Фокус уходит из грида целиком (одна остановка Tab), а не на кнопки внутри                                                                                     |
| M6  | Вернитесь `Shift+Tab`                  | Фокус возвращается на ту же ячейку, где был                                                                                                                   |

### B. Действия — «Accessibility — Grid»

| ID  | Действие                                          | Ожидается                                                                                                                                    |
| --- | ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| M7  | `Enter` на заголовке «Country»                    | Сортировка меняется; объявление «Sorted by Country, descending» (или ascending); состояние сортировки заголовка обновлено                    |
| M8  | `Space` на ячейке тела                            | Строка выбрана («selected»); объявление «1 row selected»                                                                                     |
| M9  | `F2` на заголовке, затем `Tab` по кнопкам         | Кнопки заголовка с именами («Pin column», «Sort …», ручка «Resize column»); `Tab` ходит по кругу внутри ячейки; `Escape` — обратно на ячейку |
| M10 | На кнопке «Pin column» — `Enter`                  | Меню, пункты «Pin left» / «Pin right»; `Escape` — фокус на кнопке «Pin column», второй `Escape` — на ячейке                                  |
| M11 | На ручке «Resize column» — `→`, `Shift+←`, `Home` | Роль разделителя (separator/splitter), текущее значение ширины меняется и озвучивается                                                       |
| M12 | `Enter` на ячейке колонки Age                     | Поле «Edit Age», текущее значение                                                                                                            |
| M13 | В поле очистите значение, `Enter`                 | Ошибка «Value is required» объявлена; поле помечено как недопустимое (invalid); редактор не закрылся                                         |
| M14 | Введите значение, `Enter`                         | Редактор закрыт, фокус на ячейке, новое значение озвучено                                                                                    |
| M15 | `Shift+→`, затем `Ctrl+C`                         | Выделение расширено; объявление «Copied 2 cells»                                                                                             |
| M16 | `Ctrl+A`                                          | Выделены все ячейки (проверьте, что страница не выделилась целиком)                                                                          |
| M17 | `Shift+F10` на ячейке                             | Контекстное меню «Context menu», пункт «Copy»; `Escape` — обратно на ячейку                                                                  |
| M18 | `Ctrl+End`, затем `↓`                             | Строка итогов (футер): «Total»; `↑` — обратно в тело                                                                                         |

### C. Иерархия — «Accessibility — Tree grid»

| ID  | Действие                                                             | Ожидается                                                                              |
| --- | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| M19 | Войдите в грид, `↓` на первую групповую строку, `←` на первой ячейке | Фокус на **строке**: роль row, «collapsed» (not expanded), «level 1», позиция «1 of 2» |
| M20 | `→`                                                                  | Строка раскрыта («expanded»); второй `→` — фокус в первую ячейку                       |
| M21 | `←` (на строку), `↓`                                                 | Подстрока: «level 2», позиция «1 of N»                                                 |
| M22 | `←` на подстроке, затем ещё `←`                                      | Фокус на родительской строке; затем она свёрнута («collapsed»)                         |

### D. Перестановка — «Accessibility — Row moving»

| ID  | Действие                                                        | Ожидается                                                                                                                                          |
| --- | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| M23 | На ячейке строки `Alt+Shift+↓`, затем `Alt+Shift+↑`             | Строка переставлена и возвращена; фокус остаётся на ней, её ячейка озвучена. В NVDA при перехвате сочетания включите режим фокуса (`Insert+Space`) |
| M24 | На строке сразу после группы `Alt+Shift+→`, затем `Alt+Shift+←` | Строка вложена в группу («level 2») и вынесена обратно («level 1»)                                                                                 |
| M25 | На заголовке колонки `Alt+Shift+→`                              | Колонка переставлена, фокус на её заголовке, номер колонки изменился                                                                               |

### E. Загрузка и режим чтения

| ID  | Действие                                                                       | Ожидается                                                                                                             |
| --- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| M26 | История **Loading**: найдите индикатор                                         | «Loading», прогресс; таблица помечена как занятая (busy — озвучивают не все)                                          |
| M27 | История **Skeletons**                                                          | Объявлено «Loading»; пустая таблица из заглушек **не** зачитывается                                                   |
| M28 | «Accessibility — Grid», режим обзора: NVDA `T` (к таблице), `Ctrl+Alt+стрелки` | Размер таблицы — число строк (с учётом шапки) и колонок (с учётом служебных), заголовки строк и колонок при переходах |

### F. Меню на ручках — альтернатива перетаскиванию (WCAG 2.5.7)

| ID  | Действие                                                                                | Ожидается                                                                                                                 |
| --- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| M29 | «Accessibility — Row moving»: на заголовке `F2`, `Tab` до ручки перетаскивания, `Enter` | Ручка — «Move column», кнопка меню; открыто меню «Move column» с пунктами «Move left» / «Move right»; `Escape` — на ручку |
| M30 | Там же: на ячейке строки `F2`, `Tab` до ручки строки, `Enter`, выберите «Move down»     | Меню «Move row» с «Move up» / «Move down» / «Indent» / «Outdent» (неприменимые — недоступны); строка переставлена         |
| M31 | «Accessibility — Grid»: мышью клик по грипу ширины (правая граница заголовка), «Wider»  | Меню «Column width» с «Wider» / «Narrower» / «Reset width»; колонка шире, соседние сдвинулись                             |

## 3. Как записывать результат

Для каждой связки заполните таблицу:

```
Связка: NVDA 2025.x + Chrome 1xx, Windows 11, дата
| ID  | Итог | Что прозвучало (из просмотра речи) | Комментарий |
| M1  | ✔    | Data table grid row 1 …            |             |
| M2  | ✘    | Country Sort descending button     | имя с текстом кнопки |
```

- **✔** — смысл совпадает с «Ожидается».
- **~** — работает, но неудобно (лишняя болтливость, неожиданный порядок).
- **✘** — информация не озвучена, озвучена неверно, фокус потерян или клавиша не
  срабатывает.

Для каждого ✘ заведите находку:

```
ID проверки: M13
Связка: NVDA 2025.x + Firefox 1xx
Шаги: …
Прозвучало: …
Ожидалось: …
Повторяется в других связках: да / нет
```

Отличия скринридеров между собой (например, JAWS не озвучивает `aria-busy`) —
не всегда дефект грида. Если поведение соответствует ARIA, а скринридер его не
поддерживает, отметьте это как «~» с пометкой «ограничение скринридера».

## 4. После проверки

- Находки — в ADR 0032 (раздел «Открыто») или новым ADR, если нужно проектное
  решение; исправление — с тестом `SR<n>` или `AX<n>`, если эмулятор или дерево AX
  могут его поймать.
- Итог прохода (связки, дата, число ✔ / ~ / ✘) — в раздел «Результаты ручной
  проверки» ниже.
